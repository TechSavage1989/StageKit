# StageKit 0.1.0-beta2

Second pre-release. It adds a Windows installer; the plugin itself is the same as 0.1.0-beta1.
**Nothing has been run in OBS on Windows or macOS yet**, including the installer, so treat it as a test
build.

## What's new

- **Windows installer**: `stagekit-0.1.0-windows-x64-Installer.exe` puts the plugin in
  `C:\ProgramData\obs-studio\plugins\stagekit`, offers to close OBS if it has the plugin open, and adds
  an entry under *Apps & features* for removing it.

## Installing on Windows

1. Close OBS.
2. Run `stagekit-0.1.0-windows-x64-Installer.exe`. It needs administrator rights. Windows may warn that
   the publisher is unknown, because the installer is not signed: choose *More info*, then *Run anyway*,
   if you trust this download.
3. Start OBS (31 or newer).

The `windows-x64` zip is still provided if you prefer to copy the `stagekit` folder into
`C:\ProgramData\obs-studio\plugins\` yourself.

## Known limits

- Shaders are only proven on OpenGL. If a StageKit filter shows a blank or unchanged picture on Windows,
  look for `stagekit` in *Help → Log Files → View Current Log* and report it.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
- Scene filters do not list items inside groups.
- No in-app update check: update by running a newer installer.
