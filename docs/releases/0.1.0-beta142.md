# StageKit 0.1.0-beta142

One hundred and forty-second pre-release: the transitions between a hidden source and its standby
image work when the source has other filters. Tested on Linux only.

## Fixed

- **Standby Image, *Show when source is hidden*: most transitions switched in place.** With any
  filter after Standby Image on the source (a shadow, corners), the standby image appeared at
  once when the source was hidden, and when it was shown the standby image stayed, or flashed,
  and then cut to the source. OBS draws a filtered source only once per frame, so while the
  source and its standby image were both on screen they both showed the same image. The standby
  image is now drawn from a copy of its own, and the source and the image are apart all the way
  through a slide, a fade or any other transition.

## Changed

- The first transition list in the Standby Image filter is now called **No-signal transition**,
  to tell it from *Show/Hide transition*. It is used while the source is shown but has nothing
  to show; *Show/Hide transition* is used when the source is hidden or shown in a scene.
