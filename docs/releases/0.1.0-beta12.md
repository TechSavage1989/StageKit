# StageKit 0.1.0-beta12

Twelfth pre-release, from the owner's reports on Windows. These changes pass the automated tests on
Linux; **they have not been run in OBS on Windows yet.**

## What's changed

- **Auto Frame holds the shape it found.** When a window goes full-screen at the same picture shape, or
  the resolution changes, the picture keeps its shape: no showing the bars and trimming them again. A
  menu or pop-up over the bars does not resize it. It changes only when another real picture shape has
  been clearly on screen for a while, or when a different program is captured.
- **Hold a shape for**: a setting (0 to 60 seconds) for how long that different shape must be on screen
  before the picture changes to it.
- **Controls are no longer pushed to the right.** Long labels did that; labels in every StageKit tool
  are now short, with the detail in a tooltip.
- **The start image is the background automatically.** Choosing a start image makes every Ambient
  Background use it. New backgrounds use it from the start.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A picture in an unusual shape that appears after a standard one is followed only after twice the hold
  time (at least 6 seconds), because it cannot be told from a pop-up at first.
- A background you want kept on its own image has to be set back to *An image* after you choose a start
  image.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
