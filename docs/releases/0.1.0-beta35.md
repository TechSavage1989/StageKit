# StageKit 0.1.0-beta35

Thirty-fifth pre-release: Undo and Redo. It passes the automated tests on Linux; **it has not been run
in OBS on Windows yet.**

## What's new

- **StageKit's moves are in OBS's Undo.** Every line-up, spacing, resizing and snapping tool, from the
  right-click menu, a hotkey or the dock, is one step in *Edit → Undo* (Ctrl+Z) and *Redo* (Ctrl+Y),
  named after the tool, for example *Undo StageKit: Align left*.
- *Snap on release* adds its own step after the drag's, so one Undo takes back the snap and a second
  takes back the drag.
- The dock's nine *Send to* buttons are a step too, added when the item has finished gliding.

Moves made by Stream Deck keys and by filters while you are live are not added to Undo: they are
part of the show, not edits.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
