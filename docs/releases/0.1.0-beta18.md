# StageKit 0.1.0-beta18

Eighteenth pre-release: Auto Frame and unusual picture shapes, from the owner's reports. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's fixed

- **Trim automatically now works for two-screen handhelds and other unusual shapes.** It only trims to
  shapes it knows, and it did not know these: two screens stacked or side by side (DS, 3DS), PSP, Lynx,
  WonderSwan, Neo Geo Pocket, Virtual Boy, upright screens and ultra-wide.
- melonDS, DeSmuME, Citra, Lime3DS, Azahar and Borked3DS start from their usual stacked-screen shape.

## What's new

- **Keep this trim for this program.** After *Measure the bars now*, or after setting the trim by hand,
  one press saves that shape for the program being captured and goes back to automatic. From then on
  that program is right at once, at any window size, and other programs are still worked out by
  themselves.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A shape that is not on the list is still not trimmed by guesswork, because a dark game would be
  mistaken for bars. Use *Keep this trim for this program* for those.
- A kept trim is centred: it assumes the bars are the same on both sides.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
