# StageKit 0.1.0-beta230

The guide groups related tools and shows which one to use for common OBS tasks.

## New

- **Choose a tool by job.** Six tables compare showing and hiding, framing, positioning, appearance, capture selection and transitions.
- **Build one holding scene with Scene Modes.** The guide walks through a shared Starting, Be right back and Ending scene with a key per mode. It also describes the Link Visibility setup used by the conversion script.

## Changed

- **Find related settings together.** Source and scene controls now sit alongside the corresponding tools. The guide links to the detailed settings from each comparison.
