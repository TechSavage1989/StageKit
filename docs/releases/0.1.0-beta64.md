# StageKit 0.1.0-beta64

Sixty-fourth pre-release: **Show in Scenes**, one switch for showing and hiding sources across
scenes. It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Show in Scenes (StageKit)**, a new filter for any source. It is a switch: on shows the sources,
  off hides them (or the other way round), in every scene they are in or only in the scenes you list.
  One Stream Deck *Filter* key does what took a multi-action with a step for every scene.
  - **Sources to show and hide**: choose to add as many as you like. Leave it empty and it acts on
    the source the filter is on.
  - **In**: *Every scene they are in*, or *The scenes listed below*.
  - **When this is on**: *They are shown* or *They are hidden*.
  - Items inside groups are included, and each item's own show and hide transition is used.

## Setting it up

1. Right-click a source, choose *Filters*, press **+** under *Effect Filters* and pick
   *Show in Scenes (StageKit)*.
2. Choose the sources and scenes, or leave both as they come to act on this source everywhere.
3. In the Stream Deck app, add an OBS *Filter* key and point it at that source and that filter.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- It acts when it is switched. If you show or hide one of the items by hand, the key can be out of
  step with it until the next press.
- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
