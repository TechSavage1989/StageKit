# StageKit 0.1.0-beta31

Thirty-first pre-release: Shadow & Backdrop grows into **Shadow, Glow & Outline**. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet**, where its changed shader is
compiled by Direct3D for the first time when OBS starts.

## What's new

- **A new name**: *Shadow, Glow & Outline (StageKit)*. The filters you already have are the same
  filter and keep their settings.
- **Glow**: *Type* chooses a drop shadow to one side or a glow all round.
- **Made from the picture itself**: the shadow or glow can be a soft, moving copy of the source's own
  colours, so a game or camera lights up the space around it. *Colour boost* makes it richer.
- **Outline**: a line round the picture at any width, in a colour or in the picture's own colours. It
  follows the real shape (text, rounded or cut corners), and the shadow is cast by the picture and
  outline together.
- **Tidier controls**: three groups, *Shadow or glow*, *Outline* and *Panel behind the source*, each
  switched on by the tick box in its heading. Only the controls that apply are shown.

The picture still keeps its size and place in every scene when these settings change.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
