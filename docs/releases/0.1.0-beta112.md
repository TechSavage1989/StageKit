# StageKit 0.1.0-beta112

One hundred and twelfth pre-release: a slide can go off the nearest edge in Show in Scenes. It
passes the automated tests on Linux.

## New

- **Show in Scenes: *Off the nearest edge*.** With *Slide* or *Swipe* chosen under *Show with* or
  *Hide with*, the direction list has one more entry. Each item then goes towards whichever edge
  of the screen it is nearest to when it hides, and comes in from that side when it shows, so
  items on different sides of the screen each go their own way from one setting.

## Good to know

- OBS's own transitions move an item's picture inside the item's own frame: a slide leaves through
  the side of that frame, it does not travel across the screen. To have an item travel in from the
  screen's edge, the Show/Hide Animation filter does that.

## Please check

1. In a Show in Scenes filter, choose *Slide*, set its direction to *Off the nearest edge*, and
   hide and show sources on different sides of the screen. Does each go towards its own side?
