# StageKit 0.1.0-beta60

Sixtieth pre-release: switch to a window by hand and have it stay, alongside automatic app switching.
It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Active App: captures you switch to.** A new list in the Active App filter for captures you show
  yourself, such as a Window Capture of your browser.
  - Show one and it takes over and stays, whatever app you click into.
  - Hide it and the capture of the app you are using comes back, and automatic switching carries on.
  - With several on the list, showing one hides the others.
  - It is shown and hidden like any item, so a Stream Deck key that shows and hides the source works
    as the toggle, and so do OBS's own *Show* and *Hide* hotkeys for the item.
  - Two new hotkeys on the scene in *Settings → Hotkeys*, named after the filter: one steps through
    these captures and then back to the apps, one goes straight back to the apps.

## Setting it up

1. In the scene with your app captures, add a Window Capture aimed at the window you want.
2. Open the scene's filters, choose *Active App*, and add that capture under *Captures you switch to*.
3. Make a Stream Deck key that shows and hides that source in that scene.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
