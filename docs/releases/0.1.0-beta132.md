# StageKit 0.1.0-beta132

One hundred and thirty-second pre-release: a tidier dock. The updater is out of its bottom and the
Arrange tools are a block. It
passes the automated tests on Linux; the Windows side has not run in a real OBS here.

## Changed

- **The update notice is at the top of the StageKit dock, and only there when there is an
  update.** *StageKit … is available*, with *What's new* and *Update*, is now the dock's first
  row. With no update there is nothing of the updater in the dock.
- **The rest is in OBS's Tools menu, under StageKit:** the version you have, *Check for updates
  now*, *Check when OBS starts* and *Include test versions*; and *Update to … now* while a newer
  version is waiting. Checking from the menu answers in a small window when there is nothing
  newer, since the dock may not be in sight.
- The *Updates* button at the bottom of the dock is gone; it and the notice below the tabs had
  pushed the dock past its window and brought up a scroll bar.
- **The Arrange tab's tools are a block**, three across: align left, centre and right on top;
  align top, middle and bottom under them; then the spacing tools; then same width, same height
  and same size. **How the tools measure** stands to the right of the block, so everything below
  moves up and the tab no longer needs a scroll bar.
