# StageKit 0.1.0-beta23

Twenty-third pre-release: one correction to the dock. It passes the automated tests on Linux; **it has
not been run in OBS on Windows yet.**

## What's fixed

- **Zooming the start image thumbnail no longer zooms the background in your scene.** The mouse wheel
  and dragging on the thumbnail now only give a closer look at the picture in the dock. If you zoomed
  it in beta20 or beta21, the moving background goes back to showing the whole picture.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The thumbnail's zoom is not remembered; it resets when the picture changes or OBS restarts.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
