# StageKit 0.1.0-beta234

OBS Plugin Manager now identifies StageKit and all 22 bundled plugins by name.

## Changed

- **Bundled plugins are clearly labeled.** In Tools > Plugin Manager > Installed, look for StageKit and entries beginning with “StageKit -”, including “StageKit - Move Transition”, “StageKit - 3D Effect” and “StageKit - Freeze Filter”.

## Good to know

- **Standalone plugins can be disabled in OBS.** If your setup uses only the StageKit version, clear the matching standalone entry, click OK and restart OBS. This works even when the standalone plugin has no uninstaller.
