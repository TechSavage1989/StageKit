# StageKit 0.1.0-beta255

Keep controls from different scenes together in one StageKit Views panel.

## New

- **One control panel.** StageKit Views opens with buttons for existing modes, linked visibility, Show in Scenes, controller choices and combined views from across the scene collection. Use them directly without selecting a different scene or controller first.
- **Choose your buttons.** Edit panel adds several controls at once, including ordinary source and OBS Sources group visibility. Set labels, sections and order, or return to automatic controls. Each scene collection remembers its own panel.
- **Import all.** Import every supported Scene Modes and Link Visibility filter on the selected controller's scene in one action. Existing imports are skipped, and the result reports imported and skipped counts.

## Changed

- **Controller management.** Scene and controller selectors, configuration and import are under Manage controllers. Back to controls returns to the button panel. Adding a controller leaves Import immediately accessible.
- **Combined-view wording.** The editor shows Control and Set to, with help explaining that a preset chooses settings for existing controls. Individual group buttons do not require a combined view.

## Fixed

- **Saved button targets.** Buttons keep their identity when sources are renamed. A removed target stays unavailable instead of selecting a new source with the same name. Highlights follow actual OBS state, including changes made outside the panel.
- **Complete imports.** Bulk import validates the complete batch before applying it and preserves full settings and disabled filters. A rejected batch cannot leave a partial set of new groups.
- **Removing imported originals.** An original filter retained by OBS for Undo no longer blocks its active imported group after deletion. The controller keeps its groups and settings; existing keys or panel buttons that target the original must be retargeted before removing it.

## Good to know

- **Existing setups.** The panel can operate existing controls without importing them. Imported originals remain compatibility aliases so existing keys and hotkeys keep working. Show in Scenes and other filters still provide their own behavior.
- **Independent choices.** Choose one source limits visibility within that group. Different groups can each have an active choice, and combined views can select several groups together. Link Visibility's Together and Follow behaviors remain supported.
- **Companion.** The Stream Deck companion remains 0.43.0.0. Existing actions and controller definitions are unchanged.
- **Windows first.** The Windows installer is published after its native build, actual OBS frontend checks and shared release checks pass. Other platform assets follow through the existing publisher.
