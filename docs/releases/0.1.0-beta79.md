# StageKit 0.1.0-beta79

Seventy-ninth pre-release: the Stream Deck plugin's keys use the StageKit icon pack. The OBS plugin
itself is unchanged from beta77. **The Stream Deck plugin has not been run on a real Stream Deck
yet.**

## New in the Stream Deck plugin

- **The keys show the icon pack.** Left on *Automatic*, a key takes the picture that fits its filter
  and how it is set:
  - Ramp Blur: its blur type (Gaussian, box, Kawase, pixelate, zoom, motion, hexagons);
  - Send To and Place Item: the place on the screen it sends the item to;
  - Shadow, Glow & Outline: soft shadow, glow, outline or panel;
  - Corners & Edges: round, cut, notch or scoop;
  - Auto Capture, Auto Frame, Show in Scenes, Standby Picture: their own picture.
  Switch keys have an "on" and an "off" look.
- **Picture**: give a key any other picture of the pack, such as the ones drawn for one source.
- **Colour**: one choice for every StageKit key: mono (as it comes), violet, ocean, forest, ember or
  neon.
- A filter the pack has no picture for yet shows a plain switch.

Install `stagekit-0.1.0-streamdeck.streamDeckPlugin` from this page over the earlier one; keys you
have already set up keep their settings.
