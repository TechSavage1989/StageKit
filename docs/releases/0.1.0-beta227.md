# StageKit 0.1.0-beta227

The dock shows which sources it acts on, remembers move timing and gives more control over captures and scene transitions.

## New

- **Copy to a chosen destination.** Copy transforms to the same source in other scenes or to the listed sources. The Arrange tab shows which selection it will use.
- **See what a filter is doing.** Scene Fit identifies sources it fits or skips. Scene Shadow and Scene Blur name a filter that prevents them from drawing. Apply Layout shows when its saved source list has changed.
- **Choose how captures change.** Auto Capture can use the Standby Image's own transition. When hiding scene items, it can use a chosen transition or keep each source's own. Ambient Background adds four wipes and Fade and zoom.
- **Set both shadow times.** Scene Shadow has separate fade-in and fade-out durations. A filter with a saved duration starts with that value in both fields.

## Changed

- **Pick a transition directly for a scene source.** Scene Transitions offers the scene's sources under Settings for. Window pickers offer titles and their stable prefixes. Auto Frame and Aspect Ratio Preset share the 8:7, 64:49 and 16:15 choices.
- **Use the dock's saved move settings.** The Place tab remembers Duration. New position keys use the chosen scene when In every scene is clear. The update check opens the release details when it finds a newer build.

## Fixed

- **Keep hotkey bindings after a rename.** The affected capture, switcher, zoom, preset and standby hotkeys follow the new name.
- **Keep a background's chosen image.** Changing the shared standby image preserves backgrounds set to their own image file. The dock can also clear the shared standby image.
