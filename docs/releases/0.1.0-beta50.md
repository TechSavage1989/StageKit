# StageKit 0.1.0-beta50

Fiftieth pre-release: *Same width* and the other line-up tools follow the item you selected last,
*Ignore shadows* does what it says, and the guides are drawn a new way. It passes the automated tests
on Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **"Last selected" (and "First selected") could pick the wrong item.** The order you select items in
  was only noticed by the dock looking at one scene a few times a second. When the dock's own *Scene*
  list showed a different scene from the one you were editing, the order was forgotten every time,
  and the item highest in the Sources list was used instead. The order now comes straight from OBS
  each time you select an item, in every scene, so it is right from the dock, the preview's
  right-click menu and the hotkeys alike.
- **The dock's Arrange box always works on the scene you are editing**, whatever its *Scene* list
  shows (that list is for the *Send to* buttons). It falls back to the dock's scene only when nothing
  is selected in the one you are editing.
- **"Ignore shadows" did the opposite with *Same width*, *Same height* and *Same size*.** It removed
  the shadow by cutting a strip off the source's edges. When a picture does not reach its own edges,
  as a browser widget's often does not, the shadow was inside that strip and was counted as picture.
  Now the picture is measured as it is before its shadow is added. Ticked: the pictures come out the
  same size and each shadow reaches past its picture. Unticked: each item together with its shadow
  comes out the same size, allowing for a shadow that keeps its size on screen.
- **Guides in the preview showed nothing.** Each line is now a thin window of its own laid exactly over
  the preview, instead of one see-through window over all of it, and whether the mouse button is held
  is also asked of Windows directly.

## Changed

- The dock's *Order* box: *Bring to front* above *Send to back*, and *Forward one* above *Back one*.
- *Ignore shadows* and the *Same* tools have tooltips that say what they compare.

## If the guides still do not show

Make sure the preview is set to *Scale to Window* (right-click the preview, *Preview Scaling*). Then
send the newest file from *Help → Log Files → Show Log Files*: lines starting `[stagekit] Guides:` say
whether StageKit found the preview, saw your drag and placed a line, and where.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides assume the preview is set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
