# StageKit 0.1.0-beta9

Ninth pre-release: two fixes to the dock's *Start image* box, both reported by the owner. They pass the
automated tests on Linux; **they have not been run in OBS on Windows yet.**

## What's fixed

- **A long start image file name no longer stretches the dock.** The dock could not be made narrower
  than the name. The name is now shortened to fit; hover over it for the full path.
- **The dock shows a small picture of the start image**, so you can see which one is set.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Auto Capture works on Windows only and its game detection has not been tried on a real machine.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
