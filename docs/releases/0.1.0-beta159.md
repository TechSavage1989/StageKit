# StageKit 0.1.0-beta159

One hundred and fifty-ninth pre-release: a fix for beta158, where a chat box could be drawn into the
camera's morph. Tested on Linux only.

## Fixed

- **The camera no longer morphs from the chat box.** Beta158 let a source left over join a morph
  already under way when it covered as little as 15 % of the screen. In Chat Live, showing the
  full-screen camera hides the capture and the chat column: the camera morphed from the capture, as
  it should, and from the chat box as well. Now joining a morph as the main image needs a third of
  the screen on both sides: the camera and the captures still join, and a panel beside them (a chat
  box, say) fades by itself. A source you link to another in Morph's settings still joins its morph.

## Added

- **OBS's log names every morph between two sources and why**, one line per change, for example
  `Morph: 'DSLR' changes into 'Window Capture' in 'Chat Live' (main image)`.

## Not yet tried on Windows

- Tested headless with OBS 30; not yet run in OBS 32 on Windows.
