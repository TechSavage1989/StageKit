# StageKit 0.1.0-beta139

One hundred and thirty-ninth pre-release: the standby image can take a source's place while the
source is hidden. It passes the automated tests on Linux; the Windows side has not run in a real
OBS here.

## Added

- **Show when source is hidden**, a new tick box in the **Standby Image** filter. Add the filter to
  any source (a camera, a capture, an image) and tick it: from then on, in every scene that has
  the source, hiding it shows the standby image in the same position and at the same size, and
  showing it again takes the standby image away.
  - The standby image gets the source's own shadow, corners and other filters that come after the
    Standby Image filter, so it looks like the source's frame with another image in it.
  - **Transition** and **Duration** under the tick box set how the standby image appears and
    disappears (a fade of 300 ms as it comes).
  - The image is the one chosen in the filter: the standby image, a file, or another source.

## How it is done, and what to expect

- OBS draws nothing for a hidden source, so StageKit adds a second, locked item straight under
  each one, named after the source with *(standby)* at the end. You will see these in the Sources
  list. StageKit keeps each in its source's place and shows and hides it by itself. Unticking the
  box or removing the filter takes them out again.
- Sources inside a group are not covered yet, only sources placed straight in a scene.
- The filter's older use is unchanged: on a capture it still shows the standby image while the
  capture has nothing, whether or not the new box is ticked.
