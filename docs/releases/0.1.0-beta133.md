# StageKit 0.1.0-beta133

One hundred and thirty-third pre-release: Blur reaches a camera shown through a Cropped View. It
passes the automated tests on Linux; the Windows side has not run in a real OBS here.

## Fixed

- **A camera shown through a Cropped View was never blurred.** Blur's *And live captures on
  screen* only looked for captures placed in the scene themselves. A capture that is on screen
  only by way of a Cropped View (or a scene or group the view shows) was passed over, so *Square
  Camera* stayed sharp whether or not it was under *Never blur these*. Such a capture is now
  blurred with the others, and listing the Cropped View under *Never blur these* keeps it clear,
  as before.
