# StageKit 0.1.0-beta36

Thirty-sixth pre-release: line up to one chosen item, and see what is selected. It passes the automated
tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Align to: First selected / Last selected.** That item stays where it is and the others line up
  with it. *Same width*, *Same height* and *Same size* copy that item's size too. Click the item you
  want the others to follow first (or last), then Ctrl-click the rest.
- **The dock lists everything you have selected**, under *Selected* in the Arrange box, in the order
  you selected it. With *First selected* or *Last selected*, the item the others will follow is in
  bold and marked *(stays put)*.
- The right-click menu's *Align to* is now a small sub-menu with all four choices: the screen, each
  other, first selected, last selected.

OBS does not record the order items are selected in, so StageKit notes it while its dock exists. Items
selected in one go (dragging a box round them) count in their order in the Sources list.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
