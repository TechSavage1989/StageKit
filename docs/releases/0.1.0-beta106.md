# StageKit 0.1.0-beta106

One hundred and sixth pre-release: the shared place is for the scenes you choose, and a size set by
hand survives a restart. It passes the automated tests on Linux.

## Changed

- **Fit to Space: *Same place in these scenes*** is now a list of scenes, in place of the tick box
  that linked every scene. Only the scenes you add get the item's place; anywhere else the source
  keeps its own. The link holds both ways, so adding scene B to the list in scene A is enough for
  both, as long as B has a Fit to Space for the item too.
  **If you ticked *Same place in other scenes* on beta105, that tick is gone: add the scenes to
  the new list instead.** Copies that beta105 already moved in other scenes stay where it put
  them; put those back by hand, or with *Copy transform to chosen scenes*.

## Fixed

- **An item with *Resize it to fit* unticked changed size by a few pixels each time OBS was
  restarted.** On loading, the filter went back to the size the item had before the filter was
  first added, so a size set by hand afterwards was lost. The size kept is now saved with the
  scene collection and used when OBS starts.

## Please check

   Do the scenes you left out keep their own layout?
2. Set the chat box to the camera's width once more, close OBS and start it again: is it still
