# StageKit 0.1.0-beta10

Tenth pre-release: Auto Capture's controls, redone after the owner's first look at them. The owner has
seen Auto Capture load and capture a game on Windows; these new controls pass the automated tests on
Linux and **have not been run in OBS on Windows yet.**

## What's changed

- **It says what it is capturing**, at the top of the filter: *Now capturing: snes9x-x64.exe*, or that
  it is waiting for a game.
- **Not a game? Never capture this program**: one press when it picks up the wrong thing.
- **Pick from the programs that are open** and press *Always capture it* or *Never capture it*. No file
  names to type.
- The two big list boxes are now two short text lines (`blender, vlc`), and the labels are short enough
  to read. Lists made in 0.1.0-beta8 keep working.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The line that says what is being captured is read when the filter's window opens; press *Check again*
  to update it.
- Auto Capture works on Windows only.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
