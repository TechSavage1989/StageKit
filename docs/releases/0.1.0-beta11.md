# StageKit 0.1.0-beta11

Eleventh pre-release: Auto Frame's controls redone, and picture shapes that need no setting up. These
changes pass the automated tests on Linux; **they have not been run in OBS on Windows yet.**

## What's changed

- **Auto Frame says what it sees**: the top line names the program being captured and the picture shape
  in use.
- **Numbered groups and short labels**: frame size, picture, black bars, picture shape for each
  program, movement. Nothing is cut off in the filter window.
- **Common emulators are known already**: Snes9x, bsnes, mGBA, VisualBoyAdvance, Project64, DuckStation,
  ePSXe, Kega Fusion, BlastEm, Flycast, Redream, PPSSPP, BGB, SameBoy and Gambatte get their usual
  picture shape with nothing to set. It can be switched off.
- **Pick a program instead of typing**: choose from the programs that are open, or find the program's
  file on the computer, choose a shape and press *Remember this shape for this program*. Your shapes win
  over the built-in ones. Shapes saved in earlier versions keep working.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The built-in shapes assume each emulator's usual picture settings. If one is wrong for your setup,
  save your own shape for that program.
- Emulators that play several consoles (RetroArch, Dolphin, PCSX2) are not built in.
- The top line is read when the filter's window opens.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
