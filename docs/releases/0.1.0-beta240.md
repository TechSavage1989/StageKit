# StageKit 0.1.0-beta240

Set a timer on a clock face and reduce repeated rendering work in OBS scenes.

## Timer controls

- In Timer settings, click the clock or drag its hand to choose hours, minutes and seconds. Scheduled timers pair the clock with a calendar and AM/PM buttons.
- Set a countdown or count-up limit with one of five presets: 1, 5, 15 or 30 minutes, or 1 hour. The private dock and on-stream source use the same controls.
- A paused calendar timer runs its finish actions once when resumed after the chosen time.

## Scene performance

- Scene Fit and the placement tools find the same visible edges with fewer pixel checks, including on transparent overlays.
- Scene Fit looks up each source's claimed space directly when it moves, settles or becomes hidden.
- In Each source mode, Scene Shadow reuses an identical layer mask for outlines and shadows, avoiding a second draw of those sources.
- Ambient Background skips a graphics pass when the base image is already its own darkest-level reference. The live capture and transition paths still apply the configured lift.
