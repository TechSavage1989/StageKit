# StageKit 0.1.0-beta240

Reduce graphics-thread work in scenes that use Scene Fit and Ambient Background.

- Scene Fit and the placement tools find the same visible edges with fewer pixel checks, including on transparent overlays.
- Scene Fit looks up each source's claimed space directly when it moves, settles or becomes hidden.
- Ambient Background skips a graphics pass when the base image is already its own darkest-level reference. The live capture and transition paths still apply the configured lift.
