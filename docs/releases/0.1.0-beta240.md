# StageKit 0.1.0-beta240

Set a timer on a clock face and reduce repeated rendering work in OBS scenes.

## New

- **Clock-face time picker.** Click an hour, then a minute, or drag the hand to a precise second. For a scheduled finish, pick a date from the calendar and choose AM or PM.
- **One-click durations.** Set a countdown or count-up limit to 1, 5, 15 or 30 minutes, or 1 hour. The private timer and the on-stream source share these controls.

## Changed

- **Scene Fit and placement.** StageKit finds the same visible edges with fewer pixel checks and looks up each source's claimed space directly when its layout changes.
- **Scene Shadow.** In Each source mode, outlines and shadows can reuse the top layer's mask when every visible source in that layer casts.
- **Ambient Background.** The background skips a graphics pass when its base image is also its darkest-level reference. A live capture or transition uses the configured lift.

## Fixed

- **Calendar timer finish actions.** Resuming a paused timer after its deadline displays the end message and switches Program to the selected scene once.

## Good to know

- **Open the clock.** Choose Timer settings in Docks > StageKit Timer or in the properties of a Countdown Timer (StageKit) source.
