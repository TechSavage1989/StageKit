# StageKit 0.1.0-beta209

Outlines with chosen corners go evenly round what shows of each source, and a new Square corner gives sharp corners.

## New

- **Square outline corners.** *Outline corners* has *Square*: a line with perfectly sharp corners
  round the source's image, in Shadow, Glow & Outline and Scene Shadow, carried by Morph.
  *Follow the source* still follows text and odd shapes, its outer corners rounded by the line's
  width.

## Fixed

- **Outlines are the same width on every side.** With *Square*, *Rounded*, *Bevel*, *Notch* or
  *Scoop*, the line now goes round the part of the source that shows, so a capture or widget with
  see-through margins no longer gets a thin line on some sides and a thick one on others. It holds
  for sources in a bounding box, cropped or scaled, and through a Morph. *Rounded* or *Bevel* at a
  corner size of 0 are exactly square.

## Good to know

- **Only run on OpenGL.** The shader changes have only been run on OpenGL here, not on Direct3D,
  and have not been seen on Windows.
- **Crop before Shadow, Glow & Outline.** An item's crop cuts that filter's outline with the rest of
  what it draws. Crop with a Cropped View or a crop filter placed before it, or use Scene Shadow.
