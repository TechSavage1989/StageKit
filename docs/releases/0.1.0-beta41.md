# StageKit 0.1.0-beta41

Forty-first pre-release: a likely cause of games crashing removed, and steady pictures when a game or
window changes size. It passes the automated
tests on Linux; **it has not been run in OBS on Windows yet.**

## Games crashing

To tell whether the program in front is a game, Auto Capture looked at which graphics and controller
libraries it had loaded, once a second. The Windows call it used for that works, for another program,
by starting a thread inside that program. That is a plausible cause of the game crashes you reported,
though not a proven one. Auto Capture now:

- reads the list from outside the program, with nothing started inside it;
- looks into a given program at most six times while it starts up, then remembers the answer for as
  long as that program runs.

**If a game still crashes with OBS open, please tell me which game**, and whether it also crashes with
the Auto Capture filter switched off (the eye icon next to it).

## What's changed

- **No jump when a game goes between a window and full-screen.** With Auto Frame set to *Just the
  picture*, the source used to take the capture's own pixel size, so the same game at a different
  resolution made everything re-fit. The picture now always has the height set in Auto Frame and is as
  wide as its shape needs. The same shape at another resolution changes nothing a scene can see.
- **Fit Item no longer lags a frame behind.** It now sets the item's OBS bounding box and lets OBS fit
  the picture inside it for every frame drawn. A window being dragged to a new size stays fitted in
  real time, as your old scenes did. Fit Item works on any source, including a Window Capture.
- **Auto Capture finds windowed games sooner.**
  - A program seen to be a game is remembered, so next time it is picked up at once, in a window and
    even behind another program.
  - It looks twice a second instead of once.
- **A shape held from one game no longer sticks to the next.** After an old-ratio emulator, a
  widescreen game could stay cropped to the old shape, for a long time if its picture was dark. When
  the capture has been away for more than four seconds, the next picture now starts afresh. A game
  switching between a window and full-screen is back sooner than that and keeps its shape.

## After installing

In Auto Frame on your game capture, set *Height* to your canvas height (1440) if it is not already, so
the picture is not scaled up from a smaller size.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A change of *shape* (a different console, or a game changing aspect) still re-fits at once, with no
  glide.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
