# StageKit 0.1.0-beta119

One hundred and nineteenth pre-release: no more frame drops when the window switcher changes
windows, a manual / automatic toggle, names in OBS's own terms, and Stream Deck keys with a picture
and a title for every option. It passes the automated tests on Linux; the Windows side and the
Stream Deck plugin have not run on real hardware here.

## Fixed

- **Frame time jumped at every switch between windows.** Your logs showed it: OBS spent up to
  135 ms in one step at a switch, and that step was Window Captures being started. Each switch
  started one background capture, re-aimed the Window Capture itself and stopped a third. Now
  every open window on the lists has its background capture from the moment its app opens, the one
  being shown included, and a switch only changes which of them is drawn. Nothing is started,
  aimed or stopped at a switch.

## New

- **Toggle manual / automatic.** One action that goes from automatic switching to your manual
  window (the one held last) and back. It is a button in the filter, a hotkey under the capture,
  and an *On press* choice on the Stream Deck key. Pick the window with *Capture Active Window*,
  then use the toggle. The scene filter has the same hotkey.
- **Stream Deck plugin 0.9.0.0**
  - **No words in the key art.** Every picture, in every palette, has had its name taken out.
  - **Titles set by themselves.** Each key's title says what it does with the options you chose
    (*Manual / Auto*, *Blur Off*, *Slide Up Left*, *Align Left*, *16:9* and so on). A title you
    type yourself still wins.
  - **A picture for every option.** Every arrange tool, every dock option, every aspect ratio,
    each of the four *Manual Window / Source* actions, a saved spot, a layout, and every filter
    that had only the plain key now has its own picture, in all six palettes.

## Renamed

All the names from the table you approved. Only what you see changed: filters already in your
scenes keep working and keep the names you gave them, and keys on your deck keep working.

| Before | Now |
| --- | --- |
| Capture App in Use | **Automatic Window Switcher** |
| Show Source in Use (first Follow Active App) | **Automatic Source Switcher** |
| Apps to capture | **Windows to switch between** |
| Follow the app in use | **Switch to the active window** |
| Apps you switch to / Captures you switch to | **Manual windows** / **Manual sources** |
| Switch to the next of these | **Switch to next manual window** |
| Back to following the apps | **Return to automatic** |
| Keep the others ready | **Keep other windows captured** |
| Change with / Lasting, in every filter | **Transition** / **Duration** |
| Show with / Hide with | **Show transition** / **Hide transition** |
| Hiding and showing it | **Show/Hide transition** |
| Next Manual Capture (Stream Deck) | **Manual Window / Source** |
| Capture Front Window (Stream Deck) | **Capture Active Window** |

## Good to know

- While a window is shown from its background capture, the Window Capture's own *Window* setting
  stays where it was. The filter's status line says what is being shown.
- The first switch after OBS starts, or after an app opens, may still go the slower way: its
  background capture needs a moment to start.
- The new option pictures are plain line drawings on the pack's own little screen. They were
  drawn here, not with the program that made your icon pack.

## Please check

1. Click between your windows a few times with OBS's Stats window open. Has the frame time stopped
   jumping at each switch?
2. Install the Stream Deck plugin from this release. Do the keys show no words in their pictures,
   and a title that fits their options?
3. Set a *Manual Window / Source* key to *Toggle manual / automatic*. After *Capture Active Window*
   on your browser, does it switch between the browser and automatic?
