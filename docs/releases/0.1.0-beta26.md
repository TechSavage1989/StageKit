# StageKit 0.1.0-beta26

Twenty-sixth pre-release: a tidier dock. It passes the automated tests on Linux; **it has not been run
in OBS on Windows yet.**

## What's changed

- **Less text in the dock.** The three explanatory paragraphs are gone; hover over a box or the
  thumbnail to read them as a tooltip.
- **Shorter labels.** For example *Make 9 position keys*, *Save this spot as a key…*, *Background
  picture…*, *Use visible pixels*, *Ignore shadows*, *Snap on release*; the boxes are now *Send to*,
  *Keys*, *Add effect*, *Arrange* and *Order*.

Nothing works differently.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
