# StageKit 0.1.0-beta63

Sixty-third pre-release: the Standby Picture keeps its own shape and morphs into the capture. It
passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **The standby picture changed shape the moment a game was recognised, then cut to the game.** It
  now keeps its own shape while it waits, and when the capture arrives its size glides smoothly to
  the capture's shape while the picture fades into the game.
- **The picture was cropped to the game's box.** It is now shown whole, in its own shape, as tall as
  the capture last was.
- **After the game ended it kept the game's shape.** It now glides back to its own shape.

## Changed

- *Fade to the capture* is now **Change over**, and covers both directions. The default is 0.8
  seconds, up from 0.3.
- New tick box **Picture keeps its shape** (on). Untick it for the earlier behaviour: the picture
  fills the size the capture last had.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- With an Auto Frame on the same capture, the game's shape can go on settling for a moment after it
  starts; the glide follows each change.
- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
