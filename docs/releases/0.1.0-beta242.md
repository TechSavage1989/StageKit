# StageKit 0.1.0-beta242

Keep the running timer in place as the digits change. The ending message fits the box you positioned.

## Fixed

- **Steady digits in the scene and the private dock.** The font size, baseline, and position stay fixed through each tick, including when 10:00 becomes 9:59 with the leading zero off.
- **Fixed formatted output.** Prefixes, separators, and text after the time stay put with custom fonts and time placeholders.
- **An ending message that fits in place.** The message resizes inside the existing box. Finishing and resetting crossfade the clock and message at their own sizes.

## Good to know

- **Existing timers.** Saved fonts, formats, and OBS scene-item transforms carry over. A hidden leading digit leaves its position empty.
