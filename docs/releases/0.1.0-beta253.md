# StageKit 0.1.0-beta253

Choose scene modes and source views from one OBS dock and matching Stream Deck keys.

## New

- **Scene Controller.** One scene filter holds independent groups for named modes, single-source choices, linked sets and visibility-follow rules.
- **StageKit Views dock.** Select a group or a combined saved view from a compact list. Configure groups, source membership, transitions and combined views directly in OBS.
- **Combined views.** Select content, camera and overlays together while leaving other groups unchanged. An ordinary view keeps the current Program scene; a scene destination is explicit.
- **StageKit View key.** Companion 0.43.0.0 uses the same native definitions and state, with direct selection or next-choice cycling and the shared image controls.
- **Legacy import.** Copy complete Scene Modes or Link Visibility settings into a controller. Active imports keep the old filter as a compatibility alias for existing keys and hotkeys; inactive copies can be reviewed first.

## Good to know

- **Compatibility.** Existing filters and keys remain supported. Newly configured groups need no additional or hidden filters.
- **Rendering.** The controller reuses native visibility and mode behavior and adds no image effect. This release does not establish a hardware frame-time improvement.
- **Companion update.** Update both the OBS plugin and Stream Deck companion to use StageKit View. The countdown cycle key continues to show its clock deadline.
