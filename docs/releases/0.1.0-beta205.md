# StageKit 0.1.0-beta205

Ambient Background no longer shows black bars between the repeats of an image with empty edges, and an animated standby image, such as a GIF, now plays everywhere it is shown.

## Fixed

- **No black bars between the repeats.** An image file used as the Ambient Background with
  see-through or black edges (rows and columns all the way along, up to a quarter of the image from
  each side) is drawn without them, so drifting and *Mirror at the edges* join the image itself
  with no strip between the copies. The edges are found once when the image is loaded.

- **Animated standby images play.** A GIF chosen as the standby image now moves in the Standby Image source, in every Standby Image filter (also the image shown in a hidden source's place and those Scene Standby adds), in Ambient Background and in the dock's small image, which keeps its zoom. Still images are shown as before.

## Good to know

- **Only run on OpenGL.** The shader change has only been run on OpenGL here, not on Direct3D.
- **Sources are used as they are.** A source or scene chosen as the background, and a live
  capture, are not trimmed.

- Tested on Linux only; not yet seen on Windows.
