# StageKit 0.1.0-beta184

Auto Capture now really leaves alone a program it gets no image from.

## Fixed

- **OBS no longer keeps trying to hook a program Auto Capture is leaving alone.** When a program
  such as an emulator with no game running gave the capture no image for ten seconds, Auto Capture
  was meant to leave it alone for a while. But the capture stayed aimed at it, and OBS went on
  trying to hook it about twice a second. Now, while the program is left alone, the capture is
  aimed at no window, or at another game if there is one. It is aimed at the program again when the
  wait ends.
- **A changing window title no longer ends the wait at once.** Dolphin's titles change all the
  time, with the frame rate or a GBA window going between *Volume 100%* and *Muted*, and each wait
  ended a quarter of a second after it began. Now numbers in a title do not count, and neither does
  any title seen in the first ten seconds of the wait. Only a title not seen before ends it, at most
  three times while the program stays open. Clicking back into the program counts only when none
  of its windows was in front.
- **A program put on *Never capture* while it is left alone gives way at once.** The capture goes
  back to any full-screen application, if that is ticked, instead of staying aimed at no window.

## Good to know

- The OBS log says `aimed at no window while <program> rests` once for each wait.
- A program that takes a while to show its first image (Ryujinx took seven seconds) still gets the
  full ten seconds on every try.
- Not yet tried on Windows.
