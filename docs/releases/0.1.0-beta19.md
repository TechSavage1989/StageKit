# StageKit 0.1.0-beta19

Nineteenth pre-release: the Cropped View source. It passes the automated tests on Linux; **it has not
been run in OBS on Windows yet.**

## What's new

- **Cropped View (StageKit)**, a source that shows part of another source: a square, 4:3, 16:9, 3:4 or
  9:16 taken from the middle, or set amounts off each side. Filters added to the view, such as Shadow &
  Backdrop, follow the crop. One camera can be shown in several shapes, each with its own shadow,
  without a scene wrapped around it, and it is still captured only once.

This is what lets the rebuilt scene collection have no nested scenes at all: the square camera and the
component-layout camera are Cropped Views of the one camera source.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A view carries no sound; the source it shows keeps its own.
- A view is drawn into its own picture first, which costs a little more than drawing the source alone.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
