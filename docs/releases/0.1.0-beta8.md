# StageKit 0.1.0-beta8

Eighth pre-release: one Game Capture for every game, and camera spots as filters on the camera. These
changes pass the automated tests on Linux; **they have not been run in OBS on Windows yet**, and Auto
Capture's game detection can only be proven there.

## What's new

- **Auto Capture (StageKit)**, a filter for a Game Capture source. It finds the game in front by
  itself, windowed or full-screen, and stays on it until the game closes or another game comes to the
  front. There is no list of games to keep.
  - *Never capture* leaves out programs picked up by mistake. OBS, browsers, Discord and similar are
    already left out.
  - *Always capture* is optional, for a game it does not pick up by itself.
- **Send To (StageKit)**, a filter you add to the camera (or any source), once per spot. Choose a
  corner, or drag the camera where you want it and press *Save the item's current spot*. A Stream Deck
  OBS plugin *Filter* key on that filter then moves the camera there. It works in the scene on screen
  or in every scene the camera is in, including inside nested scenes and groups.
- Everything from 0.1.0-beta6, which was not published separately: the automatic trim no longer chases
  black game backgrounds, program rules for picture shape, and the Picture Shape key.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Auto Capture works on Windows only.
- A game that loads neither controller support nor fills its screen is not picked up automatically;
  add it to *Always capture*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
