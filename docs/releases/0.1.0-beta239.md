# StageKit 0.1.0-beta239

Run an on-stream or private timer with duration, calendar and count-up modes.

## New

- **Countdown Timer source and private dock.** Add a transparent timer overlay in Sources, or open Docks > StageKit Timer. Select a scene timer in the dock to control the same clock viewers see.
- **Three timer modes.** Count down for a duration, pick a local date and time from the calendar, or count up from zero with an optional stopping time.
- **Finish actions.** Show a custom end message and optionally switch Program to a scene when the timer finishes.
- **Time display controls.** Choose days, hours, minutes and seconds with a live preview. Set the overlay font and color in its source properties.
