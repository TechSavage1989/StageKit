# StageKit 0.1.0-beta239

Add a countdown timer to an OBS scene and control it manually or start it when the scene goes live.

## New

- **Countdown Timer source.** In Sources, choose **+ > Countdown Timer (StageKit)**. Set the duration, font and text color. The timer holds at zero.
- **Timer controls.** Start, pause and reset each timer from its properties or OBS hotkeys. Enable **Restart when the scene goes live** to start the countdown when its scene enters Program.
