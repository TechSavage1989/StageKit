# StageKit 0.1.0-beta129

One hundred and twenty-ninth pre-release: the fit no longer trails a window switch when the
capture also has a Standby Picture, and Switch Scene keys use your own scene pictures. It passes
the automated tests on Linux; the Windows side has not run in a real OBS here.

## Fixed

- **The fit still trailed the window switch.** Your logs and settings showed why: the Standby
  Picture filter comes after the Automatic Window Switcher on the capture, and it glided the
  capture's size a second time, over its own 800 ms, after each step of the switcher's 250 ms
  change. The size, and with it the fit, arrived long after the switch. With a window switcher on
  the capture, Standby Picture now takes the size as the switcher gives it while the capture is
  live. Its own transition still applies when it stands in for the capture and gives way to it.

## Changed (Stream Deck plugin 0.15.0.0)

- **Switch Scene keys use your scene pictures.** Left on *Automatic*, a key takes the icon pack's
  own picture of that scene's layout when the pack has one by the scene's name (*Game-Capture-Scene*
  gets *game capture*, *Window-Component-Capture-Scene* gets *window component*, and so on), with
  the green dot and red slash as on every key. A scene the pack has no picture for gets the
  generic one; a picture you choose yourself always wins.
