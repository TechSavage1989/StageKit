# StageKit 0.1.0-beta250

Countdown Timer cycle keys now show the selected mark and the clock time the timer is set to.

## Changed

- **Timer deadline on the key.** The Countdown Timer cycle key shows its selected :15, :30, :45 or :00 mark above the saved target time, such as 9:45 PM. The time uses the OBS computer's local 12-hour or 24-hour clock format.

## Fixed

- **Timer setting refresh.** Editing an idle or paused timer's deadline in OBS updates connected cycle keys. Changing back to a duration clears the displayed deadline.

## Good to know

- **Update both plugins.** Install this OBS update and Stream Deck companion 0.42.0.0 to display the target time. An older OBS plugin still shows the selected mark.
- **Existing controls.** Tap to cycle and hold for 0.8 seconds to start or stop. Leave the Stream Deck Title field blank for the automatic two-line label.
