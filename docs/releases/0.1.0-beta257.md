# StageKit 0.1.0-beta257

Choose built-in StageKit icons or custom images for scene shortcuts and view controls.

## New

- **Built-in icon library.** Choose from StageKit's Stream Deck artwork directly in the Views panel editor. Search scenes, sources and controls, browse thumbnails, and select from six color palettes.

## Changed

- **Clear icon choices.** Icon library and Custom image are separate options beside the selected control. Both save a small image with the scene collection for use in the List and Buttons layouts.
- **Scene button instructions.** The guide explains how to select scenes in Edit panel and show them as individual buttons alongside other controls. The Scene dropdown remains available.

## Fixed

- **Icon selection without a separate download.** StageKit includes the library artwork with the OBS plugin, so choosing an icon does not require an installed Stream Deck plugin or locating its image files.

## Good to know

- **Existing panels.** Custom icons, selected controls, scene shortcuts, labels, sections, order and button size are preserved. Choosing an icon changes appearance only.
- **Companion.** The Stream Deck companion remains 0.43.0.0; existing action IDs and key behavior are unchanged.
- **Windows first.** The Windows build, actual OBS frontend and restart checks, and shared release checks must pass on the final release revision before publication.
