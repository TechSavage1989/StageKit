# StageKit 0.1.0-beta263

Morph's other unpaired transitions work again on OBS 32, and the Views editor no longer refuses a save made right after another.

## Fixed

- **Another transition under Unpaired sources plays again.** With Morph's **Unpaired sources** set to another transition (a slide, a swipe, a fade of OBS's own), a source shown with nothing to pair with drew nothing for the whole change and then appeared at once, and a hidden one stayed whole until it was cut. OBS 32 cancels such a transition when it is set to its very start; StageKit no longer does that.
- **Views: an editor opened right after a save keeps working.** Saving in **Edit panel...** or the controller editor and opening it again at once could refuse the next save as "changed meanwhile". The editor now starts from the save you just made.
- **Steadier with scene controllers when scenes are removed.** A scene removed while a scene controller watched it could write into memory the controller no longer owned, which could crash OBS later. The controller now ignores a scene that is going away.

## Good to know

- No settings change. The rest of this release is test fixes for the build checks.
