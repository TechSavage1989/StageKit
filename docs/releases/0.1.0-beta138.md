# StageKit 0.1.0-beta138

One hundred and thirty-eighth pre-release: StageKit can keep OBS's window layout and bring it back
when OBS starts. It passes the automated tests on Linux; the Windows side has not run in a real
OBS here.

## Added

- **Window layout**, in OBS's **Tools** menu under **StageKit**:
  - **Save window layout** stores where every dock is, docked or floating, and how the docks
    share the window.
  - **Restore window layout** brings that back at once.
  - **Restore it when OBS starts** (ticked as it comes): the saved layout is brought back about a
    second and a half after OBS has finished loading, once every plugin's docks are there. OBS
    brings its own layout back earlier, before some docks exist, which is one way a layout gets
    lost at start-up.
  - **Save it when OBS closes** (unticked as it comes): keeps the saved layout up to date by
    itself. Leave it unticked if you want one fixed layout to come back every time.

  Nothing happens until you save a layout once. It is kept in StageKit's own settings folder, not
  in the scene collection, so it is the same for every collection and profile.
