# StageKit 0.1.0-beta126

One hundred and twenty-sixth pre-release: Stream Deck keys show whether they are on or off, and
Blur's *Never blur these* offers every source. It passes the automated tests on Linux; the Stream
Deck plugin has not run on a real Stream Deck here.

## Changed

- **Stream Deck keys show which way they are** (Stream Deck plugin 0.13.0.0). Every key that
  switches something now marks it on its picture: a **green dot** while it is on, the picture
  **dimmed with a red slash** while it is off, in every palette and for every picture you can
  choose. It follows the switch however it is changed: the key, OBS, a hotkey or another key.
  That is every feature key (Blur, Shadow, Zoom, Fit to Space and the rest), *Blur All*, *Dock
  Option* and *Fit to Space Overlap*.
- **No more flash on press.** Stream Deck used to flip a two-state key's picture by itself when it
  was pressed, before StageKit put it right. It no longer does; the key shows only what OBS says.
- **Manual Window / Source shows its state too.** Set to *Toggle*, it is on while a manual window
  is shown; set to *Hide*, it is on while the capture is shown. *Next*, *Return to automatic* and
  *Clear picked windows* keep one picture.

## Fixed

- **Blur: your camera was missing from *Never blur these*.** The list offered only the kinds of
  source StageKit counts as captures. It now offers every source with a picture, *Square Camera*
  and the other Cropped Views included, and a Cropped View listed there also keeps the camera it
  shows clear.
