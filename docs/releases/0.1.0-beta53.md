# StageKit 0.1.0-beta53

Fifty-third pre-release: the tools that place things follow the Arrange options, and another attempt
at *Guides in the preview*. It passes the automated tests on Linux; **it has not been run in OBS on
Windows yet**, and the widget in your screenshots is a browser source, which the tests cannot run.

## Fixed

- **Slide to the next edge went by a widget's box, not its picture**, with *Use visible pixels*
  ticked. Two faults in how a source's own pixels are measured are fixed:
  - a source that draws itself, as a browser source does, was drawn the wrong way for measuring;
  - when that measurement found nothing, the whole box was used. Now everything the item draws is
    used, less its shadow.
- **Guides in the preview**: the line windows were still of a kind Windows can refuse to draw. They
  are now ordinary windows that do not take the keyboard or the mouse's focus.

## Changed

- **The Send to buttons follow the Arrange options.** The nine positions kept the *Edge distance* to
  the item's box. Now it is kept to what the options count as the item: with *Use visible pixels* the
  picture you can see, and with *Ignore shadows & outlines* its shadow reaches past it.
- **Send To and Place Item keys do the same**, so a key and a dock button land in the same place. For
  an item with a shadow or empty room around its picture, **existing keys now land a little
  differently**: the picture, not the box, is the edge distance from the edge. Untick *Use the
  Arrange options* in a filter to go back to the box. Saved spots and spots on the screen are
  unchanged.
- **What a filter takes away is not picture.** With *Ignore shadows & outlines*, edges trimmed by
  Corners & Edges or hidden by a mask no longer count.
- **Ticking Guides in the preview flashes a frame** round the picture in the preview for a moment,
  and the dock says *Guides are on*. If you see neither, they are not working; if the dock says it
  cannot find OBS's preview, that is the reason.
- Each slide writes one line to OBS's log saying what it measured, for when one stops in the wrong
  place.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
