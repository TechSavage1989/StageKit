# StageKit 0.1.0-beta4

Fourth pre-release: fixes for what was reported after trying 0.1.0-beta2 on Windows. These changes pass
the automated tests on Linux; **they have not been run in OBS on Windows yet.**

## What's new

- **The dock works on any scene.** A *Scene* box at the top lets you pick any scene, not only the one on
  screen, so an item that lives in a nested scene can be moved and given keys.
- **Items inside groups** are listed in the dock and in the scene filters, and land in the right place
  on screen when moved or matched.
- **In front of / behind.** The dock has *Bring to front*, *Forward one*, *Back one* and *Send to back*.
- **Layout for chosen items.** A Layout can be limited to the items you list, so several keys can each
  move a different set. Leave the list empty for everything.
- **Fix:** an item that had never been moved since it was added could be measured as a 1×1 box, which
  made Place Item and Match Item size or place it wrongly.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Dragging items and zoom points on a picture in the dock, and mouse-wheel zoom, are not built yet.
- "An item dropped behind others" with Match Item has not been reproduced; the new order buttons are the
  way to put it back.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
