# StageKit 0.1.0-beta57

Fifty-seventh pre-release: a fix aimed at OBS freezing while you move items with guides on. It passes
the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **OBS freezing while an item is moved.** To measure what is visible in an item, StageKit asks OBS's
  drawing side to draw it and waits for the answer. That wait had no limit, and when the drawing side
  was itself waiting for the window, both waited for ever and OBS stopped responding. The wait is now
  at most four tenths of a second. When there is no answer in time:
  - a drag shows no guide lines that once;
  - a slide does not move the item and the dock says *OBS was busy. Press again.*;
  - other tools go by the item's box that once.

## Changed

- The extra line in square brackets after *Guides on* is gone again, now that guides show.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
