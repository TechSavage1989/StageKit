# StageKit 0.1.0-beta33

Thirty-third pre-release: fixes for Shadow, Glow & Outline. It passes the automated tests on
Linux; **it has not been run in OBS on Windows yet.**

## What's fixed

- **An outline made from the picture no longer looks like stacked copies.** It was built from a
  handful of shifted samples, which showed as repeated ghost images on a wide outline. It is now one
  continuous continuation of the picture past its edge.
- **Smoother outline edges** on wide outlines.
- **Copying the filter to another source or group no longer moves it.** The copy carried the first
  source's record of the room already made for its shadow, so the new one was left shifted by that
  much. A copied filter now starts with a clean record. The crash reported with this was not
  reproduced in testing; it may or may not be gone.

## What's new

With *Outline → Made from → The picture itself*:

- **Past the edge**: *Stretch the edge* carries the picture's edge colours straight outwards;
  *Mirror the picture* reflects the picture at each edge.
- **Outline blur**: 0 keeps the continuation sharp; higher numbers melt it into a soft frame of the
  picture's colours. The default is 20 px.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
