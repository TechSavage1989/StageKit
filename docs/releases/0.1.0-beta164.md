# StageKit 0.1.0-beta164

A Stream Deck release: every key can use any image. The OBS plugin is the same as in beta163.

## Changed

- **Any image on any key.** Every key's type list now offers every image there is, after the ones
  that fit the key:
  - a key for a source (Show in Scenes, Shadow, Blur, Move Source, the arrange tools and the rest)
    offers every source type and every scene image, your original scene layouts included, so a
    Show in Scenes key for your start screen can show the *Starting soon* scene image;
  - Switch Scene and the keys for a filter on a scene offer every source type after the scene
    types.

  The types that fit the key are still listed first. Further down come *More: ...* (the other
  source types), *Scenes: ...* (the scene images) or *Sources: ...* (the source types, on scene
  keys).
- **The Corners & Edges key has a Source type list** as well as its Corner style.

Install the Stream Deck plugin again from this release (`StageKit.streamDeckPlugin`); keys keep
their settings.
