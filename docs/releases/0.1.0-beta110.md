# StageKit 0.1.0-beta110

One hundred and tenth pre-release: the Morph transition now morphs in OBS itself. It passes the
automated tests on Linux.

## Fixed

- **Morph (StageKit) only cut from one scene to the next.** The transition asked OBS for its size,
  and OBS's own window never gives a transition one, so it found no size, skipped its drawing and
  switched at the end of its time. It now takes the size of its scenes. The tests gave it a size
  by hand and so did not catch this; they now run it the way OBS does.

## Please check

1. With Morph (StageKit) chosen in *Scene Transitions* and a duration of about 700 ms, switch
   between two scenes that share the camera and the chat box. Do they glide, and does the game
   turn into the window?
2. Say what looks wrong: something that jumps at the start or the end, a shadow that changes size,
   an item that fades when it should move.
