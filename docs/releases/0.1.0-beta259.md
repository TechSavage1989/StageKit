# StageKit 0.1.0-beta259

Your saved dock layout now also puts back docks that appear a few seconds after OBS starts.

## Fixed

- **Docks that appear late go back to their place.** StageKit restored the saved layout once, 1.5 seconds after OBS loaded. A dock added after that, such as the Stream Information dock after your streaming service signs in, or a Quick Access, StageKit Views or StageKit Timer dock, was placed where OBS puts a new dock, and the layout had to be restored by hand. For 30 seconds after each restore, a dock that appears now brings the saved layout back once docks stop appearing.

## Good to know

- The layout is never put back while a mouse button is held, so dragging a dock in those 30 seconds is not undone mid-drag.
- A dock that is not part of the saved layout stays where OBS put it. Save the layout again (**Tools > StageKit > Save window layout**) to include it.
- The OBS log says `Window layout: a dock was added after the layout came back; bringing it back again` each time this happens.
