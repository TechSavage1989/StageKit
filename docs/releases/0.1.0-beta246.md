# StageKit 0.1.0-beta246

Complete the Studio Mode controls for Stream Deck.

## New

- **Preview to Program key.** Add this action from the StageKit list. One press runs OBS's current Studio Mode transition with its current duration and native swap behavior. Studio Mode must be on.

## Improved

- **Studio Mode state images.** One monitor means off; two monitors mean on. Existing keys keep their settings and follow changes made directly in OBS. A chosen Scene type keeps its image with the corresponding monitor badge.
- **Matching image options.** Both keys support the existing image layouts and six palettes. Preview to Program has its own action icon, Source type choices and transition badge.

## Good to know

- **Stream Deck update.** Install the companion plugin from this release, version 0.39.0.0. Existing Studio Mode keys update in place; Preview to Program is a separate action to add.
- **Request feedback.** Preview to Program confirms when OBS accepts the request and shows an alert when Studio Mode is off, OBS is disconnected, or the request is rejected.
