# StageKit 0.1.0-beta160

One hundred and sixtieth pre-release: every Stream Deck key has a type list now, and a key that
does something specific shows both what it acts on and what it does.

## Changed

- **Stream Deck plugin 0.20.1.0: a type list on every key.** Manual Window / Source, Arrange tool,
  Slide to Edge, Dock Option, Set Aspect Ratio, Move Source and Move Scene Item get a **Source type**
  list; Capture Active Window gets one beside its Game / Window choice, and Blur All a **Scene type**
  list beside its Blur style.
- **What the key does shows as a small badge** in its top-right corner when a type is chosen: a
  camera with an arrow to the corner it goes to, a game with a "back to automatic" arrow, a window
  with a skip arrow, a capture with a crossed-out eye for Hide, and so on. Move keys also show, in
  the top-left corner, a linked source coming along or a move made in this scene only. With the list
  on *Automatic* a key looks exactly as before.
- **Move Source and Move Scene Item** offer every place the filter can send a source, now including
  *Spot on the screen*, each with its own drawing. A key set to a spot on the screen is titled
  *Screen Spot* (it said *Saved Spot*).

## Fixed

- **"Ignore shadows & outlines"** showed as "Ignore shadows  outlines" in the filters' settings
  windows: OBS took the "&" for a shortcut marker. It shows the "&" now.

## Not yet tried on a Stream Deck

  icon menu stays over the plugin's.
