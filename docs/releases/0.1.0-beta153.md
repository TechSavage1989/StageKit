# StageKit 0.1.0-beta153

One hundred and fifty-third pre-release: modes inside one scene, so Intermission can join the
holding scene and the GBA layout can join the Component scene. Tested on Linux only.

## Added

- **Link Visibility: Follow the first source.** The first source in the list leads: shown, the
  others come with it; hidden, they go with it, and stay hidden whatever else tries to show them.
  This is what a *mode* of a scene is: a title (or a marker) and what belongs to it.
- **Modes and switches respect each other.** A source shows only when its mode says so and no
  Show in Scenes switch holds it off. Your camera switch brings back only the camera views of the
  mode that is showing, and choosing a mode never shows a camera you switched off.

## Changed

- The StageKit dock's *Background* tab is called **Standby & Ambient**.
- A Standby Image's stand-in (*Show when source is hidden*) does not appear for a source that a
  mode not showing keeps hidden.
