# StageKit 0.1.0-beta6

Sixth pre-release. It fixes Auto Frame resizing the picture over and over on games with black
backgrounds, reported with Snes9x on Windows, and adds two hands-off ways to set a picture's shape.
These changes pass the automated tests on Linux; **they have not been run in OBS on Windows yet.**

## Fixed

- **Auto Frame no longer follows black areas of the game.** A black background looks the same as a black
  bar, so the automatic trim was chasing the artwork. It now trims more only when what would be left is
  exactly one of the shapes games and emulators output (16:9, 16:10, 3:2, 4:3, SNES/NES on a 4:3 screen,
  5:4, 8:7, 10:9, 16:15, 1:1). A dark scene leaves an arbitrary shape and is ignored. It still lets go
  quickly when the picture grows.

## What's new

- **Programs with a known picture shape.** In Auto Frame, add lines such as `snes9x = 4:3` or
  `mesen = 16:15`. When the captured program's name or window title contains the text, that shape is
  used at once, with nothing to detect and nothing to press.
- **Picture Shape key (StageKit)**, a small filter to add next to Auto Frame, once per shape. Switching
  it on tells Auto Frame the picture's shape and it switches itself off again, so a Stream Deck OBS
  plugin *Filter* key or a hotkey can set 4:3, SNES, 3:2 and so on. A key set to *Automatic* hands
  control back.
- **Trim to what is on screen now**, a button in Auto Frame that measures once and stores a fixed trim.

Order of precedence: a set trim amount, then a Picture Shape key, then a program rule, then automatic
detection.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Program rules rely on the capture source reporting what it is attached to. That has only been tested
  here with a stand-in; whether Game Capture and Window Capture report it on Windows is unverified.
- Automatic detection will not trim a picture whose shape is not in the list above; use a rule or a key.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
