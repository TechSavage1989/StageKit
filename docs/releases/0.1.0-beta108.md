# StageKit 0.1.0-beta108

One hundred and eighth pre-release: the Morph scene transition. It passes the automated tests on
Linux; it has not run on Windows before this release.

## New

- **Morph (StageKit)**, a scene transition. Add it in OBS's *Scene Transitions* box (the plus,
  then *Morph (StageKit)*) and set its duration there.
  - Everything that shows the **same source in both scenes** (the camera, the chat box, a widget,
    the background) glides from its place, size and crop in the scene you leave to its place, size
    and crop in the scene you go to.
  - **Morph the main picture** (ticked as it comes): the largest item left over in each scene,
    such as a game capture in one and a window capture in the other, changes from the one into the
    other while it moves and resizes.
  - **Other items**, which are in only one of the scenes, fade, fade and zoom, or slide off the
    nearest edge. Backgrounds always cross-fade.
  - **Easing**: the same curves as everywhere else.

## Good to know

- Items are matched by source. Two different sources that look alike are cross-faded, unless they
  are the two main pictures.
- A scene with a filter that draws on the scene itself (a blur, a colour correction) is
  cross-faded as a whole, and OBS's log says which filter it was.

## Please check

1. Set Morph as the transition and switch between two of your scenes that share the camera and the
   chat box. Do they glide, and does the game turn into the window?
2. Say what looks wrong: something that jumps at the start or the end, a shadow that changes size,
   an item that fades when it should move.
3. If it only cross-fades, send the OBS log (Help, Log Files, Upload Current Log File).
