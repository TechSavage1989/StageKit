# StageKit 0.1.0-beta27

Twenty-seventh pre-release: the line-up tools work from anywhere, and the background has a dock of its
own. It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's changed

- **Right-click in OBS's preview** now has a *StageKit* menu with every line-up, spacing, resizing and
  snapping tool and their options. OBS has no official way to add to that menu, so this is the part
  most in need of a check on Windows.
- **Hotkeys for every tool.** *Settings → Hotkeys*, the entries that start with *StageKit:*.
- **One set of options everywhere.** *Use visible pixels*, *Ignore shadows*, *Align to*, *Snap on
  release* and the new *Keep shape when resizing* are shared by the menu, the hotkeys and the dock,
  and are saved with the scene collection.
- **Resizing can stretch.** *Same width*, *Same height* and the new *Same size* keep an item's
  proportions by default. With *Keep shape when resizing* off they change only the direction asked for.
- **The Arrange box says what it will move**, for example *Moves: Camera + 2 more*, and tells you when
  a tool needs more items selected. Every button has a tooltip saying what it does.
- **StageKit Background** is a new dock (under *Docks*) holding the start image and the background
  buttons. The StageKit dock keeps the item tools.
- **The start image thumbnail** now also reads pictures in formats OBS can load but its window toolkit
  cannot (WebP, AVIF, TGA and others), and tries again if the file could not be read at start-up.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.
The new dock is switched on under *Docks → StageKit Background*.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
