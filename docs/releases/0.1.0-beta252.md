# StageKit 0.1.0-beta252

StageKit limits shadow-reuse preparation to the redraws that can benefit from it.

## Fixed

- **Shadow rendering overhead.** Ordinary shadows, Morph transitions and ineligible blur redraws avoid the extra preparation tracking introduced in beta251. Eligible per-source Scene Blur redraws keep their shadow and glow reuse.

## Good to know

- **Same appearance and controls.** Shadow quality, transitions, settings and the countdown cycle-key deadline display are preserved. The Stream Deck companion remains 0.42.0.0.
- **Windows frame time.** This removes unnecessary work found while investigating a reported increase. Its effect on a particular Windows setup still needs to be measured there.
