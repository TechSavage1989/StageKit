# StageKit 0.1.0-beta32

Thirty-second pre-release: a fix for the moving background. It passes the automated tests on Linux;
**it has not been run in OBS on Windows yet.**

## What's fixed

- **No black background when the capture has nothing to show.** With *Live capture replaces the
  picture* on, a Game Capture that had not caught a game left the background black. Ambient Background
  now looks at the capture twice a second:
  - nothing drawn at all: the start image (or the background's own picture) shows at once;
  - a picture that is black all over for two seconds: the same. The two seconds keep a game's brief
    cut to black from flashing the start image in;
  - the moment the capture shows anything, it takes over again.

The same applies when the capture is blended in rather than replacing the picture.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
