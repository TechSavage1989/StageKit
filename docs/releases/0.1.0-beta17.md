# StageKit 0.1.0-beta17

Seventeenth pre-release: the program trigger. It passes the automated tests on Linux; **it has not been
run in OBS on Windows yet**, and its Windows-only code can only be proven there.

## What's new

- **Program Trigger (StageKit)**, a filter for a scene or a source. While a program is open it shows the
  items you chose and switches on the filters you chose; when the program goes, it hides them and
  switches them off.
  - Choose the program from the open ones or find its file. A window title can be required too, or used
    alone (for example `GBA1`).
  - It can count a program whenever its window is open, or only while that window is in front.
  - *Do the opposite* hides and switches off while the program is here.
  - It acts when the program appears or goes, so a change made by hand in between is kept.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Windows only. A minimised window does not count as open.
- It cannot react to sound, so "hide the music widget when Spotify is silent" is not covered.
- On a scene it switches that scene's items; on a source it switches that source's filters.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
