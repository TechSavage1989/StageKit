# StageKit 0.1.0-beta204

A capture hooked by hand goes back to Auto Capture once the hooked program closes.

## Changed

- **A hook by hand hands the capture back when the program closes.** *Capture Active Window* still switches the capture's Auto Capture off so it stays on the window you picked; once that program has closed, Auto Capture switches itself on again and follows games, also after OBS is restarted. An Auto Capture you switched off yourself stays off.

## Good to know

- **Not yet seen on Windows.** The tests drive it with stand-in windows.
