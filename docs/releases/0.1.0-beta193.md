# StageKit 0.1.0-beta193

The Automatic Window Switcher can show only an emulator's game, its menus and tool bars left out.

## New

- **Game area only, on the Automatic Window Switcher.** Tick it and only the part of the window
  the app draws its game in is shown: an emulator's menu bar, tool bar and status bar are left
  out, with nothing to crop by hand. It is found by itself for every window the switcher
  captures, and followed when it changes: the size glides to the new one, and a menu that opens
  for a moment changes nothing. Switching to another app glides once to that app's game area.
  It needs Window Capture's *Client area* ticked. Where an app has no separate game area the
  window is shown whole, and so is a web browser, tabs and address bar included. A window you
  resize or maximise keeps its game area, and a game area that changes is followed by Fit to
  Space in the same glide. Unticking it glides back to the whole window.
- **The log says what was found.** For each program, OBS's log has a line such as *game area of
  Ryujinx.exe: child ..., 1280x720 at 0,24 in a 1280x768 client*, or *no game area found in
  ...: shown whole*.

## Unchanged

- *Game area only* is off as it comes: captures you have already set up look as before.
- Nothing is written to your scene items or the capture's own settings.

## Good to know

- Not yet seen on real emulators or on Windows: if an emulator is still shown whole or cut in
  the wrong place, please send OBS's log; the line above says what was found.
