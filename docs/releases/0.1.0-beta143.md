# StageKit 0.1.0-beta143

One hundred and forty-third pre-release: a crash when OBS starts. Tested on Linux only; the crash
was in another plugin on Windows and could not be reproduced here.

## Fixed

- **OBS crashed while starting, with *Show when source is hidden* ticked on a Standby Image
  filter and the Quick Access Utility plugin installed.** The crash was inside that plugin as
  it went through the scenes while OBS loaded them. StageKit was adding its standby items to
  the scenes during loading, and those items show a source other plugins are not told about.
  StageKit now waits until OBS has finished loading, plus two seconds, before it adds them.
