# StageKit 0.1.0-beta231

Saved layouts remember their framing, scene rules follow renames, and capture filters gain separate show and hide transitions.

## New

- **Save the whole layout.** Apply Layout now saves bounds, alignment and crop alongside position, scale and rotation. Earlier layouts continue to move items using their existing framing.
- **Choose how captures appear and disappear.** Program Trigger and Automatic Source Switcher can use a different transition for each listed source. Auto Capture and Automatic Window Switcher offer the same show and hide settings for the capture itself.
- **Control the scene directly.** Scene Shadow has a button and three scene hotkeys. Automatic Source Switcher has buttons for manual and automatic control and can lock hidden captures.

## Changed

- **Keep older controls working.** Move Source is the choice for a new move. Existing Move Scene Item filters, hotkeys and Stream Deck keys continue to work.
- **Choose coverage in Scene Corners.** Select all or chosen sources. Full-screen = background controls whether a background gets corners. Saved filters keep their coverage.
- **Remember switch defaults.** New Show in Scenes switches restore only what they hid. New Automatic Source Switchers start at 300 ms. Saved switches retain their earlier behavior.

## Fixed

- **Keep references after renaming.** Cropped View, Ambient Background, Morph links and rules, and source-specific transition settings follow the source or scene's new name.
- **Save edits to existing Morph rules.** Changes to an existing pair save immediately. Add this rule creates a new pair.
