# StageKit 0.1.0-beta24

Twenty-fourth pre-release: tools for lining items up. It passes the automated tests on Linux; **it has
not been run in OBS on Windows yet.**

## What's new

A **Line up, space out, snap** box in the StageKit dock. Select one or more items in OBS's preview
(Ctrl-click for several) and:

- **Line up**: left, centre, right, top, middle or bottom, with the screen or with each other.
- **Space out**: equal gaps between three or more items, across or down.
- **Same width / Same height**: resize the others to match the top-most selected item, keeping their
  shape.
- **Snap now**: move each item the last few pixels so an edge or centre meets the screen's or another
  item's.
- **Snap when I let go of an item**: the same, by itself, after you drag an item in the preview.
- **Go by what is visible** (on by default): everything above measures the picture actually drawn in
  each item and ignores the empty, see-through room around it. OBS itself only knows an item's box.
  *Leave shadows out* keeps a Shadow & Backdrop's shadow from counting as picture.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Snapping happens after you let go, not while you drag: OBS's own dragging cannot be changed by a
  plugin. It does not snap while you resize an item by its handles.
- No guide lines are drawn in the preview.
- Rotated items are lined up by their outer extent.
- A change made by these buttons is not on OBS's undo list.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
