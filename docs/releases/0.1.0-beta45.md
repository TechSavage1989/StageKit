# StageKit 0.1.0-beta45

Forty-fifth pre-release: a window you resize stays fitted in real time. It passes the automated tests
on Linux; **it has not been run in OBS on Windows yet.**

## What's changed in Fit Item

- **Nothing lags behind a window being resized.** Fit Item used to work out the picture's size itself
  and hand OBS a box of exactly that size, one frame after the picture had changed. It now hands OBS
  the *space* the picture may take, and OBS fits the picture into that space on every frame it draws.
  Drag a captured window larger or smaller and it grows and shrinks on stream as you drag, centred, the
  way a plain OBS bounding box does.
- A shadow on the source is still allowed for: the picture is what sits centred in the space, with the
  shadow outside it.
- Fit Item works on any source. A Window Capture needs no Auto Frame: add Fit Item to the scene and
  choose the window capture as the item.

A picture with the space's own shape still fills it, and any other shape still keeps the margin. The
one moment Fit Item has to step in is when a picture crosses from one of those to the other.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.
Fit Item filters you already have keep their settings.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
