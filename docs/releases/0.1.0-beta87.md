# StageKit 0.1.0-beta87

Eighty-seventh pre-release: clearer names in the OBS plugin and the Stream Deck plugin. Nothing
works differently, and everything you have already set up keeps working; a filter already on a
source keeps the name it has.

## Renamed

| Before | Now |
| --- | --- |
| Ramp Blur | Blur |
| Ramp Zoom | Zoom |
| Send To | Move Source |
| Place Item | Move Scene Item |
| Layout | Apply Layout |
| Fit Item | Fit to Space |
| Active App | Follow Active App |
| Visibility Link | Link Visibility |
| Picture Shape key | Aspect Ratio Preset |
| Picture shape (Stream Deck key) | Set Aspect Ratio |
| Hook capture (key) | Capture Front Window |
| Window switch (key) | Next Manual Capture |
| Dock switch (key) | Dock Option |
| Slide to next edge (key) | Slide to Edge |
| Blur everything (key) | Blur All |

In the keys' settings: *Keep ratio* (*This game only*, *Until changed*) and, for *Next Manual
Capture*, *Next capture* and *Back to automatic*.
