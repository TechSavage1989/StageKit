# StageKit 0.1.0-beta84

Eighty-fourth pre-release: a Stream Deck key for each feature, picture shapes by hand, and a hook
that changes over with a transition. It changes **both** the OBS plugin and the Stream Deck plugin.
It passes the automated tests on Linux; **none of it has run on Windows or on a Stream Deck yet.**

## Changed in the Stream Deck plugin

- **One key per feature** instead of one *Filter switch* for everything: Ramp Blur, Shadow, Glow &
  Outline, Corners & Edges, Ramp Zoom, Auto Capture, Auto Frame, Standby Picture, Show in Scenes,
  Fit Item, Active App, Program Trigger, Visibility Link, Show/Hide Animation, and for the moves
  Send To, Place Item and Layout.
- **One list per key** instead of *Source* then *Filter*: it holds only what that key is for, by the
  source's name (with the filter's name where a source has more than one).
- Keys you already made with *Filter switch* and *Move* keep working. Those two are no longer in the
  list of keys.

## New

- **Picture shape** key: sets a game's shape by hand, 4:3, 8:7, 3:2, 10:9, 16:9, 16:10, 5:4, 1:1 or
  64:49, or *Automatic* to hand it back to Auto Frame. *Keep it* is *For this game* as it comes: the
  shape stays while that game is captured and goes back to automatic when it ends. Set before the
  game has started, it waits for it. *Until I change it* keeps it for good. The key shows its shape.
- **Hook capture** has *Change with* and *Lasting*: the capture fades out, takes the new window or
  game, and fades back in. A fade over 300 ms as it comes; a cut or any other transition OBS has can
  be chosen.
- **Window switch** key, for a scene with an Active App filter: on to the next of its *Captures you
  switch to*, or back to following the apps.

## Please check

1. Install the OBS plugin (this is the last time by hand if you have beta83: its *Update* button
   should offer this release) and the Stream Deck file.
2. Do the new keys appear, one per feature, and does each list show only its own filters?
3. *Picture shape*: set 4:3 on a game, then close the game: does the next game start on automatic?
4. *Hook capture*: does the capture fade out and back in on the new window?
