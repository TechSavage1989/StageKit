# StageKit 0.1.0-beta16

Sixteenth pre-release: linked visibility. It passes the automated tests on Linux; **it has not been run
in OBS on Windows yet.**

## What's new

- **Visibility Link (StageKit)**, a filter you add to a scene, once per set of items.
  - *Show only one at a time*: showing one item hides the others in the set.
  - *Show and hide together*: showing or hiding one does the same to the rest.
  - Items are picked from a list of the scene's items. It follows the eye icon, Stream Deck *Source*
    keys, hotkeys and anything else that shows or hides an item.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- It reacts to items directly in the scene. An item inside a group can be switched by it, but showing
  or hiding that item does not set the others off.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
