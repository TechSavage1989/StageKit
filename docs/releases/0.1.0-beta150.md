# StageKit 0.1.0-beta150

One hundred and fiftieth pre-release: Stream Deck keys you can read when they are off, all in one
style. Only the Stream Deck plugin changes (0.17.2.0); install it again from this release.

## Changed

- **Off keys are readable.** The picture stays almost as bright as when the key is on, and a red
  "no" sign sits in the corner where an on key has its green dot. Before, the picture was darkened
  and crossed by a red slash, and the key could not be told apart without a title.
- **Every key in one style.** The arrange tool, copy, snap, guides, slide, camera position, Capture
  Active Window and unset keys now use the same framed screen with a drawing in it as the other
  keys. A picture you chose by hand for a key still shows as before.
