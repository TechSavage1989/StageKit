# StageKit 0.1.0-beta42

Forty-second pre-release: the live background is there at once. It passes the automated tests on
Linux; **it has not been run in OBS on Windows yet, and this change could not be tested here** (the
test machine has no capture sources).

## What's changed in Ambient Background

- **Keep the capture ready** (new, on by default). Switching from a scene with no live background to
  one with it used to wait while the capture started up again, because OBS stops a capture that no
  scene on screen is showing. With *Blend in live capture* on *Automatic*, the background now keeps
  the capture it last used running, out of sight, in scenes that do not show it. If it has not used
  one yet, it keeps the largest capture in any scene ready.
- **It follows a scene change within a tenth of a second** instead of up to half a second.

Untick *Keep the capture ready* if you would rather the capture stopped when it is not on screen.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
