# StageKit 0.1.0-beta136

One hundred and thirty-sixth pre-release: a Window Capture keeps hold of a window whose title
changes. It passes the automated tests on Linux; the Windows side has not run in a real OBS here.

## Added

- **A window named by part of its title is followed when the rest of its title changes.** In an
  Automatic Window Switcher, an entry can be part of a window's title. Until now the capture was
  aimed by the whole title and lost the window as soon as the title changed. It is now aimed
  again at once. Dolphin's Game Boy Advance windows are the case in point: *GBA1 | Volume 100%*
  becomes *GBA1 | Muted* when you mute it, which is why the old scene needed two captures for each
  window.
- **The lists offer the first part of a title.** Besides the open programs and the whole titles,
  *Windows to switch between* and *Manual windows* now offer the first part of a title that has
  several (*GBA1* of *GBA1 | Volume 100%*): the part that stays the same.

## Two windows of one program in one scene

One Window Capture can only ever show one window, so use one capture for each:

1. Add two Window Captures to the scene, for instance *GBA 1* and *GBA 2*.
2. Give each an **Automatic Window Switcher** filter.
3. In the first, under *Windows to switch between*, choose **GBA1**; in the second, **GBA2**.

Each capture then holds its own window through every change of title, and each can be placed,
sized and given its own shadow and corners like any other source. That replaces the four captures
(two for each window, one per title) of the old scene.
