# StageKit 0.1.0-beta136

One hundred and thirty-sixth pre-release: a Window Capture finds a window again after its title
has changed, and the window switcher gets a list of ignored windows. It passes the automated tests
on Linux; the Windows side has not run in a real OBS here.

## Added

- **A window named by part of its title is found again after its title has changed.** In an
  Automatic Window Switcher, an entry can be part of a window's title. The capture is aimed by the
  whole title, so once it had to look for the window again (OBS starting, or the window being
  reopened) it could not find it under a different title. It is now aimed at the window again as
  soon as it has no image and the title differs. Dolphin's Game Boy Advance windows are the case
  in point: *GBA1 | Volume 100%* is *GBA1 | Muted* when muted, which is why the old scene needed
  two captures for each window. A capture that still holds its window is left alone, so a window
  whose title changes all the time (a frame rate in it) is not disturbed.
- **Ignored windows.** A new list in the Automatic Window Switcher: windows the capture never
  takes, whatever they match in the other lists, by program or by part of a title. Use it when a
  short entry matches a window you do not want.
- **The lists offer the first part of a title.** Besides the open programs and the whole titles,
  *Windows to switch between* and *Manual windows* now offer the first part of a title that has
  several (*GBA1* of *GBA1 | Volume 100%*): the part that stays the same.

## Two windows of one program in one scene

One Window Capture can only ever show one window, so use one capture for each:

1. Add two Window Captures to the scene, for instance *GBA 1* and *GBA 2*.
2. Give each an **Automatic Window Switcher** filter.
3. In the first, under *Windows to switch between*, choose **GBA1**; in the second, **GBA2**.

Each capture then finds its own window whatever its title says at the time, and each can be placed,
sized and given its own shadow and corners like any other source. That replaces the four captures
(two for each window, one per title) of the old scene.
