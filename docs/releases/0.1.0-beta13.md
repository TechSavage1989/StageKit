# StageKit 0.1.0-beta13

Thirteenth pre-release. These changes pass the automated tests on Linux; **they have not been run in
OBS on Windows yet.**

## What's new

- **A picture of the scene in the dock.** Click an item to select it and drag it to move it. Turn the
  mouse wheel to make it bigger or smaller. If it has a Ramp Zoom, drag the yellow cross to set where it
  zooms in, and hold Ctrl while turning the wheel to set how far. *Show the live picture* can be
  unticked to show outlines only.

## What's fixed

- **The dock scrolls.** It no longer forces its window to be as tall as everything in it.
- **Snes9x's picture shape is 8:7**, not the near-4:3 shape the last version assumed, which cut into the
  picture.
- **Known emulator shapes are now only a starting point.** If the picture clearly shows another shape,
  that shape is used. A shape you saved yourself is still obeyed as it is.
- **No blink when switching between a window and full-screen.** The last good picture stays up for a
  fifth of a second while the capture settles at its new size, and for up to a second if the capture
  drops out. The picture no longer slides for a moment when its shape has not changed.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Moves made in the dock's picture cannot be undone with Ctrl+Z.
- The live picture is redrawn about four times a second, so it trails the real preview slightly.
- Rotated items are shown and dragged by their outer box.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
