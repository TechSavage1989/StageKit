# StageKit 0.1.0-beta1

First pre-release. Everything here has passed automated tests on Linux, but **nothing has been run in
OBS on Windows or macOS yet**. Treat it as a test build and try it on a copy of your scene collection.

## What's in it

- **Ramp Blur**: blurs a source in and out smoothly, with six blur types and a Blur All hotkey.
- **Ambient Background**: a soft, drifting backdrop from an image or another source, optionally tinted
  by the live capture.
- **Shadow & Backdrop**: drop shadow, a panel behind the source and rounded corners, with no wrapper
  scene.
- **Ramp Zoom**: zooms smoothly into a point of a source and back out.
- **Place Item**: sends an item to one of nine screen positions or a saved spot, and can bring a linked
  item along.
- **Show/Hide Animation**: slides or pops an item in and out when it is shown or hidden.
- **Match Item**: keeps an item lined up with an item in another scene.
- **Layout**: saves an arrangement of a scene's items and glides back to it.
- **StageKit dock**: click an item into place and make Stream Deck keys for its positions.

The ramp and move tools are triggered by switching a filter on or off, so they work with the Stream Deck
OBS Studio plugin's Filter and Source keys, and with hotkeys.

## Installing on Windows

1. Close OBS.
2. Unzip the `windows-x64` zip and copy the `stagekit` folder into
   `C:\ProgramData\obs-studio\plugins\`.
3. Start OBS (31 or newer).

## Known limits

- Shaders are only proven on OpenGL. If a StageKit filter shows a blank or unchanged picture on Windows,
  look for `stagekit` in *Help → Log Files → View Current Log* and report it.
- The macOS and Windows packages are not signed by a publisher.
- Scene filters do not list items inside groups.
- No in-app update check: update by replacing the plugin folder.
