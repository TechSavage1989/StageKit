# StageKit 0.1.0-beta72

Seventy-second pre-release: filters measure by their own settings, not the dock's. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet.**

## Changed

- **Fit Item, Place Item and Send To have their own "Use visible pixels" and "Ignore shadows &
  outlines".** They replace *Measure by Arrange options* and *Use the Arrange options*, which took
  whatever the StageKit dock happened to be set to. Each filter now keeps its own two settings, and
  changing the dock's Arrange options no longer changes what a filter does.
  - Both are ticked as they come, in every filter you already have.
  - A filter where the old box was unticked goes by boxes, as before.
  - The dock's own *Send to* buttons still follow the dock's options.
- The explanations on these tick boxes are on several lines, so they no longer run off the screen.

## Please check

1. In Fit Item, untick *Ignore shadows & outlines*: the game's shadow should keep the gap too.
   Change the same option in the dock: the filter should not react.
