# StageKit 0.1.0-beta249

Choose whether Auto Frame keys remember an aspect ratio for an application or a specific window name.

## New

- **Remember by application or window.** Remember Aspect Ratio and Measure and Remember now offer Application and Window name. Window name is the default, allowing games in one emulator to keep separate aspect ratios.
- **Window rules override app defaults.** A saved window title applies within its application and takes priority over that application's saved ratio. Both kinds of rule remain visible and removable in Auto Frame.

## Changed

- **Full window names are preserved.** Scoped rules keep the complete captured identity, including punctuation. Reopening the same title in the same application reuses the saved rule.

## Good to know

- **Update both plugins.** Install the StageKit OBS update and Stream Deck companion 0.41.0.0. The saving keys check that OBS supports the selected scope before saving. Existing saved rules remain available, and Measure Bars continues to measure without saving.
- **Window titles identify games.** Window name works when the application gives different games different titles. A renamed title needs its own saved rule.
