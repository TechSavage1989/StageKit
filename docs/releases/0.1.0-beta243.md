# StageKit 0.1.0-beta243

Choose the timer box once and use it with different durations or Stream Deck shortcuts.

- Set **Box size (W × H)** in Timer settings or edit **Box width** and **Box height** in source properties. The on-stream clock keeps the pixel size chosen under **Font**.
- Select the timer and use the existing nine squares in **StageKit > Place** to align the text inside the box. Timer settings offers the same grid. The ending message fits the box at that position.
- OBS **Edit Transform** moves and scales the complete timer source. **Fit to Space** reserves the entire rectangle, including when **Use visible pixels** is enabled.
- Set **Dock text size** for a fixed private readout. Longer running formats may need a wider box or a smaller font.
