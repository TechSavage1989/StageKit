# StageKit 0.1.0-beta243

Set a fixed countdown box and use the Place dock to align the clock and its ending message.

## New

- **Timer box.** Set the width and height under Timer settings or in the source properties. Choose the running text size under Font in the source properties.
- **Text alignment.** Select a timer and click one of the nine squares on the StageKit dock's Place tab. The ending message fits the same box at the selected position. The timer settings include the same grid.
- **Dock text size.** Set a fixed size for the operator readout, or let the readout size its clock to the dock.

## Changed

- **Fit to Space.** Placement uses the full timer rectangle, including transparent space. OBS Edit Transform moves and scales the whole rectangle.

## Fixed

- **Countdown size across presets.** Five-minute and forty-five-minute presets draw the same remaining time at the same size and position. Setting a new duration or using a Stream Deck clock shortcut keeps the saved box dimensions.

## Good to know

- **Long running text.** Widen the box or reduce the source font when a running format reaches the edge. The ending message automatically scales and wraps.
