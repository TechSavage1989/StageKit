# StageKit 0.1.0-beta166

A Stream Deck release: every key can show its image in a layout. The OBS plugin is the same as in
beta165.

## New

- **Layout list on every key.** Keys with a *Source type* or *Scene type* list now have a
  *Layout* list just above it. Choose the layout first, then the type:
  - *Automatic*: the image the key had before. Keys you already have look the same.
  - *Standalone*: the type's image by itself. A scene type that is a layout already (Gameplay,
    Capture card, Window / app, with or without chat) shows just its drawing.
  - *Live (no chat)*: the type in the icon pack's live layout, with the hexagon frame and a small
    camera in the corner.
  - *Live + chat*: the type in the layout with a camera and chat column on the right.

  Every layout image uses the same template, with the camera in the same place; only the drawing
  in the panel changes. Every type has its own pair, in all six palettes. An image with no drawing
  of its own, such as the standby image, is shown smaller inside the layout. Corner badges and the
  on/off dot stay on top.

## Changed

- **Every key drawing is centred** in its frame. Before, the drawings sat a little to the left.
  This applies to all drawn key images and corner badges, not only the new layouts.
- **No program logos or letters on the types.** The 3D app, Sculpting app and CAD app types now
  show a wireframe cube, a bust with a sculpting tool, and a set square with a ruler. A key where
  you picked one of the old app images by hand keeps it.

Install the Stream Deck plugin again from this release (`StageKit.streamDeckPlugin`); keys keep
their settings.
