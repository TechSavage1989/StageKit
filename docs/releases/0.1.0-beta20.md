# StageKit 0.1.0-beta20

Twentieth pre-release: the dock, redone to what the owner asked for. It passes the automated tests on
Linux; **it has not been run in OBS on Windows yet.**

## What's changed

- **The live picture of the scene is gone from the dock.** Select an item in OBS's own preview and the
  dock works on that item.
- **Dock keys are filters on the item itself.** *Make keys for all nine positions* and *Save its current
  spot as a key* now add Send To filters to the item's own source, such as your camera, named after
  the position. A Stream Deck OBS plugin *Filter* key on the camera and one of those filters moves it.
- **The start image thumbnail controls the moving background.** Turn the mouse wheel on the thumbnail to
  zoom the background in, drag to choose the part shown, double-click to reset. It is one setting for
  the whole collection and is saved with it.
- **The background can have a picture of its own**, chosen in the dock, or go back to the start image.
  *Background settings…* opens the Ambient Background's other settings.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Keys made by an earlier version stay where they are, as Place Item filters on the scene. They still
  work; delete them if you remake the keys.
- The zoom and the part shown apply to backgrounds set to *The start image*.
- *Background settings…* opens the first Ambient Background in the collection.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
