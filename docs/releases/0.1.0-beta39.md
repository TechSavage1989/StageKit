# StageKit 0.1.0-beta39

Thirty-ninth pre-release: one game capture for every scene and every picture shape. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Auto Frame → Frame → Just the picture.** Instead of a frame of a fixed size with the picture
  fitted inside, the source becomes the trimmed game picture and nothing else. The scene then decides
  where it goes, so the same source can be used differently in different scenes.
- **Fit Item (StageKit)**, a new filter for a scene. Choose the item and where it should fit: the
  whole screen, or a box you set.
  - A picture with that box's shape **fills it**: a widescreen game fills a widescreen scene.
  - Any other shape, such as an emulator's squarer picture, **floats centred** inside the *Margin
    for other shapes*.
  - A shadow on the source is allowed for: the picture is what gets centred.

## Setting it up for the full-screen and the component game scenes

1. On **Game Capture Framed**, open *Filters → Auto Frame* and set *Frame* to *Just the picture*.
2. On **Game-Capture-Scene** (right-click the scene → *Filters*), add *Fit Item*, choose *Game Capture
   Framed*, leave *Fit it in* on *The whole screen* and set the margin you like (your example is
   about 90 px).
3. On **Game-Component-Capture-Scene**, add *Fit Item*, choose *Game Capture Framed*, set *Fit it in*
   to *A box I set* and enter the game box: left 30, top 86, width 1754, height 1268. Set the margin
   to 0 so every shape fits the box edge to edge.

Fit Item takes over that item's position and size. Switch the filter off to move the item by hand.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Fit Item places the item at once; it does not glide when the picture's shape changes.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
