# StageKit 0.1.0-beta78

Seventy-eighth pre-release: the first step of a Stream Deck plugin. The OBS plugin itself is
unchanged from beta77. **The Stream Deck plugin has not been run on a real Stream Deck yet.**

## New

- **A Stream Deck plugin**, as its own file on this page:
  `stagekit-0.1.0-streamdeck.streamDeckPlugin`. Double-click it to install (Stream Deck 7.1 or
  later). Its keys appear under **StageKit**.
  - **Filter switch**: switches one StageKit filter on and off, and the key shows which way it is,
    also when the filter is switched some other way.
  - **Move**: runs a Send To key, a Place Item, a Layout or a Picture Shape key.
  - You choose the source and the filter from lists that hold only StageKit's filters.
- It talks to OBS through OBS's own WebSocket server. Set it up once: in OBS, *Tools → WebSocket
  Server Settings*, tick *Enable WebSocket server*, press *Show Connect Info*; in Stream Deck, open
  **OBS connection** at the bottom of any StageKit key's settings and fill in the port and password.
- Elgato's OBS Studio plugin and your existing keys are not touched and keep working.
