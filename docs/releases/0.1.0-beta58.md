# StageKit 0.1.0-beta58

Fifty-eighth pre-release: StageKit stops cleanly when OBS closes. It passes the automated tests on
Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **A possible cause of OBS freezing when you close it.** StageKit's docks, guides and snap watcher
  kept running while OBS was closing down and taking its scenes apart, still asking about scenes and
  measuring items. They now stop the moment OBS starts to close. Whether this was the cause of your
  freezes is not confirmed: no log of a frozen close has been seen.

## Good to know

- Other things can freeze OBS on close and are outside StageKit: a media source that reads a network
  camera and keeps losing it, and other plugins.
- StageKit writes a line to OBS's log when its part of closing is done, so a log from a frozen close
  shows whether StageKit was involved.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
