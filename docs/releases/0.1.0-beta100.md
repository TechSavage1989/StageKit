# StageKit 0.1.0-beta100

One hundredth pre-release: a fix for a camera that changed size by itself. It passes the automated
tests on Linux.

## Fixed

- **Fit to Space with *Resize it to fit* unticked: an item got a little smaller each time it was
  hidden and shown again.** The filter was re-reading "the size to keep" from the item at moments
  when the item was not at its real size. It now re-reads that size on three occasions only: when
  you give the filter another item, when you untick *Resize it to fit* (it then takes the size the
  item had before the filter), and after you resize the item by hand in the preview, which only
  counts while the item is selected and showing.

## Not proven

This could not be reproduced in the tests, so the fix closes every way the size could be re-read
by mistake rather than one known cause. If the camera still changes size, the filter now writes a
line to OBS's log each time the kept size changes, with the reason: please send the log (Help, Log
Files, Upload Current Log File).

## For an item that has already shrunk

Tick *Resize it to fit* and untick it again: the item goes back to the size it had before the
filter. Or, with it unticked, drag the item to the size you want in the preview.

2. Put the camera back to its size, then hide and show it several times. Does it stay the same
