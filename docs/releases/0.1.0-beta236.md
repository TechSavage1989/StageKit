# StageKit 0.1.0-beta236

Show in Scenes now follows a camera item's assigned show and hide transitions when its scene has no rule for that item.

## Fixed

- The Show in Scenes key and filter switch use the item's configured Morph or Make Room movement and duration when set to **As the scene sets** and no scene rule covers it. A press applies only the direction being played.
- **Show only what it hid** restores eligible items using their show transitions. Sources already hidden before the press stay hidden.

## Existing settings

- An explicit transition under **Settings for** still takes priority unless the scene has **Override other filters** enabled. Choose **Keep each source's own** to use the transition the Sources eye plays.
