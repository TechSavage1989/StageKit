# StageKit 0.1.0-beta258

Fit more StageKit Views controls into the dock with compact image-only buttons.

## New

- **Image-only buttons.** Select **Buttons**, then check **Image only** to display square, Stream Deck-style controls. Icons are centered and use most of the button instead of sharing the space with a label. Buttons without assigned artwork show short initials; their full names remain available on hover.
- **Compact sizes.** The **Button size** slider now starts at 24 pixels, close to the compact List row height, and still extends to 112 pixels. The grid fits as many image-only buttons across the available dock width as possible.

## Fixed

- **Icon visibility.** Image-only icons scale with the tile, including at the largest sizes, rather than staying limited to half the button size.
- **Dense layout.** Square buttons retain their bounds without clipping, overcrowding section borders or adding horizontal scrolling.

## Good to know

- The original labeled button layout is unchanged until **Image only** is enabled.
- The selected size and Image only setting are saved per scene collection. Switching between List and Buttons does not erase them.
- Existing controls, icon files, labels, sections, checked states, actions and the Stream Deck companion remain unchanged.
