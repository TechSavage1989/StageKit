# StageKit 0.1.0-beta261

The Countdown Timer dock shows the clock time a timer counts down to, as the Stream Deck key does.

## New

- **Deadline in the timer dock.** Under the timer's status the dock now reads, for example, **Until 9:45 PM**, with the date added when the deadline is not today. It uses the same time text as the Stream Deck Countdown Timer key, so the two always agree.

## Good to know

- The line appears only for timers set to a date and time (including the quick +15 / +30 / +45 / +60 marks). Duration and count-up timers show no deadline.
- The timer source shown on stream is unchanged: it still shows only the countdown, never the time it ends at.
