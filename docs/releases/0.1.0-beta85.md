# StageKit 0.1.0-beta85

Eighty-fifth pre-release: Stream Deck keys for the dock's switches and for slides. It changes
**both** the OBS plugin and the Stream Deck plugin. It passes the automated tests on Linux; **none
of it has run on Windows or on a Stream Deck yet.**

## New in the Stream Deck plugin

- **Dock switch** key: one of the StageKit dock's switches on a key. *Snap on release*, *Guides*,
  *Stop resizing at edges*, *Slide to the next edge*, *In every scene* or *Keep shape*. The key
  shows which way the switch is, and follows when you change it in the dock. *A press* can switch
  it over, only on, or only off.
- **Slide to next edge** key: slides the item selected in OBS left, right, up, down or cornerwise
  until it meets the next edge, or centres it in the free space. The next press passes that edge.
  It uses the dock's edge distance and timing.

## New for remote control

- `GetOptions`, `SetOption` and `Slide` requests, and an `OptionsChanged` event (see *Remote
  control* in the README).

## Please check

1. Install both files (the OBS plugin through the dock's *Update* button if it offers it).
2. *Dock switch* set to *Guides*: does the key light when guides are on, and follow the dock?
3. *Slide to next edge*: select the camera in OBS, press the key: does it stop at the first edge?
