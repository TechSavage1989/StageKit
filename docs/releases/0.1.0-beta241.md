# StageKit 0.1.0-beta241

Read a larger timer in the dock, enlarge the overlay with sharp text, and choose how the timer starts, counts and finishes.

## New

- **Clock shortcuts and Stream Deck control.** Choose the next quarter hour, :15, :30, :45 or full hour. The Countdown Timer key can set and start a private or on-stream timer, then stop and reset it on the next press. In Cycle mode tap through :15, :30, :45 and :00. Hold to start or stop the selected mark.
- **Start when streaming starts.** Enable this for any scene timer or the private timer. A paused timer resumes when the stream starts.
- **Independent finish actions.** Turn the end message and Program scene switch on or off separately. Each keeps the text or scene you selected.
- **Custom output and leading zero.** Use a format such as IN %time%, choose the displayed units, and show 4:06 or 04:06. End messages also accept time placeholders.
- **Count-up and steady seconds.** Count up to a chosen date or a duration. Period timers can advance one second at a time after an OBS delay.

## Changed

- **Larger timer digits in the dock.** The clock fits the available width and height, including in a narrow dock.

## Fixed

- **One box for the timer and its text.** Position the digits once. Formatted output and end messages resize and fade inside the same box, including on reset. A saved message no longer widens the source before it appears.
- **Sharp enlarged overlay.** The timer draws its letters and digits at the scene item's scale.

## Good to know

- **Where to find these options.** Open Timer settings in Docks > StageKit Timer or in the properties of a Countdown Timer (StageKit) source. Leaving Steady second increment off keeps a period timer tied to elapsed time.
