# StageKit 0.1.0-beta241

Read a larger timer in the dock, enlarge the overlay with sharp text, and choose how the timer starts, counts and finishes.

## New

- **Start when streaming starts.** Enable this for any scene timer or the private timer. A paused timer resumes when the stream starts.
- **Independent finish actions.** Turn the end message and Program scene switch on or off separately. Each keeps the text or scene you selected.
- **Custom output and leading zero.** Use a format such as IN %time%, choose the displayed units, and show 4:06 or 04:06. End messages also accept time placeholders.
- **Count-up and steady seconds.** Count up to a chosen date or a duration. Period timers can advance one second at a time after an OBS delay.

## Changed

- **Larger timer digits in the dock.** The clock fits the available width and height, including in a narrow dock.

## Fixed

- **Sharp enlarged overlay.** The timer draws its letters and digits at the scene item's scale and keeps its saved size and position in OBS.
