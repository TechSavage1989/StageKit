# StageKit 0.1.0-beta29

Twenty-ninth pre-release: a new filter, **Corners & Edges**. It passes the automated tests on Linux;
**it has not been run in OBS on Windows yet**, where its shader is compiled by Direct3D for the first
time when OBS starts.

## What's new

- **Corners & Edges (StageKit)**, a filter for any source:
  - corner style: rounded, cut off (chamfer), notched or scooped;
  - corner size, and each corner on or off;
  - trim the edges, soften the edge, and an outline in any colour;
  - sizes are as seen on screen, like Shadow & Backdrop's.
- **It does not disturb the other tools.** The source keeps its size. A Shadow & Backdrop after it
  casts a shadow of the new shape, and the filter places itself above an existing shadow when you add
  it. After an Auto Frame it shapes the game picture inside the frame.
- The dock's *Add effect* box has a *Corners & Edges* button.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
