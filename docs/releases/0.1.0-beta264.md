# StageKit 0.1.0-beta264

The saved OBS window layout is kept again: the StageKit dock no longer resizes itself after OBS loads.

## Fixed

- **The StageKit dock keeps its size after OBS starts.** With **Save layout when OBS closes** ticked, StageKit saved the layout after OBS had already taken its browser and service docks down, so the docks beside them had taken their room. That squeezed layout was then put back over OBS's own about a second and a half after every start, and again when a late dock appeared. StageKit now saves the layout the moment the OBS window is asked to close, before any dock goes.

## Good to know

- A layout saved at closing by an earlier version is not restored automatically, because it may be the squeezed one. OBS's own layout is kept until OBS closes once with this version, which saves a good one. **Tools > StageKit > Restore window layout** still restores the old file by hand.
- No other settings change.
