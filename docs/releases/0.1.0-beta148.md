# StageKit 0.1.0-beta148

One hundred and forty-eighth pre-release: OBS no longer closes itself when you change scene collection.
Tested on Linux only.

## Fixed

- **"Source Cleanup Error ... OBS Studio will now exit"** when changing scene collection or closing
  OBS, with a source that uses Standby Image's *Show when source is hidden*. The Standby filter kept
  hold of that source's scene items, so OBS could never let go of the source itself (its log said
  "Not all sources were cleared ... - DSLR"). It has been so since that option came in (beta139).
