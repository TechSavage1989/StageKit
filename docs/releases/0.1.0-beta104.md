# StageKit 0.1.0-beta104

One hundred and fourth pre-release: more kinds of blur, and Bloom for Ambient Background. It passes
the automated tests on Linux. The new shader code has not run on Windows before this release.

## New

- **Blur: seven cell shapes for Pixelate** (*Cell shape*): squares, hexagons, circles, triangles,
  Voronoi (uneven cells), rhomboids and triakis (triangles split in three). With them come
  **Smoothing** (how far each cell's colour runs into its neighbours), **Origin X / Y** (the point
  the pattern is laid out from) and **Rotation**.
- **Blur: a Temporal type.** The picture stays sharp and is blurred over time instead: whatever
  moves leaves a trail. Strength is how long the trail lasts (100 is one second).
- **Ambient Background: the same.** A *Blur type* (Dual Kawase as before, Gaussian, Box or
  Temporal), and the mosaic in all seven cell shapes with smoothing, origin and rotation.
- **Ambient Background: Bloom.** The bright parts of the picture shine over what is around them.
  *Bloom* is how strongly (0 is off), *Bloom from brightness* how bright a part must be, and
  *Bloom size* how far the light spreads.

## Changed

- The *Hexagons* blur type is now *Pixelate* with *Cell shape: Hexagons*. Filters set to it are
  switched over by themselves and look the same.

## Not included

- Composite Blur's effect masks and its background source for compositing. Say if you want them.

## Please check

1. Try a new cell shape (circles, say), the Temporal type and Bloom. They are drawn by new shader
   code that has only run on Linux so far. It is kept apart from the old code, so your existing
   blurs and backgrounds draw as before either way; if a new option does nothing, send the OBS log
   (Help, Log Files, Upload Current Log File).
2. Say what looks wrong or is missing.
