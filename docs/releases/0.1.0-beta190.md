# StageKit 0.1.0-beta190

Auto Capture lets go of a game whose window closes while the emulator stays open, so the Standby Image shows.

## Fixed

- **The last frame of a closed game no longer stays in the capture.** With an emulator whose game
  and menu are separate windows (Dolphin), closing the game left its last frame in the Game
  Capture for as long as the emulator stayed open, and the Standby Image never came. Auto Capture
  now lets go of the capture about half a second after the game's window closes, and the Standby
  Image comes in with its transition (Morph, a fade, or whichever you chose).
- **The next game is picked up as usual.** Starting another game in the emulator opens a new game
  window, which is captured as before. The emulator's menu is not taken for a game meanwhile.
- **Going full-screen does not flash the Standby Image.** A game window that is only made again,
  or minimised, is not let go of, and neither is closing one GBA window while the game runs.

## Good to know

- The OBS log says `the window it captured in <program> has closed; letting go` when this happens,
  then `aimed at no window while <program> shows no game window`.
- Programs on *Always capture* are let go of the same way.
- Not yet tried on Windows.
