# StageKit 0.1.0-beta34

Thirty-fourth pre-release: the start image picture fits the dock. It passes the automated tests on
Linux; **it has not been run in OBS on Windows yet.**

## What's changed

- **The picture in the StageKit Background dock is as wide as the dock.** It grows and shrinks as you
  resize the dock, keeping its shape. In a short dock it stops growing before it would push the
  buttons out of view. The wheel, drag and double-click on it work as before.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
