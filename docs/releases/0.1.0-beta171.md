# StageKit 0.1.0-beta171

A small fix to Scene Transitions.

## Fixed

- **Scene Transitions no longer rewrites a transition while a scene's sources are still loading.**
  When a scene was loaded or sources were added to it, it could now and then write a source's show
  or hide transition once more just before the saved one arrived. It now waits a tenth of a second
  after a source is added. Nothing you see changes.
