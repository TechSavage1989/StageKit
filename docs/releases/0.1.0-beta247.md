# StageKit 0.1.0-beta247

Show Auto Frame's detected ratio, add measurement keys, and transition with a Studio Mode hold.

## New

- **Measure Bars key.** Measure the current image on a selected Auto Frame filter and receive feedback when the result is ready.
- **Remember Aspect Ratio key.** Save the measured ratio for the window currently being captured.
- **Measure and Remember key.** Take a fresh measurement and save it for the same detected window in one press. Failed or interrupted measurements do not save an older ratio.
- **Studio Mode long press.** Hold the Studio Mode key to send Preview to Program using OBS's current transition. Choose the hold time or turn the hold action off. A normal press keeps the key's Studio Mode action.

## Changed

- **Visible measurement results.** Auto Frame shows the detected image ratio beside Measure the bars now, with progress and unavailable-image feedback.
- **Automatic rule fields.** Program or window and Its aspect ratio fill from the actual captured window and measured image. You can still edit the draft before saving it. The editor remains available after measuring.

## Good to know

- **Update both plugins.** Install this StageKit OBS release and its Stream Deck companion, version 0.40.0.0, for the new keys.
- **Save deliberately.** Automatic field filling does not save a rule. Use Remember this ratio, Remember Aspect Ratio, or Measure and Remember when you want to keep the result.
