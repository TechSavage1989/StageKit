# StageKit 0.1.0-beta256

Switch scenes directly, use a compact controls list, and customize your view buttons with icons and sizing.

## New

- **Direct scene switching.** A Scene selector is always available at the top of the panel. Pin individual scenes as one-click rows or buttons. In Studio Mode these controls select Preview.
- **List or buttons.** StageKit Views offers compact rows under collapsible scene and section headings, or the button layout. Both use the same selected controls and remember the layout for each scene collection.
- **Button size and icons.** Adjust button size from the dock. Choose a custom icon for a control; a small copy is saved with the collection and also appears beside its compact list row.
- **Show the selection's scene.** The panel can display the owning scene when selecting a named mode or combined view without an explicit destination. This option starts on, respects configured destinations, and changes Preview in Studio Mode.

## Changed

- **Simpler panel editing.** Check individual controls or a complete group to include them. Remove several controls together, clear the panel, and apply a section to multiple selected entries.
- **Shared panel settings.** Switching between list and buttons keeps the same choices, labels, sections, icons and order. Search in the editor keeps existing selections intact.

## Fixed

- **Reopening an active view.** Selecting a mode or view that is already active can bring its scene back into view while another scene is selected. Scene navigation runs with the native selection rather than racing it from the dock.
- **Compact active state.** List rows show actual control state independently of keyboard focus. Focusing or restoring a row does not activate it.

## Good to know

- **Existing setups.** Saved panels carry forward. Turning the new scene-navigation option off retains existing native destination rules. Source, linked visibility and Show in Scenes controls keep their behavior.
- **Optional icons.** Removing an icon or a control from the panel does not remove its underlying source, filter or controller rule.
- **Companion.** The Stream Deck companion remains 0.43.0.0; existing action IDs and key behavior are unchanged.
- **Windows first.** The Windows build, actual OBS frontend and restart checks, and shared release checks must pass on the final release revision before publication.
