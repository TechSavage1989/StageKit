# StageKit 0.1.0-beta88

Eighty-eighth pre-release: three things from the owner's testing of beta87. It passes the automated
tests on Linux.

## Changed in the dock

- **In every scene** is on the **Arrange** tab too (under *How the tools measure*, off as it
  comes). Ticked, whatever an arrange tool moves or resizes is put the same way in every other
  scene showing that source, and one Undo takes it back everywhere.
- **Use visible pixels** and **Ignore shadows & outlines** are on the **Place** tab as well. They
  are the same two options as on the Arrange tab; ticking one ticks the other.

## Fixed

- **Fit to Space, *The free space around it*: a widget a few pixels in the way no longer costs the
  space its height.** A widget set to the same width as the column above it was read as a few
  pixels wider, and the space stopped above the widget (95 px from the bottom of the screen) to
  keep those few pixels of width. Now, when two spaces give a picture of as good as the same size,
  the roomier one is taken. The gap is still kept from everything.

2. Does the game's space now run to 30 px from the bottom, beside the music widget?
