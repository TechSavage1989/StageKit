# StageKit 0.1.0-beta187

Taking a StageKit filter off a source or scene while it is on screen no longer crashes OBS.

## Fixed

- **Removing a filter while it is drawn no longer crashes OBS.** Taking a Scene Blur, Blur,
  Corners & Edges, Auto Frame, Zoom or any other StageKit filter off its source or scene in the
  Filters window, at the moment it was being drawn, could close OBS. Beta186 fixed this for Scene
  Shadow; every StageKit filter is now safe the same way.

## Good to know

- Nothing changes in how any filter looks or behaves; your settings are kept as they are.
- Not yet tried on Windows.
