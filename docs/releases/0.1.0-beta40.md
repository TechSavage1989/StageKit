# StageKit 0.1.0-beta40

Fortieth pre-release: fixes for Send To and Place Item moves, and some hardening against crashes. It passes the automated tests on Linux;
**it has not been run in OBS on Windows yet.**

## What's fixed

- **A brought-along item flips by what is drawn in it.** Whether the item travelling with the camera
  has to go to the other side to stay on screen was judged by the item's box. A widget's box is often
  much bigger than the widget, so the answer could be wrong. It is now judged by the visible part.
  The flip only happens when *Flip sides to stay on screen* is ticked in the Send To filter; see the
  note below.
- **No shift after a move ends.** Two causes are removed:
  - *Snap on release* treated any move of a selected item as a mouse drag, so an item sent by a key or
    a filter was then snapped a few pixels to the nearest line. It now only acts after a drag with
    the mouse.
  - The last step of a glide was applied twice, which could overshoot by a pixel or two.

## Crashes

You reported OBS sometimes crashing while working with the newer filters. Without a crash report the
cause is not known. This release closes three gaps where a filter used a scene item, or a shared list,
that OBS's window could change at the same moment from another thread (Shadow, Glow & Outline when its
room changes or its scene list is checked, Fit Item, and Ramp Blur's *Blur these too*). That may or
may not be what you hit: **please send the crash report the next time it happens** (*Help → Crash
Reports → View Last Crash Report*).

## If your camera keys came from the rebuilt collection

The seven *Camera …* Send To filters on *Square Camera* in drafts 1 to 5 were written with *Flip sides
to stay on screen* switched off. Open each one under the camera's *Filters* and tick it. Keys made
with the dock's *Make 9 position keys* already have it on.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
