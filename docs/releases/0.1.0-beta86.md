# StageKit 0.1.0-beta86

Eighty-sixth pre-release: two fixes from the owner's first try of beta83 to beta85. It passes the
automated tests on Linux; **the updater's Windows side still has not run anywhere but the owner's
machine.**

## Fixed

- **The *Update* button did nothing.** The dock said "Downloading the update" and stayed there. The
  helper that downloads and installs was started in a way that kept it from running; it is started
  differently now. This is a likely cause, not a proven one, so the helper now also writes what it
  does to `update.log` in the `StageKitUpdate` folder of your temp folder, and the dock says when an
  update did not go through instead of saying nothing.
- **The StageKit dock scrolled with nothing below it.** It was as tall as its tallest tab whichever
  tab was showing. Now it is only as tall as the tab you are on.

## Please check

1. Install this one by hand (the *Update* button in beta83 to beta85 cannot install it).
2. The next release will be the real test of *Update*. If it does not go through, send the
   `update.log` file.
3. Is the dock's scrollbar gone on the shorter tabs?

## Changed in the Stream Deck plugin

- The settings pages' own text (*OBS connection* and the note under it) is in the same font as the
  rest of Stream Deck, not a serif face.
- *A press* is now *On press*, with *Toggle*, *Switch on* and *Switch off*. More names follow in
  the next release.
