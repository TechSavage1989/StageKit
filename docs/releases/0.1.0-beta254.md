# StageKit 0.1.0-beta254

Restore the macOS build of Scene Controller and StageKit Views.

## Fixed

- **macOS build.** Correct JSON-array iteration in the Views dock for Clang's compiler checks. The dock, saved views and controller behavior remain the same as the Windows beta253 release.
- **Linux verification.** Use a checksum-verified OBS 32.2.2 test package so an unavailable package server cannot silently substitute an older OBS version.

## Good to know

- **Windows.** Scene Controller and StageKit Views were released for Windows first in beta253. This follow-up retains the same features and companion 0.43.0.0.
- **Performance.** This compile correction does not establish a hardware frame-time improvement.
