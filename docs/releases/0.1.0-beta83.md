# StageKit 0.1.0-beta83

Eighty-third pre-release: StageKit updates itself from inside OBS. It passes the automated tests on
Linux; **the download and install have not been run on Windows yet**, so the first update after this
one is its real test.

## New

- **Updates without going to GitHub.** About ten seconds after OBS starts, StageKit looks at this
  project's releases. When there is a newer one, a line appears at the bottom of the StageKit dock:
  *StageKit … is available*, with **What's new** and **Update**.
- **Update** asks first, then does the rest:
  1. downloads the installer, and the Stream Deck plugin's file if that plugin is installed;
  2. checks each file against the checksum in the release notes, and stops there, saying so, if one
     does not match (nothing has been changed at that point);
  3. closes OBS, runs the installer without its pages (Windows asks for permission), hands the
     Stream Deck file to Stream Deck, and opens OBS again.
- It will not start while you are streaming or recording.
- The **⋯** button at the bottom right of the dock shows the version you have, and holds *Check for
  updates now*, *Check when OBS starts* and *Include test versions*.
- Looking for updates is an ordinary request to GitHub; nothing about you or your setup is sent.
  Untick *Check when OBS starts* to stop it.

## Good to know

- This release has to be installed by hand one last time; the updater starts working from here.
- A release shows up a few minutes before its Windows installer does. The updater waits until the
  installer is there.
