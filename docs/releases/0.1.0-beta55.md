# StageKit 0.1.0-beta55

Fifty-fifth pre-release: a different way of showing **Guides in the preview**. It passes the automated
tests on Linux; **it has not been run in OBS on Windows yet.**

## Changed

- **Guides in the preview are drawn inside OBS's preview** instead of as separate small windows laid
  over it. Your dock said guides were on, yet nothing showed: the windows were being made and never
  appeared on your machine. Tick the box and a frame should flash round the picture in the preview
  for a moment.

## Good to know

- You reported no crashes with *Guides in the preview* and *Snap on release* unticked. Beta54 changed
  how items are measured when a drag starts and ends, which is the likeliest cause; this version
  changes the guide lines themselves, the other possible cause. If OBS still crashes with either
  ticked, untick them again and send the crash report.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
