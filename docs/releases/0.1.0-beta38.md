# StageKit 0.1.0-beta38

Thirty-eighth pre-release: leave a shadow off in chosen scenes. It passes the automated tests on Linux;
**it has not been run in OBS on Windows yet.**

## What's new in Shadow, Glow & Outline

- **Leave it off in these scenes.** When a source sits in several scenes, the filter's settings now
  list every one of those scenes by name with a tick box. Tick a scene and the filter draws nothing
  while that scene is on screen: no shadow, glow, outline or panel. The source shows plain there, in
  the same place, and everything is back in the other scenes.

How it decides: a filter cannot tell which scene is drawing it, so it goes by the scene on screen
(Program, in Studio Mode). A scene you are only editing in Preview follows the Program scene's rule
until you switch to it. The change takes about half a second after a scene switch.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
