# StageKit 0.1.0-beta182

Filter names say whether they go on a scene or a source, tooltips are easier to read, and Scene
Modes offers every mode type the Stream Deck does.

## Changed

- **Filter names.** In OBS's list of filters every StageKit filter now says where it goes:
  *Scene Filter: Fit to Space (StageKit)*, *Scene Filter: Link Visibility (StageKit)* and the
  other scene filters; *Source Filter: Blur (StageKit)*, *Source Filter: Standby Image (StageKit)*
  and the other source filters. Filters you already have keep the names they were given, and every
  Stream Deck key keeps working. Sources (Ambient Background, Cropped View, Standby Image) and
  transitions (Morph, Fade and Zoom, Make Room) keep their names.
- **Tooltips** are broken into lines of about 64 characters instead of one long line.
- **Scene Modes: Mode type** now offers every type the Stream Deck Scene Mode key offers
  (Handheld, Linked handheld screen, Retro game, Emulator, Console, the status screens, the
  activities and the rest), so a Scene Mode key left on *Automatic* can show any of them. Modes
  you already set keep their type. *Capture card* is now called *Capture card (internal)*, beside
  *Capture card (external)*, as on the Stream Deck.
- **Stream Deck plugin 0.29.0.0**: it knows the new filter names and the old ones, so a key's lists
  name your filters as before.
