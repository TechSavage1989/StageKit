# StageKit 0.1.0-beta144

One hundred and forty-fourth pre-release: a source with a shadow no longer grows each time OBS
starts. Tested on Linux only.

## Fixed

- **A source with a Shadow, Glow & Outline came back slightly larger after every restart, in
  some scenes.** While OBS was still loading its scenes, the filter gave back the room its
  shadow takes and then took it again, but only some scenes had their items at the first step,
  so items in the scenes loaded later were given the room twice. The filter now waits until OBS
  has finished loading before it adjusts anything. A scene with a Fit to Space on the same
  source hid the fault, because that filter put the item right each time.
- **Fit to Space lost its source when the source was renamed.** The filter kept the old name,
  found nothing by it and did nothing from then on. It now follows the new name.

An item already grown by the old fault is not put back by this update: size it once more, or
give it a Fit to Space, and it will stay.
