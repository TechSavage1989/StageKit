# StageKit 0.1.0-beta232

Add source and scene filter replacements, find their equivalents in OBS, and convert a copy of an existing scene collection.

## New

- **Find an OBS filter or tool.** Open Tools > StageKit > OBS filter replacements and search by the name in your current setup. The catalog shows the StageKit control and its availability.
- **Add effects and motion controls.** Choose from Advanced Mask, Composite Blur, User-defined Shader, 3D Effect, Freeze, Retro Effects, Move Action, Move Value and the classic Lua effects. Scene Filter entries include Move Source and Move Source Swap.
- **Use the production tools.** StageKit adds Source Copy, Source Dock, Transition Table, Quick Access Utility, Scene Collection Manager and Dock Layout Manager. NDI inputs and outputs require the separate NDI runtime.
- **Convert a collection copy.** The converter preserves source names, filter order, settings and chained Move references. It relinks matching bundled shaders and lists entries that need their original plugin.
- **Control OBS from Stream Deck.** Companion version 0.36 adds keys for source visibility, filter state, mixer mute, Studio Mode, virtual camera, moving a source in a scene and swapping two sources.

## Good to know

- **Try your exported collection first.** Choose Save a converted collection copy, then use Scene Collection > Import in OBS to open the new file.
- **Keep plugins used by flagged entries.** Advanced Scene Switcher macros, older StreamFX filters and any unavailable saved filter version keep their original settings and are listed for review. Existing Elgato OBS keys keep their bindings.
