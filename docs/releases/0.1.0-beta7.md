# StageKit 0.1.0-beta7

Seventh pre-release: the start image becomes one setting. These changes pass the automated tests on
Linux; **they have not been run in OBS on Windows yet.**

## What's new

- **One start image for the whole collection.** Choose it once, in the StageKit dock (*Start image →
  Choose the start image…*). It is saved with the scene collection.
- **Start Image (StageKit)**, a source that shows it. Add it to your start scene in place of a hand-set
  image source. Choosing a file in this source's settings changes the start image too.
- **Ambient Background can follow it.** Set *Background from* to *The start image* and the moving,
  blurred background uses the same picture. Change the start image and both update at once.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The start image is a still picture; a video is not supported as a start image.
- Changing it applies to the scene collection that is open.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
