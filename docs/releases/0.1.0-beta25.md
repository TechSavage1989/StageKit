# StageKit 0.1.0-beta25

Twenty-fifth pre-release: a crop that needs no numbers. It passes the automated tests on Linux; **it
has not been run in OBS on Windows yet.**

## What's new

- **Cropped View: *Whatever is drawn*.** A new choice under *Crop to*. It trims off the empty,
  see-through room around a source's content by itself and follows the content when it changes size.
  It is meant for web widgets, such as a now-playing card, whose page is far bigger than what it
  draws: there are no crop numbers to work out, and none to go stale when the widget's layout changes.

The rebuilt scene collection uses it for the music widget on the start, intermission, break and ending
scenes, pinned by its bottom-left corner where it sat before.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- It looks about once a second, so the view follows a change in the content a moment later.
- A source showing nothing at all keeps the size it had.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
