# StageKit 0.1.0-beta28

Twenty-eighth pre-release: a fix for the line-up tools. It passes the automated tests on Linux; **it has
not been run in OBS on Windows yet.**

## What's fixed

- **A selected group now counts.** With a camera and a group (such as the chat box group) selected and
  *Align to: Each other*, the group was skipped, so only the camera was left and it went to the edge of
  the screen. A selected group is now lined up, spaced, resized and snapped as one item, measured by
  its visible pixels like any other.
- With *Align to: Each other* and fewer than two items selected, nothing moves and the dock says to
  select two or more.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
