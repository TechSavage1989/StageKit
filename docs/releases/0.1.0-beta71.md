# StageKit 0.1.0-beta71

Seventy-first pre-release: three options asked for. It passes the automated tests on Linux; **it has
not been run in OBS on Windows yet.**

## New

- **Shadow, Glow & Outline: "Keep it on screen"** (off as it comes). When an item reaches the edge
  of the canvas, its shadow, glow or outline would be cut off there. Ticked, the item is made a
  little smaller instead, by just enough for the whole effect to show, and stays against that edge.
  - It acts once the item has been still for a moment, so it does not get in the way of a drag or of
    an item gliding in.
  - An item whose picture is itself partly off the canvas is left alone.
  - The item keeps its shape. It does not grow back by itself when moved away from the edge.
  - It works on ordinary items. With Fit Item, a picture that fills the screen makes room for its
    shadow instead.
- **Fit Item: "Size it by hand"**, for *A box I set*. Resize the item in the preview as you would
  any other; a moment after you let go, the size you gave it becomes *Box width* and *Box height*.
  *Box left*, *Box top* and the margin stay as set, so the item goes back to that corner.
- **Ambient Background: "Ignore a standby picture"** (on as it comes). While a Standby Picture is
  standing in for the capture, the background no longer blends that still picture in as if it were
  the game: it shows its usual picture. Untick it to have the standby picture blended in as before.

## Please check

1. Tick *Keep it on screen* on a shadow and put the item against the canvas edge: after a moment it
   should shrink just enough for the shadow to show.
2. Tick *Size it by hand* in Fit Item, resize the game in the preview: it should keep that size and
   go back to the box's corner.
3. With no game running, the Ambient Background should show its usual picture, not the start image.
