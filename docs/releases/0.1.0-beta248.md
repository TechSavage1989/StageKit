# StageKit 0.1.0-beta248

Apply changed capture options to windows kept ready by Automatic Window Switcher.

## Fixed

- **Capture options reach prepared windows.** Changing the capture method, cursor option or other capture-source settings now updates windows already kept ready by Automatic Window Switcher.
- **Stable image during settings changes.** The selected window remains visible while a replacement starts. Manual selection stays intact, and other switchers sharing the original capture keep their own settings.
- **Rapid option changes.** Reverted or superseded settings cannot replace the current image later. Returning to the original options reuses the existing shared capture when available.

## Good to know

- **OBS plugin update.** The Stream Deck companion remains at version 0.40.0.0 and includes the Auto Frame measurement keys and configurable Studio Mode hold from beta247.
