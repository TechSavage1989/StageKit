# StageKit 0.1.0-beta30

Thirtieth pre-release: a fix for the moving background's live capture. It passes the automated tests
on Linux; **it has not been run in OBS on Windows yet.**

## What's fixed

- **No black bars in the background's live capture.** When the capture has an Auto Frame, Ambient
  Background now takes exactly the game picture Auto Frame has found, trimmed and shaped, instead of
  the whole frame with its empty sides. *Fill the screen*, *Fit*, *Match the width*, *Match the
  height* and *Stretch* all work from that picture, and follow it when the game changes shape.

A capture without an Auto Frame is used whole, as before. If its bars are part of the capture itself,
add an Auto Frame to it.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
