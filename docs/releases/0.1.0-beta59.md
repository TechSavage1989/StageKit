# StageKit 0.1.0-beta59

Fifty-ninth pre-release: copy an item's transform to the scenes you choose, and clearer names for the
copy tools. It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Copy transform to chosen scenes.** Select an item, and its position, size, rotation and crop go
  to the copies of the same source in the scenes you have listed, and no others.
  - The list is in the dock, under *Scenes to copy to*: choose a scene from *Add a scene...* to add
    it, and press the **x** beside one to take it off.
  - The list is saved with your scene collection.
  - Locked copies are left alone, and it is one step in *Edit → Undo*.
  - It is also in the preview's right-click *StageKit* menu and in *Settings → Hotkeys*.

## Changed

- **Same in every scene is now called Copy transform to all scenes.** It does what it did; the name
  says so. A hotkey you gave it still works.
- The two copy tools have a box of their own in the dock, **Copy to other scenes**.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The copy tools do not copy OBS's *crop to bounding box* setting.
- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
