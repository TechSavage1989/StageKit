# StageKit 0.1.0-beta67

Sixty-seventh pre-release: an item that is showing nothing no longer gets in the way. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **A widget showing nothing stopped a resize short.** With *Use visible pixels* ticked, an item that
  is drawing nothing at all, such as a music widget between songs or a capture with no window, was
  still measured by its box. It is now treated as not there:
  - *Stop resizing at edges* does not stop at it;
  - *Slide to the next edge* does not stop at it;
  - *Snap on release* does not snap to it, and no guide line is shown for it.

  With *Use visible pixels* unticked, every item counts by its box, as before.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- *Stop resizing at edges* acts when you let go of the mouse, not while you drag.
- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
