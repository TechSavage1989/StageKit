# StageKit 0.1.0-beta169

One Link Visibility can make a chat column (or anything else) follow every capture of a scene.

## Changed

- **Link Visibility: Follow sources.** *Follow the first source* is now *Follow sources*, with two
  lists:
  - **Lead sources**: one or more sources of the scene, for example every capture.
  - **Following sources**: the sources that go with them, for example the chat column.

  The following sources are shown while a lead source is shown and hidden once every lead source
  is hidden. Changing from one capture to another never hides them in between, whichever way the
  change is made (a Show in Scenes key, the eye icon, a hotkey). Everything else works as before:
  a following source shown by anything else while the leads are hidden is hidden again, one that a
  Show in Scenes switch has off stays off, *Also in other scenes*, *Lock hidden sources* and the
  Show/Hide transition (Morph included) all apply.
- **Followers show when**: *Any lead is shown* (as it comes) or *All leads are shown*, for
  following sources that should show only while every lead source is shown.

## Your filters

- Nothing changes in a Link Visibility you already have. One set to *Follow the first source* has
  no lead sources, and its first linked source keeps leading the rest exactly as before. Its
  settings are not rewritten.
- Its window offers **Make the first a lead**, which moves that first source into *Lead sources*.
  It works the same afterwards, and you can then add more lead sources.

## One filter instead of five

If your layout scene has one Link Visibility per capture, each a capture followed by *Column:
Chat*, one filter can do it all:

1. In the scene's filters, add **Link Visibility (StageKit)** and set it to *Follow sources*.
2. Under *Lead sources*, add every capture the old filters led: Window Capture, the game capture,
   the capture card, the display capture and the tablet.
3. Under *Following sources*, add *Column: Chat*.
4. Set *Show/Hide transition* the same as the old filters (Morph).
5. Switch the five old filters off (the eye beside each in the filter list), then press each
   capture's key and check the chat column: it should stay up throughout. When all is well, remove
   the old filters.

## Good to know

- Not yet tried on Windows. The switching between captures was tested with Show in Scenes keys, a
  *Show only one at a time* Link Visibility and Morph, in both filter orders, on and off screen.
