# StageKit 0.1.0-beta149

One hundred and forty-ninth pre-release: your saved window layout comes back after you switch
scene collection. Tested on Linux only.

## Fixed

- **The window layout after switching collection.** A saved layout was only brought back when OBS
  started. OBS puts the docks that belong to a collection up again when you switch, and the layout
  stayed as OBS left it. It now comes back after every change of collection as well. The tick box
  in the Tools menu's StageKit entry is now called *Restore it when a collection loads*.
- Apply Layout's *Save where everything is now* button and the window layout's *Save window
  layout* shared one text, so one of them could show the other's words.
