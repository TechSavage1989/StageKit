# StageKit 0.1.0-beta54

Fifty-fourth pre-release: groups work with the dock's tools, no line of background at the screen's
edge, and a change aimed at the crashes while moving items. It passes the automated tests on Linux;
**it has not been run in OBS on Windows yet.**

## Fixed

- **Groups.** Selecting a group in OBS now makes it the dock's item, so the Send to buttons and
  *Slide to the next edge* move the group. Before, the dock kept working on whatever item it showed
  last. **Same in every scene** now copies a group's place to the same group in your other scenes; it
  used to skip groups.
- **A pixel of background at the screen's edge.** A picture with smoothed edges ends in a faint row
  of pixels, and that row was counted as picture. It is no longer counted, so with an edge distance
  of 0 the picture you see reaches the edge.
- **OBS crashing while moving and editing items.** The cause is not confirmed: no crash report has
  been seen. The likeliest fault is fixed: StageKit measured items by drawing them at the same moment
  OBS drew them for the picture. Measuring now waits its turn between two frames.

## Not fixed

- **Guides in the preview** are unchanged. To find out why they do not show, what the dock says when
  you tick the box is needed.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
