# StageKit 0.1.0-beta89

Eighty-ninth pre-release: one fix from the owner's testing. It passes the automated tests on Linux.

## Fixed

- **The update notice was cut off in a narrow dock.** Its *What's new* and *Update* buttons sat
  beside the words and fell outside the dock when it was narrow. The words are now on their own
  line with the two buttons below, sharing the width, and they shrink with the dock.

## Please check

1. If you are on beta86 or later, the dock's *Update* button should offer this release.
2. With the dock narrow, are both buttons in view?
