# StageKit 0.1.0-beta95

Ninety-fifth pre-release: change a filter everywhere at once. It passes the automated tests on
Linux.

## New

- **Dock, Copy tab: *Copy a filter's settings*.** Set one filter up the way you want in OBS's
  Filters window, then give its settings to the same kind of filter elsewhere:
  - *Every source that has one*
  - *The listed sources* (under *Sources to copy to*)
  - *Sources in the listed scenes* (under *Scenes to copy to*)
  - *Sources in this scene*

  *Add it where it is missing* also gives a copy of the filter to chosen sources that do not have
  one. It works for any filter, OBS's own included.

## Good to know

- A filter belongs to a source, not to a scene: the same source shows the same filter in every
  scene. So "in a scene" means "on the sources shown in that scene".
- What a filter keeps for its own source is left alone on each: which item it works on, where a
  shadow moved its items, what an Auto Frame has learned. Whether each filter is on is not changed.
- There is no Undo for it. Try it on one or two sources first.
