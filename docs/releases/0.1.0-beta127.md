# StageKit 0.1.0-beta127

One hundred and twenty-seventh pre-release: a Stream Deck key for switching scenes, pictures for
capture cards and other devices, and the icons as editable SVGs. Nothing in the OBS plugin changed.
The Stream Deck plugin has not run on a real Stream Deck here.

## New (Stream Deck plugin 0.14.0.0)

- **Switch Scene key.** Choose a scene; pressing switches OBS to it, on the program (live) or, in
  Studio Mode, on the preview. Choose a *Transition* and *Duration*, or leave them *As set in OBS*;
  a transition chosen here becomes OBS's current transition. The key is lit (green dot) while its
  scene is on, however it got there, and is titled with the scene's name.
- **Device pictures.** A new *devices* group in every key's *Picture* list: internal capture card,
  external capture box, HDMI, console, webcam, camcorder, DSLR, microphone, phone, display, laptop,
  browser and speaker, in all six palettes.
- **Editable SVGs** of every picture drawn for StageKit: the action-list icons, the option and
  device pictures in each palette (the drawing as shapes in its own layer, with the on and off
  marks as layers to show), and the marks themselves. They are in the repository under
  `streamdeck/svg/`. The original icon pack's own pictures are PNG only.
