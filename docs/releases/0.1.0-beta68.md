# StageKit 0.1.0-beta68

Sixty-eighth pre-release: the Standby Picture is no longer cut to the last game's shape, and it fades
back in when a game ends. It passes the automated tests on Linux; **it has not been run in OBS on
Windows yet.**

## Fixed

- **The standby picture was cut to a game's shape.** It started out cropped before any game ran,
  took an emulator's shape as soon as the emulator opened, kept that shape after the game closed,
  and shook and jumped on the way to the game. The cause: on a capture where the Standby Picture
  filter sat *before* Auto Frame in the filter list, Auto Frame took the picture for a game and
  trimmed it. Standby Picture now always puts itself after Auto Frame, by itself, also on captures
  that already have both. Nothing to change by hand.
- **Corners & Edges cut the standby picture too.** After an Auto Frame it shapes the game's
  rectangle, and it kept using the last game's rectangle while the standby picture was showing. It
  now shapes the whole standby picture until a game is back.
- **The picture came back at once when a game ended.** A capture that ends has nothing left to
  draw, so there was nothing to fade from. The last frame of the game is now kept and fades into the
  picture over *Back to the picture*, in the style chosen under *Change with*.
- **The picture could start in the last game's shape for a moment** when OBS opened, before the
  picture had loaded. It now waits for the picture.

## Please check

1. Open OBS with no game running: the standby picture should be whole, in its own shape.
2. Open an emulator, then a game: the picture should glide to the game's shape and fade into it,
   without shaking.
3. Close the game: its last frame should fade back into the picture, and the picture should return
   to its own shape.
