# StageKit 0.1.0-beta80

Eightieth pre-release: the Stream Deck plugin, tidied up and with two more keys. The OBS plugin
itself is unchanged from beta77.

## Changed in the Stream Deck plugin

- **Palette, per key.** *Colour* is now called *Palette*, and each key has its own: changing it on
  one key no longer changes the others. Keys start in mono. A key that had taken another colour from
  the old shared setting goes back to mono until you set its palette.
- **No more odd-one-out keys.** A filter the icon pack has no picture for (Fit Item, Ramp Zoom,
  Active App and others) now gets a plain key drawn in the same style and in the key's palette,
  with an "on" and an "off" look, instead of the grey placeholder.
- **A Move key shows a tick** when OBS has taken the move.
- The settings of every StageKit key are laid out the same way: what it acts on, then *Picture* and
  *Palette*, then *OBS connection* folded away at the bottom.

## New in the Stream Deck plugin

- **Arrange tool** key: one of the dock's tools on a key. Line up an edge or centre, space out
  evenly, snap, make the same width, height or size, or copy a transform to all or to the chosen
  scenes. It acts on the items selected in OBS's preview, like the dock's buttons.
- **Blur everything** key: one press switches every Ramp Blur on, the next switches them all off.
  It shows on while any blur is on.

Install `stagekit-0.1.0-streamdeck.streamDeckPlugin` from this page over the one you have; your keys
keep their settings.
