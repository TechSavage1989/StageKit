# StageKit 0.1.0-beta14

Fourteenth pre-release: one fix, reported by the owner. It passes the automated tests on Linux; **it has
not been run in OBS on Windows yet.**

## What's fixed

- **Shadow settings no longer resize or move the picture.** The shadow needs room around the source,
  and raising the softness used to shrink the picture inside its box and shift it. Now the source's
  items in every scene are adjusted by exactly that room, so the picture keeps its size and place
  whatever the softness, offset or panel margin. Switching the filter off or removing it puts the items
  back. *Keep the picture where it is* turns this off.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A shadow you already set up is left exactly as it is; the fix applies from the next change you make
  to it.
- The red selection box in the preview still grows with the shadow, because it outlines the source
  with its shadow. The picture inside it does not move.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
