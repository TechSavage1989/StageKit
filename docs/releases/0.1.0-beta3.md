# StageKit 0.1.0-beta3

Third pre-release. It adds Auto Frame. The owner confirmed on Windows (OBS 32.2.2) that the 0.1.0-beta2
tools work; **Auto Frame itself has not been run in OBS on Windows yet**, or against a real emulator.

## What's new

- **Auto Frame** (filter): put it first on a game, window or capture-card source and set the frame's
  size once. The source then always has that size, and whatever the game or emulator outputs is fitted
  inside it, gliding to its new fit when the resolution changes. One scene can serve every picture
  shape.
  - Fit: whole picture, whole-number scale (crisp pixel art), fill, or stretch.
  - Picture shape: as captured, or shown as 4:3, 16:9, 8:7, 3:2, 10:9, 16:10, 5:4, 1:1 or custom.
  - Where the picture sits in the frame, sharp pixels, and the glide time.
  - Put Shadow & Backdrop after it and the shadow follows the picture.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version; your
scenes and settings are not changed.

## Known limits

- Auto Frame fits whatever size arrives; it does not tell a full-screen game from a windowed one.
- The dock cannot reach items inside nested scenes or groups yet, and has no bring-to-front or
  send-to-back buttons.
- Match Item sizes oddly for items inside groups.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
