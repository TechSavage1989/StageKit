# StageKit 0.1.0-beta15

Fifteenth pre-release: more control over the live capture in the Ambient Background. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

In an Ambient Background with *Blend in live capture* on:

- **Live capture fit**: fill the screen (as before), fit inside the screen, match the width, match the
  height, or stretch. Where the capture does not cover the screen, the background picture shows around
  it.
- **Live capture zoom**: 25% to 400%.
- **Live capture replaces the picture**: while there is a live capture it is the whole background. The
  moment there is none, the usual picture is back, with no fade.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- "No capture" means the capture source has nothing to show at all. A game that is captured but showing
  a black screen still counts as a capture.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
