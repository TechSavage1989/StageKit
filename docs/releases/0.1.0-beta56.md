# StageKit 0.1.0-beta56

Fifty-sixth pre-release: a precaution against the crashes, and a report in the dock to find out why
guides do not show. It passes the automated tests on Linux; **it has not been run in OBS on Windows
yet.**

## Changed

- **A possible cause of the crashes is removed.** The crashes began with beta53, which started
  measuring cameras and videos in a new way. That is undone. The cause is not proven: no crash report
  has been seen yet.
- **Guides in the preview now tell you what they did.** They still do not show on Windows. When you
  tick the box, the dock's message ends with a line in square brackets. A screenshot of that message
  says where the lines were put and whether Windows is showing them.

## Fixed

- The dock's **Ignore shadows & outlines** tick box showed no "&".

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides in the preview do not show on Windows yet.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
