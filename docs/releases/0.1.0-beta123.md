# StageKit 0.1.0-beta123

One hundred and twenty-third pre-release: every StageKit key in Stream Deck's list of actions has
an icon of its own. Nothing in the OBS plugin changed. The icons have not been seen in Stream Deck
here.

## Changed

- **Stream Deck plugin 0.11.0.0: an icon for each key.** In Stream Deck's list of actions, the
  25 StageKit keys showed one of five shared drawings. Each now has its own white line drawing:
  a soft blur for Blur, a magnifier for Zoom, a target for Auto Capture, corner brackets for Auto
  Frame, a picture for Standby Picture, two windows for Automatic Window Switcher, a link for Link
  Visibility, an eye for Show/Hide Animation, a person with an arrow for Move Source, and so on.
  The pictures on the keys themselves are unchanged.
