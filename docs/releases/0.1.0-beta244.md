# StageKit 0.1.0-beta244

Place sources beside the timer using the gap to its visible text.

## Fixed

- **Visible timer spacing.** Use visible pixels now applies to the timer in Place, Arrange, Fit to Space and Scene Fit, including when it is a neighboring source. Transparent space inside the timer box no longer adds to the requested gap.
- **Timer effects and text changes.** Ignore shadows & outlines follows the same rules as other sources. Automatic fitting can notice when the timer's text or alignment changes inside its fixed box.

## Good to know

- **Full-box placement.** Turn Use visible pixels off in the relevant dock or fit filter to keep measuring from the complete timer box.
- **Timer settings.** The saved box dimensions, font and text alignment remain in place. Each fit filter uses its own measurement options.
