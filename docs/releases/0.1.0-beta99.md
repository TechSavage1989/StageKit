# StageKit 0.1.0-beta99

Ninety-ninth pre-release: two Fit to Space filters in one scene settle at once. It passes the
automated tests on Linux.

## Fixed

- **A game and a chat box, each with Fit to Space, shifted several times before settling** after a
  scene switch or after the camera was hidden or shown. Each filter waited for the other's item to
  stop, moved a little, and set the other off again. Now each filter goes by where the other is
  *taking* its item, so both work out their final places straight away and make one move.
- **An item that keeps its size no longer creeps towards the edge.** With a resized item (the game)
  on one side and the screen's edge on the other, the middle between them kept moving as the game
  made room. Such an item now goes straight against the firm side, the gap away from it, and the
  game takes the rest. Between two firm things it is still centred.
