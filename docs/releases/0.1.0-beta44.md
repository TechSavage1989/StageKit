# StageKit 0.1.0-beta44

Forty-fourth pre-release: a hexagon blur. It passes the automated tests on Linux; **it has not been run
in OBS on Windows yet**, where the new shader is compiled by Direct3D for the first time when OBS
starts.

## What's new in Ramp Blur

- **Blur type: Hexagons.** A honeycomb mosaic: the picture breaks into hexagons that grow as the blur
  ramps in, the way *Pixelate* does with squares. *Strength* sets the hexagon size.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
