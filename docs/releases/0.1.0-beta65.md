# StageKit 0.1.0-beta65

Sixty-fifth pre-release: **Stop resizing at edges**, a limit for resizing by hand. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Stop resizing at edges**, a new tick box in the dock's Arrange box, with a **Resize limit** in
  pixels beside *Snap within*. It is also in the preview's right-click *StageKit* menu.
  - Resize an item in OBS's preview as you always do, by an edge or a corner.
  - When you let go of the mouse, any side you dragged to within the limit of the screen's edge or of
    another item is pulled back, so it stops that far short.
  - An item scaled evenly is pulled back evenly, so it keeps its shape.
  - *Use visible pixels* and *Ignore shadows & outlines* apply, as for the other tools.
  - It is one step in *Edit → Undo*.

## Good to know

- **It acts when you let go, not while you drag.** OBS does not let a plugin take part in its own
  resize drag, so the item can pass the limit while the mouse is down and comes back to it on
  release.
- An item you only move is not affected; *Snap on release* still looks after those.
- Rotated and locked items are left alone.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
