# StageKit 0.1.0-beta69

Sixty-ninth pre-release: the copy-transform tools can copy to other sources. It passes the automated
tests on Linux; **it has not been run in OBS on Windows yet.**

## New

- **Sources to copy to.** The dock's copy box (now called *Copy transform*) has a second list under
  *Scenes to copy to*. Choose a source from *Add a source...* to put it on the list; press the **x**
  beside one to take it off.
  - **Nothing listed** (the list reads *The same source*): as before, the transform goes to the
    copies of the selected item's own source in the other scenes.
  - **Sources listed**: *Copy transform to all scenes* gives the selected item's position, size,
    rotation and crop to every item showing one of those sources, in this scene and all the others.
    *Copy transform to chosen scenes* does the same in the listed scenes only.
  - The listed sources take the transform *instead of* the same source. Add the item's own source to
    the list to have both.
  - With several items selected, the last one selected is the one copied.
  - The transform is copied as it is, like OBS's *Paste Transform*: a source of a different size
    ends up a different size on screen.
  - Locked items are left alone; one step in *Edit → Undo*; the list is saved with the scene
    collection. The two hotkeys follow the list too.

## Please check

1. Select an item, add another source under *Sources to copy to*, press *Copy transform to all
   scenes*: that source should take the item's place everywhere it is.
2. Take the source off the list and press it again: only the same source in other scenes changes.
