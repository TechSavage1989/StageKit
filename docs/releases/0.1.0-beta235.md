# StageKit 0.1.0-beta235

Twelve replacement plugins now run StageKit’s own code, and NDI is optional.

## New

- **Twelve StageKit implementations.** 3D Effect, Directory Watch Media, Dock Layout Manager, Dynamic Delay, Freeze Filter, Pixel Art, Quick Access Dock, Recursion Effect, Source Clone, Source Defaults, Time Warp Scan, and Transition Table now use independently written StageKit code. Existing StageKit scene entries keep their saved IDs.
- **Optional NDI startup.** A fresh installation skips NDI. To change the setting, open Tools > StageKit > OBS filter replacements, set “Load NDI support at next OBS startup”, and restart OBS.

## Changed

- **Plugin Manager identifies ports.** StageKit modules built from other plugins now end in “(port)”. The replacement catalog also identifies each implementation.

## Good to know

- **Your StageKit-only scenes can use the new code in place.** Keep the StageKit entries you use enabled. The standalone originals can be disabled in OBS, including plugins without an uninstaller.
- **Existing NDI setups can keep using it.** On upgrade, StageKit checks the prior module registrations and active collection for NDI use. An explicit startup preference takes priority.
