# StageKit 0.1.0-beta5

Fifth pre-release: Auto Frame learns to trim black bars and to copy its size from an existing item.
These changes pass the automated tests on Linux; **they have not been run in OBS on Windows or with a
real emulator yet.**

## What's new in Auto Frame

- **Black bars are trimmed.** A full-screen emulator shows its picture inside black bars (a 4:3 game on a
  16:9 screen). Auto Frame now finds those bars and removes them before fitting, so the picture fills
  your frame whatever its shape. Three choices: *Trim them automatically* (the default), *Trim by a set
  amount*, or *Leave them*.
  - Automatic waits before trimming more (3 seconds by default, adjustable), so a dark moment in the
    game does not zoom the picture in. It lets go quickly when the picture grows back into the bars.
    A fully black screen changes nothing.
- **Copy the frame size from an existing item.** In the filter's settings, pick a scene and an item and
  press *Use that item's size*. The frame takes the size that item occupies in its scene, so there are
  no numbers to look up.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Automatic trimming can be fooled by a small bright logo on a black screen that stays longer than the
  wait time: the picture would zoom to the logo until the game appears. Raise *Wait before trimming
  more*, or use a set amount, if that happens.
- Copying a size does not move the item for you; place it once in the scene.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
