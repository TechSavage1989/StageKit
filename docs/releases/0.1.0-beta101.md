# StageKit 0.1.0-beta101

One hundred and first pre-release: the updater could not see beta100.

## Fixed

- **The dock said "beta99 is the newest" although beta100 was out.** The updater read the first 20
  releases GitHub listed and took the highest. GitHub does not list them newest first: beta100 was
  33rd. It now reads every release.

## This one has to be installed by hand

Versions up to beta100 have the mistake in them, so their *Update* button cannot find this
release. Download the Windows installer and the Stream Deck file from this page, close OBS and run
the installer. From here on the *Update* button works again.

Everything in beta100 is in this one too: the fix for a kept-size camera that changed size when
hidden and shown.

## Please check

1. After installing, does *Updates* say "StageKit 0.1.0-beta101 is the newest"?
2. Hide and show the camera several times: does it stay the same size?
