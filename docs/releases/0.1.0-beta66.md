# StageKit 0.1.0-beta66

Sixty-sixth pre-release: a choice of transition, timing and motion wherever something changes over
time. It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Standby Picture: Change with.** How the picture gives way to the capture is now yours to choose:
  a fade (still the default), a cut, sliding away or wiping in any of four directions, or a zoom and
  fade.
  - Separate times **To the capture** and **Back to the picture**.
  - The **easing curve** and direction the change follows.
  - **Size glides too**: untick it to have the size change at once.
  - The picture now also comes back with the same transition when the capture ends, instead of
    appearing at once.
- **Show in Scenes, Program Trigger and Visibility Link: Change with and Lasting.** How the items
  they show and hide appear and disappear: a fade, any other transition OBS has, a cut, or whatever
  is already set on each item.
- **The dock's Send to: Motion.** Choose the curve a move follows and whether it eases at the start,
  the end or both. Keys you make with the dock take the same.

## Changed

- Show in Scenes, Program Trigger and Visibility Link now give the items they show and hide a
  0.3 second fade unless you choose otherwise. Before, they left each item's own transition alone;
  pick *What is set on each item* under *Change with* to have that back.

## Already there

Ramp Blur, Ramp Zoom, Send To, Place Item, Show/Hide Animation, Layout, Match Item and Auto Frame
already had their own timings and easing curves, and Active App already offered every OBS transition.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Shadow, Glow & Outline and Corners & Edges still switch on and off at once.
- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
