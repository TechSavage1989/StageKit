# StageKit 0.1.0-beta151

One hundred and fifty-first pre-release: an off Stream Deck key shows what it controls. Only the
Stream Deck plugin changes (0.17.3.0); install it again from this release.

## Fixed

- **Off keys look like what they turn on.** A key for a hidden source showed an empty screen with
  the off sign, so all your capture keys looked the same when off. An off key now shows its own
  picture (the game, the window, the display, the capture card ...), greyed, with the red sign in
  the corner, the way a scene key shows its scene.
