# StageKit 0.1.0-beta199

OBS no longer freezes when sources are shown and hidden with Morph: the layer that draws the change is put into the scene and taken out on OBS's own thread.

## New

## Changed

- **Morph between sources begins a frame or two later.** The source being hidden stays as it is until the layer that draws the change is in the scene, then the change runs over the time that is left. Nothing blinks if OBS is busy at that moment.
- **The timing lines name the Morph's own work.** The 30-second timing lines in OBS's log now include `stagekit_item_morph`, the part of Morph between sources that looks for what goes together.

## Fixed

- **OBS freezing while pressing Stream Deck keys.** Showing and hiding sources with Morph or Make Room could lock OBS up for good, with no crash report. StageKit added and removed its *Morph (StageKit, in progress)* layer in the middle of OBS's drawing, where it could end up waiting for OBS's window while the window waited for it. The layer is now added and removed the way OBS does it itself.
- **Show in Scenes and Link Visibility look first, then change.** They went through the scenes and showed or hid each source as they found it, with OBS's scenes locked meanwhile. They now find the sources first and change them after.
- **Nothing is worked out in the middle of a drawing.** Morph and Make Room no longer ask OBS for a source's position while a scene is being gone through or drawn.

## Good to know

- **Not seen on Windows yet.** It was tested on Linux, with OBS's own thread made to answer up to five frames late and seconds late. The freeze itself never happened in the tests, so the proof is your OBS no longer freezing.
- **If OBS still freezes.** Leave it frozen, open Task Manager, go to *Details*, right-click `obs64.exe` and choose *Create memory dump file*. Send that file and the OBS log: the dump shows what each part of OBS was waiting for.
- **Average time to render.** Each change between two sources still makes OBS save the scene collection twice, when the layer goes in and when it comes out. If the figure stays high, send the log: it now says what the Morph costs.
