# StageKit 0.1.0-beta49

Forty-ninth pre-release: Auto Frame finds a windowed game's shape in a dark scene, and remembers each
program's shape. It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## Improved

- **A windowed game's shape is found far sooner, also on a dark scene.** Until now the picture had to
  show a straight, lit edge on both sides before its bars were believed, and a modern game on a dark
  scene can take a long time to do that. Now:
  - anything a little brighter than the bars themselves counts as picture. Bars are flat black; even a
    night scene is not;
  - a picture fitted in its window is recognised from a few lit pixels at each side: it reaches both
    ends one way and stops the same distance in from both ends the other way, leaving a real shape;
  - a new size is looked at ten times a second until the shape is settled, instead of every 0.4 s.
- **A program's shape is remembered.** Once a program has held one shape for a quarter of a minute it
  is kept, and the next time that program is captured the picture starts in that shape from the first
  frame, at any window size, even while the screen is black. This is what saving a shape by hand did;
  it now happens by itself. What is seen on screen still corrects it, and a program that shows more
  than one shape starts from nothing.
  - *Start from each program's usual shape* (group 4, on to begin with) switches this and the built-in
    emulator shapes on and off together.
  - *Forget shapes seen before* clears what is remembered; its tooltip lists it.
  - Shapes you saved yourself are untouched and still win.
- **More windowed games are recognised as games.** Besides controller support, a program with a
  graphics engine now counts when it has a game store's library, a game engine's player, game audio or
  video, or a game engine's own kind of window. It is looked for four times a second.

## What I could not settle

Why the Game Capture takes a while to *start* on a windowed game. Programs on your *Always capture*
list need no recognising, so for those the wait is either OBS's own hook or the game's black start,
and I cannot tell which from here. OBS's log has the times: please send the newest file from
*Help → Log Files → Show Log Files* after a slow start.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A picture that is pure black at its edges still cannot be told from bars until something lit
  reaches them.
- A game whose opening video has bars of an exact standard shape is trimmed to it, and takes the hold
  time to come back when the game fills the screen.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
