# StageKit 0.1.0-beta157

One hundred and fifty-seventh pre-release: every Stream Deck key now chooses its image from a list
made for what the key does, in place of one long Image list. Nothing changes in OBS itself.

## Changed

- **Stream Deck plugin 0.20.0.0.** Each key has its own type list, with *Automatic* first:
  - *Switch Scene* and the scene filter keys: **Scene type**, 47 types in groups (holding screens,
    games, apps and screens, camera and talk, status, activities, all in one), such as Starting
    soon, Gameplay, Console + handheld link, Retro gaming, Desktop, Just chatting, Podcast, Be right
    back and Ending.
  - Keys that act on a source: **Source type**, up to 86 types in groups (captures and games, apps,
    devices, cameras and audio, overlays, status, holding screens), such as Game, Capture card,
    Window, Browser, Camera / webcam, DSLR / mirrorless, Chat, Alerts and Countdown. Each key offers
    only the types that make sense for it.
  - *Scene Mode*: **Mode type**. *Blur* and *Blur All*: **Blur style** (blurs and mosaics). *Shadow,
    Glow & Outline*: **Shadow style**. *Corners & Edges*: **Corner style**. The keys that show and
    hide sources: **Transition**. *Move*: **Position**. *Capture Active Window*: **Capture type**.
  - Every name is general, so the lists fit any layout. The images are the StageKit icon pack's own
    where one fits, and new drawings in the same style everywhere else: devices, status, styles and
    activities.
  - A key you set up before keeps its image. An image chosen in Stream Deck's own icon menu is
    meant to win over the plugin's; this has not been tried on a deck yet.
