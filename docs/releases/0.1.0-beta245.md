# StageKit 0.1.0-beta245

Reset OBS statistics from a dedicated Stream Deck key.

## New

- **Reset Stats key.** Add Reset Stats from the StageKit actions in Stream Deck. One press runs OBS's own statistics reset, including while the Stats dock is hidden.
- **Matching key images.** The key includes a dedicated statistics/reset icon, all six palettes, and the existing Source type and Image layout choices.

## Good to know

- **Shared connection.** Uses your existing StageKit OBS connection. No source selection or keyboard shortcut assignment is needed.
- **Stream Deck update.** Install the companion plugin from this release to add the new action. Its version is 0.38.0.0.
