# StageKit 0.1.0-beta47

Forty-seventh pre-release: a widescreen game no longer opens in an old-style shape, windowed games
come right sooner, and Send To moves the source in every scene. It passes the automated tests on
Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **A widescreen game opening cropped to a square or 4:3 shape, and taking a long time to come
  right.** Auto Frame took a picture shape from the capture before it had seen any picture: from a
  black loading screen, or from a size the capture only had for a moment while starting. That shape
  was then put on the real picture, and a dark, moving scene never gave it the steady evidence it
  wanted to let go. Now:
  - a shape is only held once the picture has been seen to end exactly where it is trimmed;
  - a shape carried over to a new size is a starting point. If the picture plainly shows inside it,
    it is let go within about a second;
  - when bars are seen clearly one way (above and below, say), they decide, even if a starting guess
    had trimmed the other way.
- **Windowed games taking a long time to look right.** A game in a window usually has its picture
  inside the window with bars above and below. Those bars had to hold for the full *Hold a shape for*
  time, on a scene bright enough to read. The first clear sight of a picture is now used within about a
  second; the hold time applies to later changes.
- **Black bars are told from a black background by their edges, not only by shape.** More is trimmed
  only when the picture ends in a straight line, the same distance in from both sides, leaving a
  standard game shape. A logo or artwork on black is left alone even when its width happens to match
  one.
- **A mouse pointer, pop-up or menu strip over a bar no longer resizes the picture.** Before, one
  resting there for six seconds did.
- A program started in a window is recognised as a game sooner the first time it is seen (it was
  looked at every 2.5 seconds while starting; now every second at first).

## Changed

- **Send To moves the source in every scene it is in.** Send your camera to the left middle and it is
  there in every scene. *Move it in* on each key now offers:
  - **Every scene it is in** (the default);
  - **Only the scene on screen**;
  - **Only one scene I choose**.
- **Keys made before this version now act in every scene.** The dock used to make every key for the
  scene on screen only. To keep a key to one scene, set *Move it in* on that key.
- The dock's *Send to* box has an **In every scene** tick box, on to begin with. It applies to the nine
  buttons and to keys you make. One Undo takes back a move in all scenes.

## If something is still slow

OBS's log now says what happened and when: which program Auto Capture aimed at, the size of the
picture that arrived, and every change of trim with its reason. If a game is slow to appear or to take
its shape, send the log from that session (*Help → Log Files → Show Log Files*, the newest file).

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A very dark game with bars keeps showing the bars until a frame is bright enough at the picture's
  edges. Common emulators start from their usual shape, so this affects other programs only.
- A saved spot is a position in the scene it was saved from. In every-scene mode the same position is
  used in each scene.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
