# StageKit 0.1.0-beta130

One hundred and thirtieth pre-release: Fit to Space's overlap rule can go by pixel distances from
each edge as well as by percentage. It passes the automated tests on Linux; the Windows side has
not run in a real OBS here.

## Added

- **Overlap by edge distances.** Under *Overlap only when it fills* there are now two tick boxes:
  - **Use fill percentage** (ticked as it comes): the rule as it was, with *Fill needed to overlap*.
  - **Use edge distances**: four amounts in pixels, **Most empty room: top**, **bottom**, **left**
    and **right**. The fitted source goes under the ignored sources (the camera) only when the
    empty room it would leave at every edge of its space is within the amount for that edge;
    otherwise it is fitted beside them. A 4:3 window on a 2560 wide canvas leaves 320 px at the
    left and at the right.
  With both ticked, either rule is enough to overlap. With neither ticked, the source is always
  fitted beside the ignored sources. Your present settings are unchanged: the percentage stays
  ticked and the edge distances start unticked, at 50 px each.
