# StageKit 0.1.0-beta134

One hundred and thirty-fourth pre-release: Morph rules for pairs of scenes, a glass look for the
mosaic, and Stream Deck keys whose picture fits their source. It passes the automated tests on
Linux; the Windows side has not run in a real OBS
here, and the new shader code has only run on OpenGL.

## Added

- **Morph: rules for two scenes.** In the Morph transition's settings there is a new group, *A
  rule for two scenes*: choose a **From scene** and a **To scene** (either can be *(any scene)*),
  set how that change is made, and press **Save this rule**. The rule appears under *Rules for
  scenes* with its own remove button. A rule sets:
  - **Change with**: *Morph*, *Cross-fade* or *Cut*.
  - **Other items**, **Morph the main picture** and the **easing**, for that change only.
  - **Both ways**: the rule also holds for the change back.
  Choosing two scenes that already have a rule shows its settings, to change and save again. A
  rule that names both scenes comes before one with *(any scene)*. How long the change lasts is
  still the transition's duration in OBS: a transition cannot set that itself.
- **Mosaic: Glass.** The Blur filter's *Pixelate* and Ambient Background's mosaic have a new
  **Glass** slider and a **Glass style**:
  - **Dome**: each cell is curved like a bead of glass and shines across its whole face, brighter
    towards the upper left, with a glint and a darker rim.
  - **Flat plate**: the face stays flat and the cell has sharp bevelled edges that catch the
    light, like a cut plate of glass. Squares and hexagons get straight facets, each lit as one;
    the other shapes are treated as round.
  At 0 the cells are flat as before. It adds one small sum per pixel and reads nothing more of the
  picture, so it costs next to nothing.

## Changed (Stream Deck plugin 0.16.0.0)

- **A key's picture fits the source it is on.** Left on *Automatic*, a *Show in Scenes*, *Shadow*,
  *Standby Picture* or *Blur* key first looks for your icon pack's own picture of that source, by
  the words of the source's name: a *Show in Scenes* key on *Square Camera* gets the pack's
  *square camera* show/hide picture. Where the pack has none for that name, a *Show in Scenes* key
  shows what the source is: a camera, a game capture, a window capture, a display, a browser. A
  Cropped View counts as what it shows, so a camera's crop is a camera. Only then does it fall
  back to the filter's general picture.
- You can still choose any picture yourself under **Picture**: the pack's per-source pictures are
  in the *show hide*, *shadow by source*, *standby by source* and *blur …* groups, and the device
  pictures (webcam, camcorder, DSLR, capture card and so on) are in *devices*.
