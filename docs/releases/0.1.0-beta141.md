# StageKit 0.1.0-beta141

One hundred and forty-first pre-release: you choose how a hidden source changes into its standby
image. Tested on Linux only; how the Morph looks between a camera and its image has not been seen
on Windows.

## Changed

- **Standby Image, *Show when source is hidden*: the change is the transition you choose.** Under
  the tick box there is now the full *Show/Hide transition*: any OBS transition, a cut, or *Morph
  (StageKit)*, with that transition's own settings (a slide's direction, say), and hiding apart
  from showing if you like. Fade is what it comes with.
  - Before, you saw the source's own hide transition (the slide, set by another filter) while the
    standby image only faded in, a moment late.
  - Now StageKit sets the chosen transition on the source's items and on the standby items, so
    the source leaves and the standby image arrives the same way, whatever hides the source: a
    Stream Deck key, Show in Scenes, the eye in OBS.
  - With **Morph**, the source changes into the standby image and back.
  - While the box is ticked, other StageKit filters (Show in Scenes, Link Visibility and the
    like) no longer change the transitions of that source's items; this filter's choice is the
    one used.
  - The standby image now appears in the same moment the source is hidden, not up to a quarter
    second after.
