# StageKit 0.1.0-beta92

Ninety-second pre-release: Link Visibility across scenes. It passes the automated tests on Linux.

## New

- **Link Visibility: *Also in other scenes*.** A list of sources that are shown and hidden with the
  filter's linked items wherever they are in your other scenes: the same camera, or another camera
  in another scene. Hide the camera in one scene, with a Stream Deck key or the eye icon, and the
  listed sources are hidden everywhere. It works both ways: hiding one of the listed sources in any
  scene hides the linked items too. Set the filter to *Show and hide together* for this.

## How to set it up for two cameras

1. On the first scene, add **Link Visibility**, choose *Show and hide together*, and add that
   scene's camera under *Linked items*.
2. Under *Also in other scenes*, add the other camera (and the first one too, if it is in more
   scenes and should follow).
3. Any key or click that hides one now hides them all.
