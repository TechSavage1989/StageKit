# StageKit 0.1.0-beta48

Forty-eighth pre-release: **Active App**, a scene filter that shows the capture of the app you are
using. It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Active App (StageKit)**, a filter for a scene that has a Window Capture for each of several apps.
  Add it to the scene and add those captures to its list. One of them is shown at a time:
  - an app that opens is shown, and so is a capture you aim at another window;
  - clicking into one of the listed apps shows it, so with two open the capture follows you from one
    to the other (*Follow the app in use*; untick it and an app is shown when it opens and stays until
    it closes);
  - clicking into anything that is not on the list changes nothing: the last app stays captured;
  - when the app that is showing closes, the one you used before it comes back. When none is open,
    the first capture in the list is shown.
- **The change is a fade**, 250 ms to begin with. *Change with* offers every transition OBS has, a
  cut, or whatever is already set on each item, and *Lasting* sets how long it takes. This is OBS's
  own show and hide transition on each item, so it also appears in the item's right-click menu.
- **Keep the others ready**: while the scene is showing, the captures of the other open apps keep
  running, so the one you switch to has its picture at once.
- Which app a capture belongs to is read from the capture itself. There are no program names to type.

## Fixed by it

- In scenes set up with a *Show only one at a time* Visibility Link and a Program Trigger per app, the
  first capture stayed hidden after an app closed, and the capture did not follow you between two open
  apps. `scripts/upgrade-collection.py` replaces those filters with one Active App.

## Doing it by hand

On each window scene: open the scene's filters, remove *One window capture at a time* and the three
*Show … while it is open* filters, add **Active App (StageKit)**, and choose each capture in
*Captures to switch between*, the standby one first.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Windows only. A minimised window counts as closed.
- An app is matched by its program, not by one particular window of it.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
