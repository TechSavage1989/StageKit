# StageKit 0.1.0-beta62

Sixty-second pre-release: **Standby Picture**, a placeholder for a capture that has nothing to show.
It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Standby Picture (StageKit)**, a new filter for a Game Capture, Window Capture or other live
  source. While nothing is captured, a picture is shown in the capture's place, so there is no empty
  hole in the scene.
  - The picture is **the start image** unless you choose an image, a video or another source.
  - It fills the size the capture last had, so nothing moves when the capture arrives.
  - When the capture starts, the picture fades away.
  - "Nothing is captured" means no game or window is attached. A game that is captured and showing a
    black screen is left alone.
  - Switch it off and on with the filter's eye, or a Stream Deck filter key.

## Setting it up

1. Right-click the capture, choose *Filters*, press **+** under *Effect Filters* and pick
   *Standby Picture (StageKit)*.
2. Leave *Picture* on *The start image*, or choose a file or another source.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Before a capture has ever shown anything, the picture is 1920x1080; after that it takes the size
  the capture had.
- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
