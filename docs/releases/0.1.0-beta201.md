# StageKit 0.1.0-beta201

The dock's Place tab can set the bounds type of the selected sources and switch the scene's fit filters on and off.

## New

- **Bounds type in the dock.** The Place tab has OBS's own Bounds list (Automatic, Stretch, Fit, Cover, Fill Width, Fill Height, Maximum size only) for the selected sources. It shows their type, and a choice keeps each source its size and place on screen. One step in Undo. When a Fit to Space or Scene Fit fits the source, the status line says that filter may set the bounds again.
- **Auto-fit on or off.** One tick box switches every Fit to Space and Scene Fit filter of the scene being edited on or off. It is greyed out in a scene without them. There is a hotkey too, *StageKit: Auto-fit on/off*.
- **Auto-fit for the selected sources only.** Tick *Selected only* and Auto-fit acts on the selected sources' own Fit to Space filters and their entries in a Scene Fit, nothing else.
- **A Scene Fit entry can be switched off.** Each source in a Scene Fit has *Fit this source*. Unticked, it is left where it is and takes no room from the others.

## Good to know

- **Not seen in OBS on Windows yet.** The new controls were tested headless only.
