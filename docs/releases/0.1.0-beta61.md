# StageKit 0.1.0-beta61

Sixty-first pre-release: sources with StageKit's filters no longer look pale in the Filters window.
It passes the automated tests on Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **A pale, washed-out picture in the Filters window.** A source with *Shadow, Glow & Outline* or
  *Auto Frame* on it looked paler in OBS's Filters and Properties windows than on the canvas. Those
  two filters were missing a marker that tells OBS they handle colour properly, so in a window whose
  surface holds colour in a different form OBS drew them unconverted. The canvas, the stream and
  recordings were not affected. The Ambient Background source had the same fault and is fixed too.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- Guides are placed for a preview set to *Scale to Window*.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
