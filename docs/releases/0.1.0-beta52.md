# StageKit 0.1.0-beta52

Fifty-second pre-release: **Same in every scene**, *Ignore shadows & outlines* measuring each source's
own pixels, and a brought-along item that flips keeping its distance. It passes the automated tests on
Linux; **it has not been run in OBS on Windows yet.**

## What's new

- **Same in every scene**, a new Arrange tool, in the dock, the preview's right-click *StageKit* menu
  and *Settings → Hotkeys* (*StageKit: Same in every scene*). It works like OBS's *Copy Transform* and
  *Paste Transform*, for all your scenes at once:
  - select an item (or several) and use it;
  - every copy of that source in your other scenes gets the same place, size, rotation and crop;
  - a copy inside a group lands on the same spot of the screen;
  - locked copies are left alone;
  - it is one step in *Edit → Undo*.

## Changed

- **Ignore shadows** is now **Ignore shadows & outlines**, and measures only each source's own pixels.
  Shadows, glows, outlines, borders and anything else a filter draws are left out, whatever filter
  draws them. This applies to the line-up tools, the *Same* sizes, *Snap* and *Slide to the next edge*.
  When a source's filters change its size in another way (an Auto Frame does), the picture is measured
  as it is before its first shadow.

## Fixed

- **A brought-along item that flips to the other side kept a shadow's width too much distance.** Your
  screenshots showed it: with shadows on, the widget sat about 20 px further below the camera than it
  had sat above it. It was mirrored round the camera's whole box, shadow included; now it is mirrored
  round the camera's picture. This applies to the dock's arrows, slides, and Stream Deck keys that
  bring an item along.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- *Same in every scene* does not copy OBS's *crop to bounding box* setting.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
