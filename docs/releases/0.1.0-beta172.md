# StageKit 0.1.0-beta172

One fix to Ambient Background's mosaic on Windows.

## Fixed

- **Ambient Background with a mosaic was black on Windows until a blur had been switched on.**
  Since beta165 an Ambient Background with a mosaic drew nothing after OBS started, so the
  background was black and Scene Shadow's shadows, falling on black, could not be seen. Switching
  a Scene Blur or Blur on once brought it back for the rest of the session. The background now
  draws its mosaic from the start, whatever else is in the scene.
