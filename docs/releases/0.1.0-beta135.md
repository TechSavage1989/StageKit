# StageKit 0.1.0-beta135

One hundred and thirty-fifth pre-release: the start image is now called the Standby image. It
passes the automated tests on Linux; the Windows side has not run in a real OBS here.

## Changed

- **Start image is now Standby image**, everywhere you read it: the box and its button in the
  StageKit Background dock (*Standby image*, *Choose the standby image…*, *Use standby image as
  background*), *The standby image* in Ambient Background's and Standby Picture's lists, and the
  source in OBS's *Add source* list, *Standby Image (StageKit)*. Nothing else changes: it is the
  same image, your choice of it is kept, and a source you already added keeps the name you see on
  it in your scenes.
