# StageKit 0.1.0-beta135

One hundred and thirty-fifth pre-release: Auto Capture stops putting programs on Never capture by
itself, the start image is now called the Standby image, and 'picture' is 'image' everywhere. It
passes the automated tests on Linux; the Windows side has not run in a real OBS here.

## Changed

- **Start image is now Standby image**, everywhere you read it: the box and its button in the
  StageKit Background dock (*Standby image*, *Choose the standby image…*, *Use standby image as
  background*), *The standby image* in Ambient Background's and the Standby filter's lists, and
  the source in OBS's *Add source* list, *Standby Image (StageKit)*. It is the same image and
  your choice of it is kept.
- **"Picture" is now "image" everywhere**, as you asked: in every label, list entry and tooltip of
  the plugin, in the README, and in the Stream Deck plugin (the list on each key is *Image*, and
  the key is *Standby Image*). That includes the filter **Standby Picture, now Standby Image
  (StageKit)** in OBS's list of filters. A filter or source you already added keeps the name it
  has in your scenes; rename it in OBS if you want it to match. Nothing but words changed.

## Fixed

- **Dolphin kept coming back on Auto Capture's *Never capture* list.** When a Game Capture got no
  picture from a program for 10 seconds, Auto Capture put that program on *Never capture* for
  good. An emulator that is open with no game running gives no picture either, so Dolphin went on
  the list every time it sat idle, however often you took it off. Auto Capture no longer adds
  anything to your lists by itself. It now leaves such a program alone for a while and tries it
  again as soon as its window's title changes (which is what happens when a game starts), or
  after a wait that grows from 30 seconds to 5 minutes. A program that really cannot be captured
  is therefore still tried only now and then, not several times a second.
  **Take `dolphin.exe` off *Never capture* one last time**; this version will not put it back.
  The other names on that list were put there the same way: remove any you want captured.
