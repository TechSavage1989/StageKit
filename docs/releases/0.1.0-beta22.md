# StageKit 0.1.0-beta22

Twenty-second pre-release: the Windows installer. The installer is built by GitHub and **has not been
run on a real machine yet**; nothing in the plugin itself changes.

## What's changed

- **The installer shows where it installs and lets you change it.** A folder page now appears on every
  install and upgrade, starting at `C:\ProgramData\obs-studio\plugins\stagekit`, or at the folder you
  used last time. Use *Browse* to pick another.

OBS Studio only loads plugins from its own plugins folder, so keep the suggested folder unless your OBS
uses a different one. A portable copy of OBS keeps its plugins in `config\obs-studio\plugins\stagekit`
inside the OBS folder.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- If you choose a folder OBS does not look in, the plugin installs but OBS will not show it.
- Moving to a new folder does not remove the copy in the old one; uninstall first if you are moving it.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
