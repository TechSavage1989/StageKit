# StageKit 0.1.0-beta251

StageKit avoids repeated bounds measurements, Scene Fit list copies and eligible Scene Shadow blur passes.

## Changed

- **Visible-pixel placement.** Unfiltered sources with matching base and complete dimensions reuse their first bounds measurement, avoiding a second draw and graphics readback.
- **Scene Fit updates.** Scene Fit retains its entry list between ticks instead of copying the list and every entry reference each frame.
- **Scene Shadow with Scene Blur.** A single Scene Shadow layer can reuse its prepared shadow and glow when Scene Blur redraws it in the same frame, without keeping extra graphics textures.

## Good to know

- **Same appearance and controls.** Measurement accuracy, blur quality, settings, transitions and update timing stay the same. Scenes using other rendering paths keep their existing behavior.
- **Performance depends on the scene.** The changes remove repeated work in specific paths. The frame-time saving depends on the sources, filters and graphics hardware in use.
