# StageKit 0.1.0-beta147

One hundred and forty-seventh pre-release: one scene per layout, holding every capture.
Tested on Linux only.

## Added

- **Link Visibility: Lock hidden sources** (off as it comes). Each linked source is locked while it
  is hidden and unlocked when it is shown, so a click in OBS's preview cannot pick a hidden capture
  stacked under the one you see.
- **Show in Scenes: Follow what is shown** (off as it comes). The switch turns on or off to match
  what is actually shown, so a Stream Deck key's light stays true when something else changes the
  sources. Matching never shows or hides anything.
- **One scene per layout**: how to set up a scene that holds every capture with one shown, chosen
  by a key, is in the README. A script for this collection layout writes a trial copy with two
  such scenes added beside the old ones.

## Changed

- A source shown or hidden by Show in Scenes or Link Visibility in a scene that is **not on
  screen** now changes at once, without its transition. Before, the transition waited until the
  scene came on and brought a hidden capture to life for a moment, which opens a capture card.
- Show in Scenes acts on the next frame after a press; of several presses in one frame, the last
  counts.
- Fit to Space: a source that is showing but has no image yet (a display before its first frame, a
  capture card that is off) keeps its room, so the camera and chat box beside it stay put.
- Fit to Space: an item kept towards a side (*Align in the space*) with *Use visible pixels* is
  measured from that side. A window kept towards the left may sit slightly differently.

## Fixed

- Link Visibility could miss a source shown at the very moment it was hiding another, leaving two
  shown.
