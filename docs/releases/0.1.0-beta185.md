# StageKit 0.1.0-beta185

Pressing Update now shows what changed since your version, release by release.

## New

- **The Update button lists what changed.** Before installing, *Update* (in the dock, or *Update
  to … now* in OBS's Tools menu, StageKit) shows every release between the version you have and
  the one it is about to install, newest first: each with its one-line summary and the headlines
  of what it added, changed and fixed. Skipped a few versions? They are all there, up to fifteen,
  then a line saying how many earlier ones there were. *Yes* installs as before.

## Changed

- **What's new shows the same list** in a window of its own, instead of opening the browser. The
  window's *Release page* button opens the full notes on GitHub.

## Good to know

- The list starts with the next update after this one: the updater you have now is the one that
  installs this release, and it does not know how to show the list yet.
- Nothing is sent anywhere new: the notes come with the list of releases StageKit already reads.
- Not yet tried on Windows.
