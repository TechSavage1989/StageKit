# StageKit 0.1.0-beta97

Ninety-seventh pre-release: one fix to Fit to Space. It passes the automated tests on Linux.

## Fixed

- **An item shrank when Fit to Space was added to it, and stayed shrunk after *Resize it to fit*
  was unticked.** A new filter starts with *Resize it to fit* ticked, so the item was fitted to its
  space the moment it was chosen, and unticking the box then kept that fitted size. The filter now
  notes the size an item has before it first touches it, and unticking *Resize it to fit* gives
  that size back.

## For a filter that has already shrunk its item

The size from before was not saved by earlier versions. Once on this version, with *Resize it to
fit* unticked, drag the item back to the size you want in the preview: that is the size it keeps
from then on.
