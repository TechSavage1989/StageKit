# StageKit 0.1.0-beta124

One hundred and twenty-fourth pre-release: the new control names you approved, and a choice of
what *Capture Active Window* does with the window it picks. It passes the automated tests on
Linux; the Windows side has not run in a real OBS here.

## New

- **Automatic Window Switcher: Captured window.** *Wait until switched to* (now the default): a
  window picked with the Stream Deck *Capture Active Window* key becomes the manual window and is
  captured in the background while your automatic windows go on showing. Switch to it when you
  want with *Manual Window / Source* (*Toggle* or *Next*). *Switch at selection*: the capture
  changes to it straight away, as before.
- **Auto Capture and the Standby Picture.** With a Standby Picture filter on the same Game
  Capture: *No game: Standby Picture* shows the Standby Picture while no game is captured (also
  over a full-screen app it falls back to) and gives way when a game is found. *Hide shows
  Standby Picture* (on as it comes) makes hiding the capture bring the Standby Picture in over it
  instead of hiding it. Hide with the new *Hide/show capture now* button, the hotkey under the
  capture in OBS's hotkeys, or the Stream Deck *Manual Window / Source* key set to *Hide or show
  the capture* (it now lists Auto Capture filters too). These changes use Auto Capture's own
  *Transition* (fade, Morph, fade and zoom, cut, slides, wipes), *Duration* and easing.

## Changed

Labels in the filters' windows and the dock, shorter and in OBS's terms (*image* for picture,
*source* for item):

- **Fit to Space**: Ignored sources, Fit area, Free space around source, Gap, Move duration,
  Resize to fit, Align in the space, Sync position to scenes, Size tolerance.
- **Move Source / Move Scene Item**: Linked source, Destination, Duration.
- **Show/Hide Animation**: Direction, Show duration, Hide duration.
- **Blur**: Blur transition, Blur-in duration, Blur-out duration. **Zoom**: Zoom-in duration,
  Zoom-out duration.
- **Ambient Background**: Live capture, Live capture opacity, Bloom threshold.
- **Auto Frame**: Aspect ratio, Saved aspect ratios, Keep aspect ratio for.
- **Shadow, Glow & Outline**: Colour source (*The image itself*), Sizes in screen pixels.
- **Standby Picture**: Cover the capture now, Duration: image to capture, Duration: capture to
  image, Keep image's aspect ratio, Animate the size change.
- **Automatic Window Switcher**: Hide shows Standby Picture, Hide/show capture now.
- **Dock**: Move to, On drop.
