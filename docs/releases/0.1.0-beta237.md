# StageKit 0.1.0-beta237

Show in Scenes now moves linked sources through the same screen edge as their primary when both use Make Room.

- Turn on **Move's linked sources too** to carry a widget, label or other linked source with its primary. They leave and return through the primary's edge and travel far enough for both to clear the canvas.
- With matching durations the linked items begin on the same frame and follow the primary's easing, even when the widget has different easing of its own.
- This also applies when **Show only what it hid** restores the linked items.
