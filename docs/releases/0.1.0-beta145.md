# StageKit 0.1.0-beta145

One hundred and forty-fifth pre-release: Morph goes by what shows. Tested on Linux only.

## Changed

- **Morph matches two different sources by their visible pixels, not their boxes.** When one
  source changes into another (linked sources, the main images, a source and its standby
  image), the empty room around each (a shadow's side, a transparent border, a group wider than
  its contents) is now left out, so the one image lands exactly on the other instead of
  drifting or changing size on the way. It applies to Morph between scenes and to Morph as a
  show/hide transition.
  - New tick box in Morph's settings: **Use visible pixels**, on as it comes. Untick it for the
    old behaviour, box into box.
  - Each of the two is looked at once as the change begins. The same source in both scenes is
    unaffected.
