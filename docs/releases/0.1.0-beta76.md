# StageKit 0.1.0-beta76

Seventy-sixth pre-release: a way to see what drops frames, and calmer moves. It passes the automated
tests on Linux; **it has not been run in OBS on Windows yet.**

## Changed

- **Fit Item's "The free space around it" waits for a move to finish.** When the camera (or anything
  else) moves, the fitted item now stays as it is until the move has ended and then takes its new
  space in one glide. In beta74 and beta75 it followed the moving item, which resized the game, and
  redid its shadow, on every frame of the move.

## New

- **A timing log.** StageKit now keeps time of each of its filters and sources. Twice a minute,
  anything that took long is written to OBS's log as a line beginning `timing, last 30 s:`. While
  everything is quick it writes nothing. It is there so that a log from a session with dropped
  frames says which part to fix, instead of guessing.
