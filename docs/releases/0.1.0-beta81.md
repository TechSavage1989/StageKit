# StageKit 0.1.0-beta81

Eighty-first pre-release: a key that hooks a capture onto the window or game in front. This one
changes **both** the OBS plugin and the Stream Deck plugin; install both. It passes the automated
tests on Linux; **the hook has not been run on Windows yet.**

## New

- **Hook capture**, a new Stream Deck key. Choose a Game Capture or a Window Capture in the key's
  settings. Bring a game or a window to the front and press the key: that capture now takes it.
  - A tick shows on the key when OBS has taken it; a warning triangle when it could not (nothing in
    front, OBS itself in front, or OBS not reachable).
  - If the capture has an **Auto Capture** filter, the key switches it off, so the capture stays on
    what you hooked instead of being aimed somewhere else a moment later.
  - To hand the capture back to Auto Capture, switch that filter on again: a *Filter switch* key for
    it, set to *Switches it on*, does that.
- **Pictures for it**: "hook game" and "hook window", in all six palettes. The key picks the one that
  fits the kind of capture; both are also in the *Picture* list under *capture*.
- For other remote controls, the same thing is the `HookFront` request (see the README).

## Good to know

- A *Filter switch* key already switches Auto Capture (and every other StageKit filter) on and off,
  with its own picture.

## Please check

1. Install the OBS plugin from this page, and the Stream Deck file over the one you have.
2. Put a *Hook capture* key on the deck, choose your Game Capture, bring a game to the front and
   press it: does the capture take the game?
3. The same with a Window Capture and a window.
4. Does it stay hooked, and does switching Auto Capture back on hand it back?
