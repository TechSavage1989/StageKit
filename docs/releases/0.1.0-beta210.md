# StageKit 0.1.0-beta210

Square and the other shaped outline corners line up with their sources on Windows, and text keeps an outline that follows it.

## Fixed

- **Shaped outline corners line up on Windows.** With *Square*, *Rounded*, *Bevel*, *Notch* or
  *Scoop*, lines on Windows could sit off their sources, shifted to one side or with no bottom
  side. They now go evenly round each source again, in bounding boxes of any alignment, in groups
  and nested scenes, and on large sources drawn small.
- **Text keeps an outline that follows it.** Text, logos, groups with gaps and other sources that
  fill well under their rectangle, and turned sources, now keep an outline that follows their
  shape instead of getting a box round them.

## Good to know

- **Only run on OpenGL.** The fix is for Direct3D, but the shaders have only been run on OpenGL
  here; it has not been seen on Windows.
