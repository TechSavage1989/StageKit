# StageKit 0.1.0-beta128

One hundred and twenty-eighth pre-release: Fit to Space moves with the Automatic Window Switcher's
change of window, not after it. It passes the automated tests on Linux; the Windows side has not
run in a real OBS here.

## Fixed

- **The fit lagged behind a window switch.** When the Automatic Window Switcher changed to a window
  of another shape, Fit to Space only noticed the shape changing, waited for it to settle, and then
  set off on its own glide to the new space: the window switched and the fit caught up afterwards.
  The switcher now tells Fit to Space the shape it is changing to the moment the new picture comes
  in, and the fit glides to that shape's space over the switcher's own *Duration* and easing. The
  picture and its place arrive together.
