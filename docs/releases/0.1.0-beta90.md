# StageKit 0.1.0-beta90

Ninetieth pre-release: programs can be told apart by their window's title, for two programs with
the same file name (Dolphin and PrimeHack, both `Dolphin.exe`). It passes the automated tests on
Linux; the Windows side has not run here.

## New

- **Auto Frame, *Shape for each program*:** the list is now *Program or window* and also offers the
  titles of the windows that are open. Pick a title (you can shorten it: `primehack` is enough),
  choose its shape and press *Remember this shape*. When several saved shapes fit a window, the one
  with the longest name is used, so `primehack = 16:9` wins over `dolphin = 4:3` for a PrimeHack
  window and the plain Dolphin window keeps 4:3.
- **Follow Active App:** two captures aimed at programs with the same file name each follow their
  own window, by its title. Nothing to set: it goes by the window each capture was aimed at.
- **Auto Capture:** *Never capture* and *Always capture* also take part of a window's title.
- Program Trigger already had *Window title contains*.

## Not changed

- What Auto Frame learns by itself (the shape a program had last time) is still kept by file name.
  For two programs that share one, save a shape for the title of at least one of them.
