# StageKit 0.1.0-beta238

Open **Tools > Quick Access Utility (StageKit) > New Dock** and choose a dock type.

- **Manual** lets you pick several sources, scenes or groups at once and arrange them with the up and down buttons.
- **Dynamic** follows the current Program scene and includes sources inside nested scenes and groups.
- **Source Search** searches the whole collection as you type. Results are grouped by source name, source type, file path, URL and filter. Assign **Opens Quick Search** in OBS Hotkeys for a floating search window.

Each row can show Properties, Filters and Parent Scenes. Parent Scenes has a visibility switch and an Edit Transform button for each occurrence. Right-click a source for its available OBS actions. Clickable Scenes sends a scene to Preview when Studio Mode is on.
