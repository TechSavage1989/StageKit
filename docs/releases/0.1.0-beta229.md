# StageKit 0.1.0-beta229

The StageKit Stream Deck plugin 0.34 organizes key settings and gives capture, scene and blur keys more precise controls.

## New

- **Match Item and Scene Transitions keys.** Each key selects a filter on a scene and shows whether it is enabled.
- **Restore the OBS transition.** Switch Scene can put the previous transition and duration back after a live switch. Restoration has been tested against a headless WebSocket server. A visual check in OBS is still pending.
- **More key images and ratios.** Set Aspect Ratio includes 16:15. Scene Shadow and Scene Corners offer style choices. Show/Hide Animation has direction images, and transition image lists include Make room.

## Changed

- **Find the controls for a key.** The first rows choose its target and action. The open Image section contains its style, layout, type and palette where applicable. Long-press and other conditional rows appear when relevant.
- **Choose what Blur All does.** Toggle, Switch on and Switch off work across the blur filters included in Blur All. Scene Mode starts with the mode in Mode settings or the filter's first mode.

## Fixed

- **Control the chosen capture.** Manual Window / Source targets the selected source or scene even when two filters share a name. Its action list follows the controls available on that filter.
- **Show the active scene and position.** A Preview key follows the live scene when Studio Mode is off. A Move key title follows its selected position. Apply Layout, Snap Now and Fit Now have distinct titles.
