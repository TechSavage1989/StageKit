# StageKit 0.1.0-betaNEXT

Stream Deck keys say which filter they work, and a Standby Image can cover any source, a camera too.

## New

- **Keys name their filter.** On every Stream Deck key that works a filter, the list is now called
  *Source and filter* (*Scene and filter* for a filter on a scene) and each entry reads *source —
  filter*, the filter's name as OBS's Filters window shows it: *Square Camera — Show in
  Scenes-Camera*. A line under the list, and its tooltip, say which kind of filter to look for in
  OBS. The Scene Mode key's list names the Scene Modes filter too. Keys you made keep working.
- **Standby Image over any source.** The **Standby Image** key's *On press* has three more choices:
  *Cover: toggle*, *Cover with image* and *Uncover*. They show the filter's image over the source now,
  whatever the source shows (a camera, a capture card, a display capture), with the filter's own
  transition, and the key is lit while the image covers it. No Automatic Window Switcher is needed.
- **Show in Scenes: Hide shows Standby Image** (off as it comes). Ticked, a press that hides the
  sources covers each one that has a Standby Image filter with its image instead, and the press that
  shows them takes the image away. Its items stay where they are, so nothing round them moves.
- **Show in Scenes key: When hiding.** One Show in Scenes filter can serve several keys, each with its
  own way: *As the filter says* (as it comes), *Hide the sources* or *Cover with Standby Image*.
- **Show in Scenes: Show only what it hid** (off as it comes). Ticked, a press that hides notes
  exactly what it hid, and the next press that shows brings back only that, and only while it is
  still hidden. A camera view that was already hidden (a full-screen camera kept for another
  layout) stays hidden, so a Link Visibility never reacts to it, and nothing hidden by anything else
  is ever shown. The switch then means "has hidden things", so a toggle key always hides and then
  restores; tick *Follow what is shown* too to keep its light true. The notes are kept when OBS
  restarts.
- Remote control: `StandbyCover`, `GetStandbyCover`, `ShowInScenesPress` and the
  `StandbyCoverChanged` event.

## Good to know

- The cover belongs to the source the Standby Image filter is on, so every scene and every Cropped
  View of that source shows the image. To cover one view only, put the filter on that view.
- A Standby Image filter that is switched off cannot cover: switch it on first.
