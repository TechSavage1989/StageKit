# StageKit 0.1.0-betaNEXT

The Automatic Window Switcher no longer shows a window that is not on its lists, and Clear picked windows clears both lists.

## Fixed

- **No more unlisted windows on screen.** With none of the listed windows open, the switcher
  could show whatever window the capture found by itself, such as another Firefox profile's
  window, even one on *Ignored windows*. Now nothing of the capture is shown then: the Standby
  Image stands in if the capture has one, and the status line says *Capturing nothing*. The
  capture is also no longer left aimed where OBS could pick up such a window by itself.
- **Clear picked windows clears both lists.** The button, its hotkey, the Stream Deck key and
  *Clear picked windows on exit* now take picked windows off *Windows to switch between* as well
  as *Manual windows*. A picked window being shown is let go of: the capture goes on to the next
  automatic window, or shows the Standby Image.
- **Firefox titles work in the lists.** A Firefox window's title (with its long dash) chosen for
  a list was taken for a picked window and matched nothing, so an ignored Firefox title did not
  ignore anything. It now matches by title like any other.

## Unchanged

- Programs and titles you added to the lists yourself stay when you clear picked windows.
- Switching between listed windows works as before.
