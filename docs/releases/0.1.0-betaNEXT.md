# StageKit 0.1.0-betaNEXT

Scene Shadow can give each source its own shadow, and Scene Corners can shape the whole scene.

## Added

- **Scene Shadow: Shadow from.** A new choice on Scene Shadow:
  - *The scene as drawn* (as it comes, and what every Scene Shadow you already have keeps doing):
    sources that overlap make one shape with one shadow and one outline round it, and a shadow
    never falls on another source.
  - *Each source by itself*: every source gets its own shadow, glow and outline, as a Shadow, Glow
    & Outline filter on each source would give it. A source's shadow falls on whatever lies under
    it, other sources included (a camera's shadow on the game under it), and the sources above it
    cover it. With the same settings it looks the same as a Shadow, Glow & Outline on each source.
    With a Scene Blur that blurs each source by itself, each shadow follows its source's blurred
    shape, as before.
- **Scene Corners: Corners on.** A new choice on Scene Corners:
  - *Each source* (as it comes, and what every Scene Corners you already have keeps doing): each
    source gets a Corners & Edges filter.
  - *The whole scene*: the scene's own image gets the look at the edges of the screen, as one shape
    (rounded or cut corners, softened edges, a line round it). The sources inside are left as they
    are and get no filter; the filters Scene Corners had added are taken off a few seconds later,
    and come back if you choose *Each source* again.
- **Morph carries both.** A change of scene with Morph still moves each source from one place to
  the other with *Each source by itself* (each shadow goes with its source) and with *The whole
  scene* (the corners go part-way from one scene's shape to the other's).

## Fixed

- Scene Corners' window now shows **Which corners** (the four tick boxes), which it had been missing.

## Good to know

- *Each source by itself* costs the same as *The scene as drawn* while no sources overlap. Each
  pile of overlapping sources (counting their shadows) takes a few more passes on the graphics card.
- A change of scene between a scene shadowed *The scene as drawn* and one shadowed *Each source by
  itself* is a cross-fade instead of a morph, and the OBS log says so.
- With *The whole scene*, Scene Corners moves itself after a Scene Shadow or Scene Blur in the
  scene's filter list, so that the shape is cut last. Sizes are screen pixels.
- The new drawing has only been run on OpenGL. If Windows logs an error about
  `stagekit-scene-shadow.effect` or `stagekit-corners.effect`, please send the log.
