# StageKit 0.1.0-betaNEXT

Countdown Timer shortcuts now set the timer 15, 30, 45 or 60 minutes from the press, with clock time as a choice per timer.

## New

- **Shortcuts count from the press.** The quick marks in the StageKit Timer dock, the date and time picker and the Stream Deck Countdown Timer key now end the timer 15, 30, 45 or 60 minutes after you press them, so the timer starts at exactly 15:00, 30:00, 45:00 or 60:00. The Cycle key steps through +15, +30, +45 and +60 minutes and its hold still starts or stops without advancing.
- **Clock time is a choice for each timer.** In **Timer settings**, **Shortcut marks** offers **Clock time (:15, :30, :45, :00)** to set the timer to the next :15, :30, :45 or :00 on the clock, as before. The dock, the picker and Stream Deck keys name the marks the way the timer counts.
- **A Stream Deck key can decide for itself.** The Countdown Timer key's new **Count from** list is **As the timer says** as it comes, or **From now** or **Clock time** for that key alone. Keys show **+15m** to **+60m** for minutes from the press and **:15** to **:00** for clock time. Stream Deck companion 0.44.0.0.

## Good to know

- Existing timers and keys now count from the press. To keep :15, :30, :45 and :00 on the clock, choose **Clock time** in that timer's **Timer settings > Shortcut marks**, or set the key's **Count from** to **Clock time**.
- While a timer counts from now, the quarter-hour mark is left out of the dock's list and the picker, because it is the same as 15 minutes. A Stream Deck key set to **Quarter hour** sets 15 minutes.
- An older StageKit OBS plugin keeps clock marks whatever the key says; its keys keep showing **:15** and so on. Update the OBS plugin and the companion together.
