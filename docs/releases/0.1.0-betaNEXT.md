# StageKit 0.1.0-betaNEXT

Three fixes to Scene Blur and the mosaic's whole cells.

## Fixed

- **Whole cells no longer cut the screen's edge.** With Scene Blur's *Each source by itself* and
  *Whole cells*, a full-screen background (an Ambient Background, say) lost the cells along every
  edge of the screen, leaving a black notched border round the whole picture. Now a cell is left
  out only where a source's own edge lies inside the screen; where a source reaches or runs past
  the screen's edge, its cells there are kept, since the screen cuts them anyway. The edges a
  smaller source has inside the screen are still whole cells.
- **Whole cells is only used where it is offered.** Choosing *Whole cells* and then switching
  *Blur area* back to *The scene as drawn* kept the notched border, although the setting is hidden
  in that mode. Scene Blur now ignores *Mosaic edge* unless *Blur area* is *Each source by itself*.
- **No gap between a blurred source and its shadow or outline.** With *The scene as drawn*, the
  cells (or the soft blur) along a blurred source's edge mixed in the background round it, so a
  lighter band stood between the source and its shadow, outline or glow. The blur now takes in
  only what lies where the blurred sources show. With *All sources* the background is blurred too,
  so along a source's edge the two still mix as the scene shows them; *Each source by itself*
  keeps every source apart.

## Good to know

- The Blur filter on a source cannot know where that source sits on screen, so with *Whole cells*
  on a full-screen source it still leaves out the cells along the screen's edge. For a full-screen
  source, use Scene Blur with *Each source by itself*.
- The new shader code has only been run on OpenGL. If Windows logs an error about
  `stagekit-looks.effect`, please send the log.
