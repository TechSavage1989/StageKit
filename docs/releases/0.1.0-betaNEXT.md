# StageKit 0.1.0-betaNEXT

Scene Modes can now hide other sources when a mode comes on, and leave a mode when a source is
shown. Together they replace the transparent marker sources that kept a full-screen camera and a
column of windows apart.

## New

- **Hide when on**, in each mode's group of Scene Modes: sources hidden in the scene when that mode
  comes on, with the mode's transition. They are not part of the mode, so another mode coming on
  does not show them again.
- **Leave when shown** and **Leave to**, in each mode's group: while the mode is on, showing one of
  these sources (a Stream Deck key, Show in Scenes, Link Visibility, or the eye) turns another mode
  on: *The mode before* (as it comes), *No mode* (when *Allow no mode* is ticked) or a mode you
  choose. The source you showed stays shown.

## Your Component-Capture-Scene without the column markers

1. Open the Scene Modes filter on Component-Capture-Scene and find *Mode: GBA*.
2. Under *Hide when on*, add **DSLR**.
3. Under *Leave when shown*, add **DSLR**, and set *Leave to* to **Chat**.
4. Remove the filter **Link Visibility-GBA**.
5. Take **Column: Chat** and **Column: GBA** out of the Chat and GBA modes, and out of the following
   sources of **Link Visibility-CaptureChat**.
6. Delete the two sources **Column: Chat** and **Column: GBA**.

Now GBA mode hides the full-screen DSLR when it comes on, and showing DSLR while GBA is on switches
back to Chat, with DSLR staying shown. Going back to Chat by a key does not show DSLR.

## Unchanged

- A filter saved before works as it did: the new lists start empty.
- A mode's own sources, the hotkeys, the Stream Deck Scene Mode key and *Switch to scene* behave as
  before. Leaving a mode because a source was shown never changes scene.

## Good to know

- If a source is in both a mode's *Leave when shown* and the next mode's *Hide when on*, it stays
  shown when it makes the switch, so the two modes never flip back and forth. The OBS log says so.
- Not yet tried on Windows.
