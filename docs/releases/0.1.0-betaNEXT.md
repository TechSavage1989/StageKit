# StageKit 0.1.0-betaNEXT

The Scene Mode key's settings are shorter: pick a mode, then set it.

## Changed

- **Stream Deck: the Scene Mode key's page** (Stream Deck plugin 0.28.0.0). Under *Scene Modes*,
  *Mode settings* picks one of the filter's modes (the key's own mode as it comes), and that mode's
  *Use in Next*, *Layout* and *Image* are right under it. Pick another mode to set its own. What
  the key does (*On press*, *Switch to mode*, *Long press*, *Long press mode*, *Hold time*,
  *Palette*) is under *Key* below. The page no longer has a second Layout and image list for the
  whole key.

## Good to know

- **Keys you already have look the same.** A key set up with one *Layout* or *Mode type* for the
  whole key keeps it: that Layout stays behind every mode that has none of its own, and that Mode
  type behind the key's own mode, where its *Image* now shows it. Change that *Image* to replace it.
- Nothing changed in the OBS plugin. Not yet tried on a Stream Deck.
