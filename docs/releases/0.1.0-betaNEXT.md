# StageKit 0.1.0-betaNEXT

Make room if not filling can now make room only when the image would really overlap a source.

## New

- **Only if it would overlap.** A new tick box under *Make room if not filling*, in Fit to Space
  and in each Scene Fit source's settings. Ticked, a source fitted to the whole screen (or a box)
  makes room only when its image, fitted there, would actually overlap one of the *Make room for*
  sources. A camera that lies wholly in the empty bar beside a narrow image is left alone and the
  image keeps the whole screen. Unticked, as it comes, nothing changes.

## Good to know

- **What counts as overlapping.** It goes by what shows of each source, as *Use visible pixels* and *Ignore shadows &
  outlines* say. Edges that only touch and the gap do not count, and a source that draws nothing
  is not there.
- **It does not flip.** It is worked out from the image's shape and where the screen would put it, so the image does
  not go back and forth once it has made room.
