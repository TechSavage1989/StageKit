# StageKit 0.1.0-betaNEXT

Auto Capture picks up a game within seconds while it is leaving a program alone, with little hooking.

## Fixed

- **A game started in an emulator is picked up within seconds.** While Auto Capture leaves alone a
  program that gives no image (an emulator with no game running), it now looks in on it for one
  second every five seconds, instead of waiting 20 seconds to a minute. A game started meanwhile is
  picked up within about five seconds, and the capture stays on it. After a minute of looks that
  find nothing they come up to 15 seconds apart.
- **OBS's hooking stays low.** The capture is aimed at the program about a sixth of the time while
  it is left alone (under ten seconds a minute in the tests), against all of it before beta184.
- **A new window title or clicking back in tries again at once.** Before, neither counted in the
  first ten seconds of a wait, and a new title only three times. Now either one tries again at
  once, for the full ten seconds. A frame rate or a volume in a title changing still does not count,
  and a title counts only once.

## Good to know

- The OBS log says `leaving it alone, looking in for 1.0 s every 5 s` once for each wait; the looks
  themselves are not logged. A look that finds the game says `has a picture from ..., looked in on
  while it rested`.
- With *No game: Standby Image*, the image stays up during the looks.
- Not yet tried on Windows.
