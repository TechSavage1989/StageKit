# StageKit 0.1.0-betaNEXT

An animated standby image, such as a GIF, now plays everywhere it is shown.

## Fixed

- **Animated standby images play.** A GIF chosen as the standby image now moves in the Standby Image source, in every Standby Image filter (also the image shown in a hidden source's place and those Scene Standby adds), in Ambient Background and in the dock's small image, which keeps its zoom. Still images are shown as before.

## Good to know

- Tested on Linux only; not yet seen on Windows.
