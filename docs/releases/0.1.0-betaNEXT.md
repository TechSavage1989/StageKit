# StageKit 0.1.0-betaNEXT

Clearer names and tooltips across the plugin: "source" instead of "item", one name for each thing, and hotkeys named one way. Nothing behaves differently.

## Changed

- **"Source" instead of "item".** Every label, tooltip and dock message that still said *item*
  says *source*: *Source to move*, *Sources to show*, *Only these sources*, the dock's *Source* row,
  *Keep each source's own* in the transition lists. Filter names such as Move Scene Item stay.
- **Hotkeys named one way.** In OBS's Settings, StageKit's hotkeys read "StageKit: *the filter's
  name*: *what it does*", for example "StageKit: Camera Blur: toggle" or "StageKit: Modes: switch to
  Starting". Your key bindings and Stream Deck keys are untouched.
- **Move Source and Move Scene Item.** *Edge distance* is *Gap*, here and on the dock's Place tab.
  The destinations *A saved spot* and *A spot on the screen* are *Saved position* and *Screen
  position*, the button is *Save current position*, and every control has a tooltip.
- **Corners & Edges has a Border.** Its line is drawn inside the edge, so it is called *Border*, not
  *Outline*, and is no longer mixed up with Shadow, Glow & Outline's outline. The same in Scene
  Corners. *Sizes as seen on screen* is *Sizes in screen pixels*, as in the shadow filter.
- **Auto Frame speaks of aspect ratios.** *4. Aspect ratio for each program*, *Start from usual
  ratios*, *Forget ratios seen before*, *Remember this ratio*. The control that stretches the image
  is *Display shape*, with a tooltip, so "aspect ratio" means one thing. Aspect Ratio Preset's help
  points to the Stream Deck *Set Aspect Ratio* key, which needs no filter.
- **Transitions.** In *Show/Hide transition* the two sliders are *Show duration* and *Hide duration*,
  and the tooltips start from *As the scene sets*. Morph's two settings for sources with no partner
  are *Unpaired: scene change* and *Unpaired: show or hide*, and Morph's own entries in that list
  read *Morph: fade*, *Morph: fade and zoom* and *Morph: slide off nearest edge*, so there are no
  longer two entries called "Fade". Make Room's first choice is *Away from the morph*.
- **Automatic Window Switcher.** The transition for a change of window is *Switch transition* and
  *Switch duration*, apart from the hide's *Transition*. The *Manual windows* tooltip uses today's
  names and lists all five hotkeys.
- **Standby Image.** *Cover the capture now* is *Cover the source now*, since it works on a camera
  too; its hotkey reads "cover or uncover". The three *Hide shows Standby Image* tick boxes have
  matching tooltips that say how they differ from *Show when source is hidden*.
- **Scene filters.** Scene Fit's own list of sources it leaves alone is *Never fitted* (*Ignored
  sources* in a fit now only means "may be covered"); its settings choice reads *Settings are: Each
  source's own / Shared by all sources*. Scene Blur's lists are *Sources covered* and *Chosen
  sources*, like the other scene filters. A background is described one way: "covers 90% of the
  screen or more". Tooltips say where a group counts as one source.
- **Blur, Zoom, Cropped View, Ambient Background.** Blur's type *Zoom (radial)* is *Radial (zoom
  blur)*; the centre is *Centre X* and *Centre Y* in Blur and Zoom. Zoom, Show/Hide Animation and
  Cropped View have tooltips. Cropped View's *Show* is *Source*, *Whatever is drawn* is *Visible
  pixels*. Ambient Background's *Blur* and *Mosaic size* are *Blur strength* and *Cell size*.
- **Link Visibility.** Its tooltips no longer say a Show in Scenes switch that is off keeps
  followers hidden (that changed in beta174), and *Follow sources* points to Scene Modes for modes.
- **The dock and the Tools menu.** Each arrange tool has one name in the dock, the menu and the
  hotkeys (*Align left*, *Space out across*). *Resize limit* is *Resize gap*. One message, "Select a
  source in OBS's preview first." The Effects buttons and the Keys box explain themselves. The
  Tools menu entries are spelled out: *Check for updates when OBS starts*, *Restore layout when a
  collection loads*, *Save layout when OBS closes*.
- **Shorter tooltips.** Several very long tooltips are cut to what happens and when to use it;
  percentages are written "50%" everywhere.
- **Help texts and the guide** name StageKit's own Stream Deck keys first and Elgato's Filter key as
  the alternative, and the guide's labels match the windows.

## Good to know

- **Saved settings are unchanged.** Only words changed: no setting, hotkey binding or Stream Deck
  key is affected.
- **A filter already on a source keeps its name.**
- **The Stream Deck plugin's own wording** follows in a later release.
