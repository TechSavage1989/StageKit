# StageKit 0.1.0-betaNEXT

Every Stream Deck key now says at the top of its settings what it works with in OBS.

## New

- **Works with, first on every key.** The first row of every StageKit key's settings says what
  the key works with: the kind of filter exactly as OBS's Filters window names it, such as
  *Source Filter: Show in Scenes (StageKit)*, or the feature, such as *OBS scenes*, *OBS
  streaming* or *StageKit dock: Arrange tools*. It is plain text, not a control.
- **The filter the key is set to, right under it.** Once a source and filter are chosen, the row
  says which, such as *Square Camera — Show in Scenes-Camera*, and *(choose one below)* until then.
  It is filled in by the key itself, so it says the saved choice with OBS closed too.
- **The chosen filter's own kind.** A key that can work several kinds of filter (Manual Window /
  Source, Fit to Space Overlap) names the kind of the one chosen while OBS is connected.
- **Not found in OBS.** A key set to a filter, capture or scene that OBS no longer has (renamed or
  removed) says *(not found in OBS)* after it: choose it again.

## Changed

- **No more line under each key's list.** The line that named the kind of filter is gone: the
  Works with row at the top says it now. The list keeps its tooltip, and its entries still read
  *source — filter*.

## Good to know

- Keys you made keep working: nothing they save has changed.
- Stream Deck plugin 0.32.0.0. Not yet tried on a real Stream Deck.
