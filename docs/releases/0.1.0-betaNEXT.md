# StageKit 0.1.0-betaNEXT

A Stream Deck release: two new keys, **Stream** and **Record**, with moving images. The OBS
plugin is the same as in beta166.

## New

- **Stream key.** Starts and stops OBS's stream. *On press*: *Toggle (start or stop)*, *Start
  streaming* or *Stop streaming*. It has no Pause: OBS can pause a recording, but not a stream.
- **Record key.** Starts, stops, pauses and resumes OBS's recording. *On press*: *Toggle (start
  or stop)*, *Start recording*, *Stop recording*, *Pause / resume*, *Pause* or *Resume*.
- **Moving images**, in your key's palette, while something is happening:
  - Stream: an antenna when stopped; waves appear while it starts, pulse out while live, flicker
    while it reconnects, and fade one by one while it stops.
  - Record: a hollow red dot beside a strip of film when stopped; the dot fills while it starts,
    pulses with the film running while recording, shows slowly pulsing pause bars while paused,
    and empties while it stops.
  The record dot is red in every palette. *Animate* *Off* gives a still image.
- **Long press** on both keys. Leave it on *Nothing* and the key works the moment you press it.
  Choose an action and holding the key for the *Hold time* (800 ms as it comes) does that
  instead; a short tap still does *On press*. For example *On press* *Start streaming* and *Long
  press* *Stop streaming*, so a stray tap never ends your stream. A bar fills under the image
  while you hold.
- **Titles** say what a press does and, while live or recording, the time (*Show time* can turn
  it off), plus *Hold: Stop* when a long press is set. A title you type in Stream Deck still wins.
- Both keys show the green dot while live or recording, like the other keys, and have the
  *Layout* and *Scene type* lists: with a scene type chosen, the key shows that type with a small
  badge saying whether it is live or recording.

Both keys use OBS's own WebSocket requests, so they work with any StageKit version in OBS.

Install the Stream Deck plugin again from this release (`StageKit.streamDeckPlugin`); keys keep
their settings.
