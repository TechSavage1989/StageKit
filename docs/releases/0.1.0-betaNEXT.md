# StageKit 0.1.0-betaNEXT

Outlines stay with their sources through a change of scene, and a full-screen game can be the main image a Morph changes into.

## Changed

- **Morph the main image now takes a full-screen source.** A source filling the screen was always
  treated as a background and cross-faded. When it lies over another full-screen source (a game
  capture over a shared background, say), it is now the scene's main image: the other scene's main
  image grows into it and back. A full-screen source with nothing under it is still a background.

## Fixed

- **No more holes or see-through outlines during a change of scene.** With Scene Shadow in both
  scenes, the outline of a source that fades or slides out was laid over both scenes' images at
  once: the other scene showed through the line, and in beta211 the line vanished wherever the
  other scene's sources stood. Each scene is now drawn with its own outlines and shadows first and
  the two are then blended, so a line is exactly as solid as its source all the way.
- **A source fading out while another fades in over it keeps its outline.** In beta211 the outline
  of the one going was missing under the one coming in.

## Good to know

- Tested on OpenGL only. The change adds shader code that has not yet run on Windows (Direct3D);
  should outlines or a change of scene look wrong after updating, please send the OBS log.
- With *Other items* set to Slide, Zoom or Fade, sources fade as they go, and so do their
  outlines. To keep them solid while they move, choose *Make room* and leave *Fade while moving*
  off.
