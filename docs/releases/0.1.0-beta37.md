# StageKit 0.1.0-beta37

Thirty-seventh pre-release: one blur key for several sources. It passes the automated tests on Linux;
**it has not been run in OBS on Windows yet.**

## What's new in Ramp Blur

- **Blur these too.** In the filter's settings, choose a source and press *Add it to the list*, once
  for each. Switching that one filter on or off, from a single Stream Deck *Filter* key, then blurs
  and clears every source in the list. A listed source with no Ramp Blur of its own is given one with
  the same settings; one that already has a Ramp Blur keeps its own.
- **And live captures on screen.** Tick this and every game, window, screen and camera capture
  showing in the scene on screen is blurred too at the moment the filter is switched on, and cleared
  with it. This part could not be tested here (the test machine has no captures).
- **Tidier settings.** The controls are in four groups: *Blur*, *Timing*, *Blur these too* and
  *Keys*. The long paragraph at the bottom is now a tooltip, and the three test buttons are one,
  *Blur on / off now*.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
