# StageKit 0.1.0-beta75

Seventy-fifth pre-release: more against the lag, and one option asked for. It passes the automated
tests on Linux; **it has not been run in OBS on Windows yet.**

## Fixed

- **Fit Item's "The free space around it" worked on scenes nobody was looking at.** Every scene's
  filters run all the time, so a Fit Item set to the free space kept looking at its scene's items
  even while another scene was on screen, and each look holds the picture up for a moment. It now
  does nothing unless its scene is being shown. Together with beta74 (which made it look far less
  often and never while things move) this should take away the dropped frames it caused.

## New

- **Show in Scenes: "Bring-along items too"** (off as it comes). Ticked, the items the listed
  sources bring along are shown and hidden with them: the items chosen under *Bring along* in those
  sources' Send To keys, and in Place Item filters that move them.

## Please check

1. With a game running, open View → Stats: is *Frames missed due to rendering lag* still climbing?
2. If it is, send the OBS log of that session (Help → Log Files → Show Log Files).
