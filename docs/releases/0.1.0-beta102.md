# StageKit 0.1.0-beta102

One hundred and second pre-release: the copy-transform tools and Fit to Space work together. It
passes the automated tests on Linux.

## Fixed

- **Copy transform to all scenes / to chosen scenes did nothing to a copy that a Fit to Space
  filter looks after.** The filter put the item straight back, above all in scenes that were not on
  screen. The copy tools now hand the item over to the filter: it takes the copied place as its
  own, and with *Resize it to fit* unticked the copied size as well. A filter that resizes its item
  fits it again around the new place.

## New

- **Copy tab: *Also change locked copies*** (off as it comes). Ticked, both copy buttons also
  change copies that are locked in their scenes, and leave them locked. Unticked, locked copies are
  left as they are, as before; *Unlock* on the same tab frees them.
