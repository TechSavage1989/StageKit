# StageKit 0.1.0-beta173

Scene Fit can give several sources one set of settings, so a few Scene Fit filters can each look
after a group of sources. The Stream Deck plugin is the same as in beta166.

## New

- **Scene Fit: Settings.** A new list in the Scene Fit window, just above *Settings for*:
  - *Each source its own* (as it comes): every fitted source has its own settings, chosen under
    *Settings for*, as before. Scene Fit filters you already have stay this way.
  - *Same for all sources*: one set of settings, *Space priority* included, for every fitted
    source. *Settings for* is hidden and the window shows *Settings for all sources* instead.
    Each source still keeps its own place and its own kept size.

  Switching either way moves nothing. Going to *Same for all sources* starts from the first
  source's settings; going back gives every source the shared settings, which you can then change
  one by one.

## How to set up groups

Add one Scene Fit per group to the scene (right-click the scene, *Filters*):

1. A Scene Fit for the main captures: add the game and window captures under *Fitted sources*, set
   *Settings* to *Same for all sources* and *Space priority* to *Takes space first*.
2. A Scene Fit for the camera and chat box: add them under *Fitted sources*, set *Settings* to
   *Same for all sources*, *Space priority* to *Makes room*, and untick *Resize to fit* if they
   keep their size.

The captures take their space as if the camera and chat box were not there and never move for
them; the camera and chat box fit round the captures. Sources in the same group share space with
each other. If you tick *Priority by list order* on both, the Scene Fit higher in the filter list
goes first instead. List each source in one Scene Fit only.

## Changed

- **Take over Fit to Space**: when a Scene Fit with no sources yet takes over two or more Fit to
  Space filters that all have exactly the same settings, its *Settings* becomes *Same for all
  sources*. If their settings differ it stays *Each source its own*. Nothing moves either way.
