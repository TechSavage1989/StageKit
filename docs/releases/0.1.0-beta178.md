# StageKit 0.1.0-beta178

The Stream Deck *Scene Mode* key now works one Scene Modes filter and shows the mode that is on.

## Changed

- **A Scene Mode key is set to one Scene Modes filter**, chosen by its scene, instead of one mode
  out of every filter's modes.
- **On press** has four choices: *Switch on* or *Toggle* a mode you pick, *Switch off* (no mode,
  where the filter allows it), and the new *Next mode*, which goes through the filter's modes in
  order and round again.
- **The key shows the mode that is on.** With *Toggle*, *Switch off* and *Next mode* the image and
  title change to the mode that is on; with no mode on the key says *No mode*. *Switch on* keys
  still show their own mode, lit while it is on.

## New

- **Each mode's own image**: under *Settings for*, pick a mode, then its layout and its image from
  the full lists. Each mode keeps its own. Left on *Automatic*, a mode uses its *Mode type* from OBS
  or what its name says.
- **Leave modes out of Next mode**: set a mode's *Use* to *Left out of Next mode*.
- **Long press**: holding the key can do one of the same four things, with its own mode and hold
  time. *Nothing* as it comes, so the key acts the moment it is pressed.

## Good to know

- *Toggle* with more than two modes goes between its own mode and the mode before it (or no mode,
  if the filter allows it). To go through all of them, use *Next mode*.
- Keys you already have keep their mode and what a press does.
- Not yet tried on a Stream Deck.
