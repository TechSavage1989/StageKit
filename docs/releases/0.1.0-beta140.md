# StageKit 0.1.0-beta140

One hundred and fortieth pre-release: Stream Deck keys keep their image and name. Only the Stream
Deck plugin changes (0.17.0.0); it passes its own tests, but has not run in a real Stream Deck
here.

## Fixed (Stream Deck plugin 0.17.0.0)

- **Some keys fell back to the wrong image and name.** A key asks OBS what it controls and takes
  its image and name from the answer. When OBS could not answer, the key showed the plain ones:
  *Switch*, *Move*, or *Capture Game* on a key set to a Window Capture. That happened while OBS
  was closed, and also just after OBS started, because OBS accepts the connection before it has
  loaded its scenes; nothing made the keys look again afterwards. Two changes:
  - **A key remembers what OBS last told it.** While OBS cannot be asked, it goes on showing its
    own image and name.
  - **The keys look again once OBS has loaded**: 2, 6 and 15 seconds after connecting, and
    whenever sources are added or removed or the scene collection changes.
- The plugin's version number is raised, so Stream Deck takes this copy in place of the one it
  has. The copy from beta135, where the list on each key became *Image* and the key *Standby
  Image*, had the same number as the one before it, and Stream Deck may have kept the older one.

A key whose filter has since been renamed or removed in OBS shows what it last knew until it is
pointed at the filter again; pressing it gives Stream Deck's warning sign.
