# StageKit 0.1.0-beta21

Twenty-first pre-release: one fix, reported by the owner from the rebuilt collection. It passes the
automated tests on Linux; **it has not been run in OBS on Windows yet.**

## What's fixed

- **A shadow is the same size on every item.** The same 20 px shadow looked small on a camera shown at
  half size and large on a panel shown bigger, because sizes were measured in the source's own pixels.
  Shadow offset, softness, panel margin and rounded corners are now measured as they look on screen,
  whatever size the item is drawn at. *Sizes as they look on screen* turns this off.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- The size is taken from the scene on screen. A source shown at different sizes in different scenes
  gets its shadow sized for the scene you are on, and changes when you switch.
- Existing shadows change size once, to match the screen.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
