# StageKit 0.1.0-beta125

One hundred and twenty-fifth pre-release: a window you pick for the Automatic Window Switcher is
that one window, never another of the same program. It passes the automated tests on Linux; the
Windows side has not run in a real OBS here.

## Fixed

- **Closing a picked window could show another window of the same program.** With two browser
  profiles open, picking one and later closing it moved the capture to the other profile's
  window: private information could go on stream. Two things did it, and both are fixed:
  - *Manual windows* kept the program, not the window. A window picked with *Capture Active
    Window* is now listed as *program — its title* and is tracked as that window; another window
    of the program never answers for it. When it closes it leaves the list.
  - OBS's Window Capture, when its window closes, looks for another window of the same program
    by itself. StageKit now watches the window being shown. When it closes, the capture's own
    picture is not shown again until StageKit has chosen the next window itself: your next
    manual window, or back to automatic. Until then the last frame stays, and with nowhere to
    go the Standby Picture is shown, or nothing.
- This works for any program. A program named in one of the lists still means any of its
  windows; pick the window to mean only that one.
