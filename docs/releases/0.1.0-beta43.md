# StageKit 0.1.0-beta43

Forty-third pre-release: one kind of list everywhere. It passes the automated tests on Linux; **it has
not been run in OBS on Windows yet.**

## What's changed

Every list you build up in a StageKit filter now looks and works the same way:

- a heading;
- a box to choose from. Choosing something adds it straight away, with no separate *Add* button;
- one row for each entry, each with its own **✕** button that removes just that entry.

It replaces the mix of one-line text boxes, OBS's plain list box and separate add buttons. The lists:

| Filter | Lists |
| --- | --- |
| Ramp Blur | *Blur these too* |
| Shadow, Glow & Outline | *Leave it off in these scenes* |
| Auto Capture | *Always capture*, *Never capture* (chosen from the programs that are open) |
| Auto Frame | *Saved shapes* (filled by the save buttons; each row can be removed) |
| Visibility Link | the linked items |
| Program Trigger | the items to show, the filters to switch |
| Layout | *Only these items* |

Lists you have already filled in are kept.

- **Leave it off in these scenes** is now chosen from every scene in your collection, whatever they
  are called, instead of a fixed set of tick boxes. Scenes ticked in beta38 to beta42 are carried over.
  The filter stands down when the scene on screen is in the list.

## Installing on Windows

Close OBS and run `stagekit-0.1.0-windows-x64-Installer.exe`. It installs over an earlier version.

## Known limits

- A box only offers what exists at the moment the filter's window is opened. Close and reopen the
  window to see a program or scene that appeared since.
- The installer and the macOS package are not signed by a publisher.
- File names carry the base version, 0.1.0.
