# StageKit 0.1.0-beta228

Twelve new animated patterns are available in Ambient Background, with nine matching fills for source and scene outlines.

## New

- **Code and signals.** Code wall, Network web, HUD data wall, Circuit board with solder pads and Data streams draw their text, links, tracks and light pulses from the chosen palette.
- **Hex tiles and materials.** Neon hex tiles, Hex flood, Frosted glass and Crystal ice add perspective, a moving color front, textured glass and shifting facets.
- **Light and motion.** Petal lattice, Liquid marble and Deep space add overlapping lit rings, flowing veins and drifting star fields.
- **Matching outline fills.** Neon hex tiles, Hex flood, Frosted glass, Crystal ice, Circuit board with solder pads, Data streams, Petal lattice, Liquid marble and Deep space are available in both outline filters.
